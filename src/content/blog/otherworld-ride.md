OTHERWORLD RIDE（站内中文版叫「异界骑行」）是一款第一人称的无尽摩托骑行游戏：车把握在手里，路在 40 多个浮空世界之间无限展开——钟楼小镇、珊瑚浅滩、云海日出、水晶荒原，还有一个永远向上盘旋的世界。掉下去不会死，弹回来接着骑。它已经上线 [itch.io](https://jerrybobai.itch.io/otherworld-ride)，也可以直接[在站内玩](/otherworld-ride/)。这是我第二款上线的完整作品。第一款 [DieDaily](/blog/die-daily/) 把死亡数当分数，这一款把失败改成弹跳——同一个题材，两种相反的压力哲学。这篇文章记录它的设计核心和技术踩坑。

### 把失败改成弹跳

DieDaily 的世界观是「死亡即奖励」：摔得越惨，分数越高。OTHERWORLD RIDE 把这个逻辑翻了回去——自由骑模式下没有失败画面，坠路只是弹回来，连读档这个动作都不存在。做即死闯关时我在追求「失败也要有信息量」，做这款时我想要的是「失败也要有性价比」：惩罚越便宜，玩家越敢贴边、越敢试那些看起来要出事的路线。

但无失败很快撞上一个问题：没有代价，骑两分钟就腻。解法不是加惩罚，而是给「好好骑车」另找回报——金币串、连击和挑战模式，都是可插拔的压力模块，接上才有张力，拔掉就回到兜风。

### 金币串：把收币做成需要脑子的张力

金币不是撒在路上就完了，它们摆成一串一串，结算按串算：一串收够七成才能续连击，漏一枚就断；整串全收有「完美收串」勋章。于是每一串都变成一个微型决策——贴边收满，还是保连击弃尾？

连击窗按距离算（100 米），串与串之间的空档不断连；5/10/15 连有递增里程碑，20 连起每 5 枚 +15 封顶。跳跃的磁吸做了分层：低空强磁吸、高空收窄——这样「跳过炸弹」和「不吃脚下币」两件事不打架。结算面板里还有一行币串对账，一秒分清你是「避开还连中」还是「漏串从头计」。

### 40+ 个浮空世界怎么铺

世界不是一张张手工地图，而是**分段切换的 biome 链**：路无限生成，每隔一段换一个世界——樱花夜原、水晶荒原、极光月夜、巨型拱门日落、花瓣谷、环雨圣所、天桥……同一段内再从路形池里抽：史诗直道、发卡急弯、窄谷穿梭、波浪缓弯，各有自己的宽度和弯率。

![钟楼小镇：钢琴路的白键一路铺到小镇门口](/images/otherworld-ride/piano-road-belltown.jpg?v=2)

![巨型拱门日落：落日正好卡在第二重拱心里](/images/otherworld-ride/mega-arch-sunset.jpg?v=2)

在 biome 之上叠了第二层天气（雷暴雨、极光、月夜）和第三层事件：天空鲸从谷底游过、金币雨砸在车前、钢琴路的路面变成琴键压出音符币、彩虹路和环链给你换个跑法。三层叠加之后，无尽模式才有了「再骑一段看看」的引力——你不知道下一个转角是天气变了，还是鲸来了。

### 四种模式，四种压力

进游戏先过模式门，四选一：**自由骑**（无压力兜风）、**每日挑战**（当天全网同一串路，成绩可比）、**120 秒挑战**（三档难度——难度的本质是路形池加权加路宽系数：轻松档宽路缓弯，困难档急弯窄谷）、**跑最远**（一条命，绊落、炸弹、坠路三种翻车点即终局）。另有轮盘，转出什么野局骑什么。

选完模式进「待发门」：世界定格，点按开始才松开——自动挡不许在背后偷跑。挑战局里跳段也被锁死：自由骑可以 N 键直跳任意世界，挑战中跳一段等于白捡一公里里程，这个刷分洞从一开始就堵上了。

### 宠物、截图和分享

宠物会骑在你车上同行，凑成对还能解锁组合技。分享做了一键三连：**Shift+P 截图**（UI 合成进图、快门声，偶尔夹一句压带搞笑音——弹簧、喇叭、鸭子叫随机四选一）、录屏直接带声音、或者带着截图直发 X。chill 游戏的传播靠风景卡，不靠成绩单，所以分享链路做得比排行榜靠前。

### 技术踩坑

从 git 历史里挑四条真实的：

1. **单文件 636KB**——全部世界、天气、音效、UI 打进一个 index.html（解压 1.69MB），秒级加载，远低于 20s 红线。代价是「发布即换血」：页面每 60 秒轮询版本指纹，发现落后且暂停中就自动刷新，toast 一句「↻ 源码已更新」——手机上 Safari 软缓存吃旧页的问题就是这么根治的。
2. **POV 相机抓帧**——骑行态相机不可控（源码注释原话），商店截图和封面全靠「冻结定格」：把世界暂停在选好的里程锚点（?s=2500 正落水晶荒原），天气要先低速跑 4 秒收敛再冻结，金币雨要手动臂事件探针。14 张商店截图，每张都是一次小型导演作业。
3. **itch 表单 120 字符实锤**——short description 写了 141 字符被表单拦下，压到 104 字符，优先保住「40+」和宠物两个卖点。同一天还误勾过「Disable downloads」——这个选项的语义是「暂停销售」，不是「无购买声明」，免费游戏误勾会把浏览器试玩一起禁掉。
4. **一份包两条商店**——包里带 CrazyGames SDK 桥，按域名分流：在 itch 上自动休眠，SDK 调用恒丢、无副作用；将来上 CrazyGames，同一个 zip 直接复用。发布策略是 itch 先行——无审核即时上线，先拿稳定链接做真人试玩，再走有审核的商店。

### 复刻指引

如果你想做一个 chill 向的无尽游戏，四条可以直接搬：**失败要便宜**（掉落等于弹回，别让玩家做读档和重开的决定）、**张力要另找来源**（连击窗、计时、一条命都是可插拔模块，接上才有紧张感）、**世界要会变**（biome 链 + 天气 + 事件三层叠加，无尽才有引力）、**分享要一键**（截图带 UI、录屏带声、直发社交）。
