## 一句话概览

Thinking Machines Lab 的 Victoria Lin 以「全面 token 化 + 全局自回归」为主线，讲清 LLM 的架构与训练原则如何成建制迁移到原生多模态模型，并沿三条路线展开：Chameleon（全离散 VQ-VAE）、Transfusion（自回归+扩散）、Mixture of Transformers（模态专属参数）。全讲反复回扣两个核心张力：图像理解与生成似乎需要两套编码，以及「理解促进生成强、生成反哺理解弱」的迁移不对称。结论：现有模型强于数字信息处理，物理世界的时空理解、实时交互与机器人控制仍是开放问题。

## 分节要点（带时间锚点）

### 一、开场与 LLM 范式回顾：为什么只有语言不够

- 讲者 Victoria Lin：Thinking Machines Lab 成员（前 Meta AI、Salesforce AI Research 研究科学家，UW 博士），声明本讲只用公开材料、观点代表个人而非雇主([0:00])
- LLM 范式回顾：transformer 架构做 next token prediction（输出词表上的概率分布），跨领域大规模语料训练；随数据与模型规模增长，涌现出知识获取、经后训练学会指令遵循、思维链推理，乃至规划复杂任务的能力([0:01])
- 但只有语言建模不够：日常数字世界与栖居的物理世界都充满图像、音频、视频等多模态信息；要构建能在物理世界中与人实时交互的 AI 系统，必须无缝处理视觉与听觉信息([0:03])
- 现状佐证：最新旗舰模型纷纷宣称 native multimodal，图像/视频理解与视觉生成等能力已相当惊艳；本讲第一部分就拆解这类模型的构建哲学([0:04])

### 二、原生多模态的统一哲学：全面 token 化

- 构建哲学：tokenization across the board（全面 token 化）——无论输入是图像、视频还是音频，都设法转成 transformer 可处理的 token，再套用与 LLM 相同的全局自回归生成建模([0:05])
- 文本用 BPE(byte pair encoding)切成小片 token；图像做 patchify：按 16×16 像素等标准尺寸分块，过编码器得向量表示后序列化为图像 token；此处 token 不必离散，编码成 dense vector 也称 token([0:06])
- 音频对波形做变换后 token 化；视频视为帧序列，逐帧 patchify 后把全部 patch 拼接，仍可表示为一个 token 序列([0:07])
- 两大类模型：①多模态输入+纯文本输出（多模态序列只作条件、损失仅算在文本 token 上），Gemini、Qwen、Kimi 的主力产品即此形态；②Omni 模型，多模态进多模态出，可生成文本之外的图像与音频，如 GPT-4o（字幕「GPT-4 0」系转写误差）([0:08])
- LLM 原则成建制迁移：混合模态 prompting 与指令遵循、带多模态信息的规划与推理；scaling 正向迁移（扩参数扩数据性能持续提升），但精确的多模态 scaling law 尚属空白（拟合幂律系数是值得做的方向）；MoE 等架构级扩展与效率技术可直接复用([0:10])

### 三、Omni 路线一：Chameleon 全离散化

- 核心假设：能否把每个模态都离散 token 化？若成立，就能把多模态世界当作离散 token 序列建模，LLM 的诸多性质可潜在迁移；关键在于如何把图像离散化([0:13])
- 做法：图像 patch 先过连续编码器得嵌入，再用 VQ-VAE 式的可学习向量码本(learned codebook)取最近邻，以码本索引作为离散 token；图文交织成序列后套交叉熵语言模型训练目标从头训练([0:14])
- 效果：能按任意顺序生成交织的文本与图像，直接产出混合模态文档；支持聊天、头脑风暴、图像对比等多任务——把纯 LLM 技术原样套到混合模态建模上([0:15])
- 意义：首个证明从头训练图文交织序列、既能诱发多模态能力又能保持强纯文本性能的工作([0:16])
- 局限：①理解侧——离散化带来显著信息损失，与 SigLIP 等连续编码的 SOTA 多模态模型存在明显性能差距；②生成侧——离散图像 token 效率低，需海量训练数据才能采样出合格图像；说明「图像信息可离散化」的假设可能过强([0:18])

### 四、Omni 路线二：Transfusion，自回归+扩散统一

- 思路：改用连续图像表征，既作输入也直接预测其输出；把自回归语言建模与扩散图像生成（从噪声出发、迭代预测要去掉的噪声直至清晰图像）合并进单个 transformer（讲者口误把 Transfusion 说成 transcription,已按论文原名修正）([0:19])
- 架构：文本段保持 causal attention；图像段为换取更好性能改用 bidirectional attention；对一段图像表征做多步扩散得到清晰图像后，再作为输入继续自回归推进([0:20])
- 收益：相比离散 token 方案，以少得多的 token 预算更快生成质量明显更好的图像——首个把 next token prediction 与扩散目标无缝统一的多模态建模方案([0:21])
- 遗留困境：Transfusion 采用的 VAE 表征利于生成却不利于理解任务，统一理解与生成的有效表征至今仍是开放问题；当前 SOTA 模型常以两套图像编码作妥协([0:22])

### 五、Omni 路线三：Mixture of Transformers，模态专属参数

- 动机：不同模态信息密度与数据性质差异很大，是否必须共用同一套 transformer 参数？Mixture of Transformers(MoT)给每个模态一套独立参数——attention 层的 QKV 投影矩阵与 feedforward 层各自独立([0:23])
- 机制：按 token 的模态确定性路由(deterministic)激活对应参数集，无需学习路由；QKV 分别投影后仍做联合 attention 让模态交互，过模态各自的 FFN；可与 Chameleon 式（各模态 AR 交叉熵）或 Transfusion 式（文本 AR+图像扩散）目标组合([0:24])
- 实验：scaling ladder 从 163M 到 7B 多档训练，对照 dense 基线与等总参数量的 MoE 基线；非文本模态（图像）生成的验证 loss 与采样式评估指标显著更优，而文本性能与 dense 持平——增益集中在非文本生成([0:26])
- 解释与定性结果：所有能力挤进单一 transformer 存在容量争抢(capacity contention)，分参数后各能力扩得更好；MoT 对细粒度指令遵循与物体细节明显更佳；可与 MoE 叠加、按模态配不同专家数——加专家对文本帮助大，图像生成随专家数扩展较慢([0:27])
- 工程红利：模态分参数让混合模态训练更稳更可控、支持异步训练；典型用法是冻结现成强文本模型、只训新增的图像/语音参数，低成本给已有模型扩展模态生成能力([0:28])

### 六、模态分离的边界与迁移的方向性

- 现场提问澄清：MoT 语境的「图像参数」指图像生成；实验未发现模态分离有助于图像理解——能力边界取决于输出是文本还是图像，只要输出文本，输入 token（无论图文）最好走同一套参数([0:30])
- 后续影响之 BAGEL：图像生成用独立参数、理解走多模态 LM 骨干，理解与生成用不同编码与参数——印证「两套编码」困境；因自回归建模，可先生成思考文本再出图，「thinking before generation」已是当今 SOTA 图像生成模型的常用技术([0:32])
- 具身智能采纳（原论文未含、社区自发）：机器人领域大量架构用 MoT 式参数把动作向量(action)当作独立模态预测，基座语言模型的世界知识经 self-attention 迁移到动作预测、提升预测质量([0:34])
- 迁移方向不对称：理解→生成强正迁移——更强理解基座带来更强信息处理/规划/推理能力，图像细节更丰富、信息图更准确更少幻觉；生成→理解几乎无正迁移证据——烧大量 token 训练生成并不提升图像理解([0:35])
- Sergey Levine(UC Berkeley)之问：next token prediction 让语言模型涌现惊人能力，next frame prediction 却没让视频模型变强；假说：①语言是人类认知的高压缩抽象，训语言即在学推理过程与行动暗示，而图像视频是被动的感官观察；②视觉 loss landscape 更复杂——loss 变好时人看图像可能还很差；③真实世界视频逐帧预测含大量冗余([0:37])

### 七、结论与问答（上）：信息融合、JEPA 与对齐方向

- 总结与收尾：Chameleon/Transfusion/MoT 这类 Omni 模型（总结页讲者口误说成 mixture of experts,应为 mixture of transformers）只解决数字信息处理这一子集；时空理解、实时理解、机器人控制仍大量未解；原生多模态是活跃但远未定型的方向——现有模型距物理世界多模态智能尚远，多模态计算更重、训练与基础设施挑战更大，短期将见更多面向特定能力的专用模型，统一成连贯系统是未来范式([0:40])
- 分离参数下信息仍融合（答问）：模态定制投影后所有 token 仍过联合 self-attention；自回归因果条件（图→文、文→图的 conditioning 顺序结构）保留，跨模态信息依然流动([0:43])
- 对 JEPA（现场发音转写「japa」）的评价：多模态空间太丰富，不同应用可能需要不同表征；patchify+encoder 范式对信息图、PDF、视觉编码类任务已很好，但真实世界的物理空间理解需要 JEPA 这类为此设计的更高效架构，值得探索([0:44])
- 训视频生成能否反哺知识工作：迄今未发现有效迁移；更有希望的信号是机器人任务训练已用视频模型辅助——未来状态预测、为下一步动作预测提供反馈([0:46])
- 把文本渲染成图像来统一模态：今年已有以图像为输入训练语言模型的工作且效果不错（可提示模型「读 OCR 图像」）；讲者预测仍不如纯文本高效（文本自带符号结构），但 OCR 式输入可用更短上下文承载同量文本；若要统一训练，应把其他模态对齐到文本而非反向——文本承载推理与 agentic 能力，反向对齐（如文本 OCR 化）会拖慢这些能力的扩展([0:48])

### 八、问答（下）：统一表征、自回归哲学与纯视觉推理

- 面向对象的语义视觉表征：提问者类比婴儿把共同移动的部件感知为一个物体；讲者认为方向值得探索，这也正是 JEPA 的研究主题之一——对视觉场景做更语义化的表征([0:52])
- 单一表征统一感知/生成/推理：今年已有工作（讲者一时忘了论文标题与出处）研究统一图像生成与理解的表征且结果有希望——用标准图像编码器表征做生成，有时甚至胜过 VAE 表征；若走通，图像建模将向语言建模（统一输入输出）再推进一步([0:55])
- 自回归哲学之争：提问者（提及与 Andre 等交流）质疑 next token prediction 是否根本正确、认为人类学习更结构化分层；讲者提到 diffusion LM、discrete diffusion 等替代路线在探索，但个人认为 next token prediction 已被证明有效，且它可能只是表面形式——网络连接复杂，潜空间里可能已涌现出我们尚未理解的结构化学习([0:56])
- 空间推理现状（自认非专家）：机器人 VLA(vision-language-action)模型进展快且被多模态语言模型加速——Physical Intelligence 等以 VLM 为骨干而非从头训练，说明多模态语言建模到空间理解存在正迁移；也有弱化语言依赖、更重视觉信号的路线（讲者了解不多）([0:58])
- 纯视觉推理是否可能：以语言为骨架对视觉推理目前更有效（语言更抽象，且 captioning 等训练已让模型在视觉信号与抽象空间间往返桥接）；提问者补充 UX 视角——文本可剥离推理段再删掉，而视频生成每帧都得有意义、无法插入专门的「推理帧」；讲者同意效率判断，但认为准确的视频下一帧预测本身即可算一种推理，视频推理数据难获得是瓶颈，待算力与表征成熟后纯视觉空间推理仍是开放问题([1:00:00])

## 核心概念速查

| 术语 | 一句话解释 |
|---|---|
| tokenization across the board | 把文本/图像/音频/视频一律转成 token 序列，再套用 LLM 式全局自回归建模的统一构建哲学 |
| patchify | 把图像按固定尺寸（如 16×16 像素）切成小块，编码后序列化为图像 token 的操作 |
| VQ-VAE | 用可学习向量码本把连续图像特征量化成最近邻码本索引，实现图像离散 token 化 |
| Chameleon | 全离散路线代表：图文交织序列从头训练、单一交叉熵目标，可任意顺序生成交织图文 |
| Transfusion | 自回归（文本）+扩散（图像）统一进单个 transformer 的混合目标架构，图像段用双向注意力 |
| Mixture of Transformers (MoT) | 每模态一套独立 QKV 投影与 FFN 参数，按 token 模态确定性路由，attention 层仍联合 |
| Omni 模型 | 多模态输入且多模态输出的模型（如 GPT-4o），区别于「多模态入、纯文本出」的主流产品形态 |
| SigLIP | 连续图像编码器代表；Chameleon 式离散编码在图像理解任务上与之存在明显性能差距 |
| BAGEL | MoT 启发的 Omni 模型：图像生成分离参数、理解走多模态 LM 骨干，两套编码并存 |
| VLA | Vision-Language-Action，机器人模型形态；常把动作向量当独立模态、用 MoT 式参数预测 |

## 自测题

1. 本讲「原生多模态语言模型」的统一定义是什么？借用了 LLM 的哪两个核心机制？
   > 对一切模态做 tokenization across the board（全面 token 化），再像 LLM 一样在多模态 token 序列上做全局自回归生成建模。
2. Gemini/Qwen/Kimi 主力产品与 Omni 模型（如 GPT-4o）的关键差异是什么？
   > 前者多模态输入但只在文本 token 上算损失、纯文本输出；后者还能生成图像、音频等非文本模态。
3. Chameleon 如何把图像离散化？暴露了哪两大局限？
   > 图像 patch 过连续编码器后用 VQ-VAE 码本取最近邻索引当 token；局限：理解侧信息丢失（明显落后 SigLIP 连续编码），生成侧 token 效率低、需海量数据才能采出合格图像。
4. Transfusion 为统一两种训练目标做了哪些关键设计？
   > 文本走 causal attention + 自回归，图像段走 bidirectional attention + 扩散目标，单个 transformer 混合训练；以远小于离散方案的 token 预算获得更好图像质量。
5. Mixture of Transformers 的路由与 MoE 有何本质不同？增益集中在哪？
   > MoT 按 token 模态确定性激活该模态专属参数(QKV/FFN)，无需学习路由；增益集中在非文本（图像）生成质量，文本性能与 dense 基线持平。
6. 「理解→生成」与「生成→理解」的迁移证据为何不对称？
   > 更强理解基座带来更好规划推理与更细粒度、少幻觉的生成（强正迁移）；反过来烧大量 token 训练生成几乎不提升图像理解（无正迁移证据）。
7. 如何解释「next token prediction 涌现智能，next frame prediction 却没让视频模型变强」?
   > 代表性假说：语言是人类认知的高压缩抽象（训语言即学推理过程），图像视频是被动感官数据；视觉 loss landscape 更复杂（loss 先于观感变好）；真实视频逐帧预测冗余大。
8. 冻结文本模型扩展新模态的工程做法是什么？统一模态训练时应对齐到哪一侧？
   > 给图像/语音新增一套参数、冻结强文本底座只训新参数（异步训练更稳更可控）；统一时应把其他模态对齐到文本而非反向——文本承载推理与 agentic 能力，反向对齐会拖慢其扩展。
