## 一句话概览

本讲从"世界模型 = f(前一状态， 动作) → 下一状态"的模拟器(simulator)视角出发，说明 JEPA 为何把预测从像素空间搬进潜空间。前半讲 Causal-JEPA：用对象中心表示 + 对象级遮罩(masking)+ 把动作当作图上的节点，逼模型学会对象间交互动力学；后半讲 LeWorldModel：无 EMA、无掩码、无预训练编码器，仅靠"潜空间预测 MSE + SIGReg"、唯一超参 λ，从原始像素端到端训出 16M 参数的世界模型，规划比 DINO World Model 快约 50 倍。

## 分节要点(带时间锚点)

### 一、背景：世界模型是"加了动作的模拟器"

- 纯自回归模型(前一状态 → 下一步)不足以描述世界：世界有内在不确定性——你观察的那一刻可能有人扔东西进来；引入动作后才构成世界模型：`f(前一状态, 动作) → 下一状态`，讲者把这个词理解为"模拟器" ([0:02:21])
- 好的世界模型三要素：①好的状态表示——不给预测器喂原始像素，要有忠实反映世界的表示；②好的转移模型——理解重力这类环境底层规则；③好的动力学模型——对动作做出恰当反应；这个框架会在 Causal-JEPA 部分结尾回扣 ([0:02:52])
- 本讲不覆盖生成式世界模型，但给出版图：GAIA(自动驾驶，输入动作与前一状态预测下一驾驶场景)、Genie(为无逐帧动作标注的在线数据学"潜动作"proxy)、Sora(视频生成，靠场景保真度出圈)、Marble(Fei-Fei Li 团队的 3D 可交互环境) ([0:03:58])
- JEPA 与生成式的分野：生成式把编码后的当前状态送进预测器、直接与未来帧在像素空间对比；JEPA 让 x、y 都过编码器，在潜空间对比预测与真目标——重点不是"没有解码器"，而是承认不确定性，让潜空间只保留可预测信息，预测更有意义、更像人类 ([0:05:39])
- LeCun 的原始论文把 JEPA 框架为能量模型(energy-based model)：能量函数对不兼容的 (x, y) 给高值、兼容的给低值，"兼容"即 y 是 x 的合理未来；能量模型会塌缩，两条防线是对比学习与正则化方法，JEPA 走后者——塑造丰富且良定义的能量景观 ([0:06:42])

### 二、Causal-JEPA：对象中心表示与遮罩设计

- 谱系铺垫：V-JEPA(连续帧 + 时空掩码，EMA 编码器、stop-gradient、加掩码提升任务难度防平凡塌缩)→ V-JEPA 2(同架构扩规模，动作条件控制的后训练让它更像世界模型)→ DINO World Model(冻结 DINOv2 编码器 + 简单因果 transformer 自回归预测未来 patch 表示，证明"规划所需的抽象"不必来自从头训练的 JEPA 编码器)；但讲者反问：人类并不会把图像 patch 化来预测下一步 ([0:08:00])
- Causal-JEPA(Learning World Models through Object-Centric Latent Interventions)目标是理解对象交互与对象动力学，用三个数据集：Push-T(操纵蓝球把灰色 T 块推到与绿色 T 完全重合)、CLEVRER(视频 + 问答，含预测性/反事实/解释性三类问题)、PHYRE(重力、质量等落地规则下的多对象交互)；现有模型 patchify 后逐 patch 预测，而人想理解的是"一个对象如何影响另一个对象" ([0:10:27])
- 对象中心表示(object-centric representation)怎么来：slot attention(Locatello)的编码器-解码器框架，slot 像装特征的"篮子"、每个对象一个；注意力里 key 与 value 都是输入特征(如 DINOv2 的 patch embedding)，slot 用 GRU 迭代更新，解决"特征-槽位"绑定(binding)问题 ([0:12:28])
- 预测器不必是因果自回归 transformer：只要只看历史，多步历史也可以，于是用双向(bidirectional)ViT 风格 transformer，未来时间步放 mask token 占位；对模型最省力的捷径是对前后 token 插值，但那不是想要的——想要的是学对象交互 ([0:15:28])
- 遮罩策略：像"把香蕉整个遮住"那样全遮最激进，模型没有捷径、必须从其他 slot 推断(猴子吃香蕉例:看不到香蕉也能从嘴动推断香蕉变短)；但 slot attention 固定最大槽位数、槽内对象无身份，对象是集合而非列表(置换等价，跨视频顺序不保证)，一次遮多个时模型不知道该预测什么——解法是首个时间步不遮、以其作 slot 身份，被遮 token = 身份令牌 + 可学习 mask token + 位置编码，顺便给每个对象留了初始条件 ([0:17:11])

### 三、动作即节点：架构与三组实验

- 动作条件化(action conditioning)的两种做法：DINO World Model 把动作 embedding 复制后拼接到每个 patch 表示之后(DINOv2-Small 是 384 维特征，每 patch 拼一次)；Causal-JEPA 把动作当成图上的另一个节点——对象是节点、动作也是节点(动机接地于因果图，但明确不恢复真因果图) ([0:20:04])
- 完整架构：历史帧 → 对象中心编码器得到对象表示 → 挑选若干对象遮罩 → 双向 transformer 预测器(动作作为节点参与)→ 预测所有被遮 token ([0:22:03])
- CLEVRER 结果：关键不是"用了对象表示"，而是遮罩本身——对比自家无遮罩版本即知；反事实类问题(如果这个对象不存在会怎样)收益最明显，与"逼模型考虑对象间影响"的动机呼应 ([0:22:32])
- Push-T 与效率：对象 token 数远小于 196 个 patch × 384 维，且对象表示语义清晰——纹理、颜色、形状、旋转状态、位置，没多少东西，不需要巨大表示空间；但把 DINO World Model 的 patch 表示直接换成对象表示会大幅掉分，因为单帧静态表示本来就定义不了速度、加速度 ([0:23:28])
- 消融数字：动作改为独立节点 + 换双向 transformer，带来 15% 的绝对提升；再叠加对象遮罩，比 OC-JEPA(Object-Centric DINO World Model)又提升 28%；动作条件化曲线里，潜向量拼接(红线)是 DINO-WM 式做法，改成节点后差距清晰 ([0:25:37])

### 四、因果语义、四条假设与局限

- PHYRE(三个数据集中动力学最复杂)暴露差异：OC-JEPA 常生成物理不合理场景——杆悬浮在固定杆下方；那是"两杆靠近就待着"的相关性学习，不是物理；遮罩等于不断问模型"如果这个不存在会怎样"，逼它考虑该看什么才能预测被遮 token，从而学到真动力学 ([0:26:17])
- 注意力探针(probe)显示失败来源：OC-JEPA 预测时关注了装蓝球的杯子(无关对象)，而 Causal-JEPA 条件在正确的杆上 ([0:27:20])
- 术语澄清："causal"在这里指时间上有向的预测依赖(temporally directed predictive dependencies)——从历史预测未来所以边有向，不是传统因果推断的定义(但现代因果机器学习也渐用此类定义)；预测器找到的"影响邻域"(influence neighborhood)= 预测充分集(predictably sufficient set)：正确预测被遮 token 所需的最小集合 ([0:28:01])
- 形式化依赖四条假设：①无瞬时(instantaneous)关系；②所有训练样本共享同一机制(重力不会随视频改变)；③对象对齐表示(object-aligned)——对象表示全程稳定，不换槽、不分裂、忠实反映场景，实践上最棘手；④历史充分性(history sufficiency)——例如 4 帧历史足以预测下一帧 ([0:29:05])
- 刻意放宽的与答疑：不假设一阶马尔可夫(对象中心表示通常不满足)，允许混杂因子(confounder)——所以无法恢复真因果图，且很多场景"真因果图"本身难定义；对象表示稍不忠实仍可(遮罩对象槽位仍是一种归纳偏置)；遮罩对象数按数据统计定、需要扫一扫；最大限制来自对象中心编码器——遮挡、对象中途出现/消失都处理不好；结尾回扣三要素：对象表示=状态表示、对象遮罩=转移模型、动作节点=动力学模型 ([0:30:48])

### 五、LeWorldModel：单超参的端到端 JEPA

- 交接：Lucas Maes(Mila/蒙特利尔大学三年级博士，导师 Damien Scieur[Samsung],与 Brown 的 Randall Balestriero、NYU 博士后 Quentin Le Lidec 及 Yann LeCun 合作)；主题是把 JEPA/世界模型的训练变简单：JEPA 主张先编码到抽象空间再学动力学，与建模输入空间本身的生成式路线直接对立 ([0:33:37])
- 为什么不建模输入空间：自驾应用不需要建模路边树叶的摆动，但生成式损失按定义会对一切细节给信号；而只要在潜空间预测，就会遇到塌缩(collapse)——不给 embedding 分布加约束，模型可以学会无视输入、恒输出常向量(比如全 0)，潜空间预测损失平凡地归零；JEPA 研究很大一部分就是防塌缩 ([0:35:08])
- 已有方案的代价：V-JEPA 靠 EMA；DINO World Model 靠冻结预训练编码器(产生非平凡 embedding,本质接近监督学习)；PLDM 全端到端 + 动作条件，但用 VICReg(把特征协方差拉向单位阵的反塌缩正则)——方差项 + 协方差项 × 空间 + 时间共 4 项，再加逆动力学损失与潜空间未来预测 L2，合计六项损失、六个超参，非常难调——这就是 LeWorldModel 的出发点 ([0:36:43])
- LeWorldModel 配方：没有 EMA、没有掩码、没有 stop-gradient、没有预训练编码器，也没有不稳定的多项损失；仅 16M 参数、单张 GPU 可训；从原始像素完全端到端，不用本体感觉(proprioception)等任何辅助信息；规划比 DINO World Model 快约 50 倍(讲者口误说成"比 LeWorldModel 快 50 倍",应为对比 DINO World Model) ([0:38:38])
- 方法本身：取 ot 与 ot+1 过共享编码器得 zt、zt+1；预测器以 (zt, at) 预测 ẑt+1，与编码器给的 zt+1 做 MSE；再用 SIGReg 防塌缩——伪代码就是真实代码，没有额外花样 ([0:39:30])

### 六、SIGReg 与控制评估

- 调参友好：返回的损失里只有唯一超参 λ，可用二分搜索以 log n 找到合适值 ([0:40:36])
- SIGReg(Sketched Isotropic Gaussian Regularizer,Randall Balestriero 与 Yann LeCun 前一年 11 月提出)：把 batch 内 embedding 的分布优化成各向同性高斯，确保 zt 有信息量、可视为学到的世界状态抽象；不走 VAE 式生成建模与 KL 散度，而借统计检验思路——但高维检验有维数灾难，于是沿大量随机方向把 embedding 投影成一维，逐个边缘分布优化为高斯 ([0:41:19])
- Cramér–Wold 定理兜底：只要(足够多方向上的)边缘分布都是高斯，联合分布就是高斯——由此可证潜 embedding 分布整体高斯，embedding 必然有信息量 ([0:43:27])
- 评估两条路：在线控制与直觉物理；控制做法是采样随机动作序列，在可微预测器里 rollout 未来，用潜空间 MSE 度量与目标帧表示(Og → zg)的距离，反向传播优化整段动作序列；四个任务：TwoRoom(2D 穿门导航)、Reacher(DeepMind Control 二连杆到位)、Push-T(只能推不能拉)、OG-Bench Cube(3D 机械臂把立方体弄到目标位) ([0:44:06])
- 结果：Push-T 上，无本体感觉的 LeWorldModel 以一半参数胜过有本体感觉的 DINO World Model，而 DINO-WM 一旦去掉本体感觉性能大跌，同为端到端无本体感觉的 PLDM 也很差；Reacher 同样胜过 PLDM 与 DINO-WM；OG-Bench Cube 胜过 PLDM 但输给 DINO-WM——它的编码器在约 1.24 亿张自然图像上预训练过，对象与 3D 理解更强 ([0:46:57])

### 七、效率、直觉物理与潜空间探针

- TwoRoom 反常：最简单的任务几乎所有基线都翻车，LeWorldModel 不翻——原因是 SIGReg 的内在维度(intrinsic dimensionality)问题：问题的真实维度(TwoRoom 只需 x、y 两维)远小于 embedding 维度时，分布根本无法变成高斯，SIGReg 会被迫"编造假信息"凑高斯；细调超参可以缓解，但为了公平所有环境共用同一组超参 ([0:48:20])
- 规划速度：DINO World Model 被重度优化后做完整规划仍需 47 秒(预测器要处理全部 patch,注意力二次方成本)；LeWorldModel 用单个 CLS token 表示潜状态，完整规划 1 秒内，约快 50 倍；再把 FLOP 固定在 LeWorldModel 的预算、把 DINO-WM 的规划超参调进 1 秒，Push-T 与 OG-Bench Cube 成功率大跌——同预算下 LeWorldModel 连 OG-Bench Cube 也反超 ([0:49:51])
- 潜空间探针：冻结 LeWorldModel 编码器，训线性或 MLP 探针(文字稿写作 "NLP probe",应为 MLP,即非线性探针)预测该状态的仿真系数；OG-Bench Cube 上线性探针几乎总是 LeWorldModel 的 MSE 更低，而非线性探针几乎总是 DINO-WM 更低——说明 LeWorldModel 潜空间更少纠缠，SIGReg 把每个维度推得更"无意义"，反而更解耦 ([0:51:18])
- 违反世界模型实验：正常轨迹中机械臂抓起立方体右移，中途做两种扰动——突然变色、突然瞬移；变色后预测误差几乎不变(动力学不需要颜色，模型不在乎)，瞬移后预测误差飙升(模型没预测到)；有人质疑"这只是分布外(OOD)"，讲者回应：人类违反内部模型时同样 OOD——看魔术硬币消失会又惊又恼，本质上是一回事 ([0:53:22])
- 两个附加实验：t-SNE 投影 embedding 空间，能恢复 agent 与 T 各位置的相对距离(至多差一个轴置换与镜像)；冻结世界模型、训练解码器解码开环(open-loop)rollout——给定同样的动作序列，世界模型想象的未来大体符合现实，但第 15、20 帧夹爪角度相反：它没学会夹爪旋转，却仍能把任务解个大概 ([0:55:07])

### 八、局限、开源库与 Q&A 精选

- 局限(讲者自称"research opportunities")：只能短期规划视野；单一时间层级、需要层级化(hierarchy)——去机场时先想"去机场"这个目标，再想开车、机场，最后才落到肌肉动作，不会一直用肌肉动作思考；要走出玩具环境，迈向真实机器人或 Minecraft 这类随机、部分可观测环境；目标指定只能给视觉目标帧，表达不了"降落要平稳"这类约束(飞机降落不能只给一张降落后的图)；顺带安利 stable-worldmodel 开源库：本讲各基线(Causal-JEPA、DINO-WM 等)、规划 solver、多环境(新加 DeepMind Control 与 Minecraft,洽谈接入真实机器人数据)都有实现与测试 ([0:57:17])
- Q(物理 AI/机器人)：Lucas 对当前 VLA(GR00T、π、Psi-Zero 等扩散基础模型)持怀疑——它们不训练"预测动作的后果"，不知道动作结果的系统难以可靠；与真实世界交互绕不开世界模型(跳舞这类只需内部动力学的除外)；Hazel 补充 Sherry Yang(NYU)的观点：世界模型还可以当策略评估器；又问世界模型 vs 扩散模型——不冲突，世界模型照样可用扩散模型，也有人试过用扩散训 JEPA ([1:00:31])
- Q(遮罩是否必要、纯预测损失够不够)：若无对象中心表示、只做预测损失，模型可能学到自动力学(self-dynamics)捷径，无法保证学到交互动力学；不能说预测损失"不足"，但遮罩能强化模型学对象动力学 ([1:02:42])
- Q(JEPA 原生 agent 与幻觉)：与 LLM agent 的差别在于学的是动作条件模型而非工具调用，且配模型预测控制(MPC)可零样本变成 agent、无需后训练；JEPA 不是新架构——LeWorldModel 的编码器与预测器都是 transformer，它是学世界模型的框架；幻觉来源不同：LLM 的幻觉部分源于不接地于真实世界，世界模型可修；世界模型学不好照样有幻觉(数据与容量问题)，还有一类是规划时动作优化越界——动作域 [-1, 1] 优化出 -2 ([1:03:58])
- Q(长视野与蒸馏)：有世界模型后两条路——直接优化动作序列得到零样本策略；或像 Dreamer 那样在预训练世界模型上训 RL 策略、周期性回环境收数据再微调；愿景是类人的 System 1/System 2：简单任务用直出动作的"反应式"策略，难任务用 MPC 仔细规划再蒸馏——类比学车：前 20 小时靠 MPC 保证不出事，自认专家后把 MPC 的规划蒸馏成直接输出动作的策略 ([1:09:35])

## 核心概念速查

| 术语 | 一句话解释 |
| --- | --- |
| JEPA(Joint-Embedding Predictive Architecture) | 联合嵌入预测架构：x 与 y 都过编码器，在潜空间比较预测与目标，而非在像素空间 |
| 塌缩(collapse) | 潜空间预测缺分布约束时，模型无视输入、恒输出常向量的失败模式 |
| 能量模型视角 | LeCun 对 JEPA 的原始框架：兼容的 (x, y) 能量低——y 是 x 的合理未来 |
| slot attention | 对象中心学习机制：迭代注意力把特征按对象"装"进固定槽位(篮子)，用 GRU 更新 |
| Causal-JEPA | 对象级遮罩 + 动作作图节点的 JEPA；causal = 时间上有向的预测依赖 |
| 影响邻域(influence neighborhood) | 正确预测被遮对象所需的最小对象集合，即"预测充分集" |
| LeWorldModel | 16M 参数、唯一超参 λ、从原始像素端到端训练的极简 JEPA 世界模型 |
| SIGReg(Sketched Isotropic Gaussian Regularizer) | 把 embedding 沿随机方向投影成一维边缘并优化为各向同性高斯的正则化；Cramér–Wold 定理保证联合高斯 |
| VICReg | PLDM 所用抗塌缩正则：把特征协方差拉向单位阵；叠加后损失多达六项、六个超参 |
| MPC(model predictive control) | 模型预测控制：用世界模型 rollout 并优化动作序列，可零样本得到策略 |

## 自测题

1. 为什么 JEPA 不用解码器、在潜空间比较预测与目标?关键是什么?
   > 关键不是省掉解码器，而是承认世界的不确定性：让潜空间只保留可预测的信息，预测更有意义、更像人类的抽象方式
2. Causal-JEPA 里的 "causal" 是什么含义?它能恢复真因果图吗?
   > 指时间上有向的预测依赖(从历史预测未来，边有向)；不能恢复真因果图——允许混杂因子，且很多场景"真因果图"本身难定义
3. 为什么 Causal-JEPA 多对象遮罩时需要"身份令牌"?
   > 对象是集合不是列表(slot 置换等价、跨视频顺序不保证)，遮多个时模型不知道该预测什么；保留首个时间步不遮作为每个 slot 的身份，再加可学习 mask token 与位置编码
4. LeWorldModel 相比 PLDM 的损失与超参配置有什么不同?
   > PLDM 用 VICReg 叠出六项损失、六个超参；LeWorldModel 只有潜空间预测 MSE + SIGReg，唯一超参 λ 可二分搜索(log n)调优
5. SIGReg 如何绕开高维统计检验的维数灾难?
   > 沿大量随机方向把 embedding 投影到一维，逐个边缘分布优化为高斯；Cramér–Wold 定理保证边缘全高斯则联合分布高斯
6. 为什么 OG-Bench Cube 上 LeWorldModel 输给 DINO World Model?
   > DINO-WM 的编码器在约 1.24 亿张自然图像上预训练过，对象与 3D 理解更强；LeWorldModel 只用数据集内轨迹从原始像素端到端训练
7. 立方体变色与瞬移实验说明什么?如何回应"这只是 OOD"的质疑?
   > 变色预测误差几乎不变(动力学不需要颜色)，瞬移误差飙升(违反动力学预期)；讲者认为"只是 OOD"的说法无意义——人类看到魔术硬币消失也同样惊讶挫败
8. 世界模型训练好之后，得到 agent 的两条路径是什么?
   > 直接在世界模型里优化动作序列得到零样本策略(MPC 式)；或 Dreamer 式在世界模型上训 RL 策略并周期回环境收数据，长期可 System 1/System 2 分层，把 MPC 规划蒸馏成直出动作的策略
