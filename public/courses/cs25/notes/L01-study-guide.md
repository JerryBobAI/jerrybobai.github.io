## 一句话概览

CS25 第六季开场课。前半程用三次范式跃迁(手工特征 → 监督深度学习 → 自监督)和 RNN → Transformer 的架构演化讲清 Transformer 是什么、为何胜出，并说明 LLM = 放大版 Transformer + 海量预训练数据。中段通过婴儿规模语料、双语混训、RAG scaling、CGLS 课程学习四个数据侧项目论证"数据效能 = 质量 × 结构 × 使用策略"，再串起 chain-of-thought 到 RLHF/GRPO 的后训练技术与智能体自我改进闭环。后半盘点 ViT/CLIP/脑科学等跨域应用，最后聚焦幻觉统一定义、长期记忆与持续学习、可解释性与对齐三大挑战，以 JEPA 世界模型与 SSM/Mamba 两条"后 Transformer"路线收尾。

### 二、范式跃迁：从手工特征到自监督学习

- 2012 年前的早期 ML：手工设计任务相关特征 + 浅层模型做预测，依赖人工采集的小规模昂贵标签构成反馈回路来更新参数([0:05])
- 监督深度学习：模型变大后，用原始数据直接取代手工特征，砍掉"特征工程"中间商，从 raw data 一步直达预测([0:06])
- 自监督学习：连昂贵标注也不要了——对原始数据加噪/masking 等破坏，训练模型还原未破坏的原始数据，从而学到可迁移的通用表示，再针对下游任务微调([0:07])
- 语言案例：早期做情感分析(短评 0/1/2 三分类、词级特征)→ 转向 next token prediction(下一词预测)：语言天然序列化、上下文丰富("the quick brown fox jumps over the ___"你能秒填)，且能从海量原始文本无限构造训练对，最大化利用数据([0:08])
- 视觉案例同构：自编码器学表示、对比学习，以及近年的 masked autoencoder(遮住图像块训练还原)；开放问题是如何选 mask——随机遮 3 块可能让任务过易(一眼看出)或过难，未来要找更好的难度平衡([0:09])

### 三、通往 Transformer：词向量、RNN 与自注意力

- 词嵌入(word embeddings)是语言模型的关键组件：Word2Vec/GloVe/FastText 等把词映射为高维稠密向量，支持语义算术(king − man + woman ≈ queen)；静态嵌入一词一向量的缺陷是无法区分 bank(银行 vs 河岸)歧义，于是有按上下文赋不同向量的 contextual embeddings([0:10])
- RNN(循环神经网络)逐步处理输入并维护 hidden state 记忆，长序列会"遗忘"开头信息；LSTM 是门控变体，用额外参数控制何时记住/遗忘/输出，缓解长程依赖丢失([0:11])
- Transformer 核心是 self-attention：学 Query/Key/Value 矩阵决定每个 token 关注什么——类比图书馆找书：query 是你的需求、key 是每本书的摘要、匹配后取回 value(书的内容)，对全馆做软匹配打分；注意力本身无序，需加 positional encoding 标注位置(最简单就是第 1/2/3…个词)；同一序列上做多组注意力即 multi-head attention，得到更丰富的表示([0:12])
- Transformer 全面取代 RNN 的三大理由：①并行性——RNN 天生逐步串行，attention 一步处理整段序列、可充分吃 GPU；②长上下文扩展性更好——LSTM 只部分缓解梯度消失/遗忘，如今 Transformer 上下文可达百万 token 量级；③能直接访问上下文中所有历史 token 并两两连边，而 RNN/LSTM 只能把历史压进有限容量的 hidden state([0:14])

### 四、规模化与预训练：LLM 的诞生

- 架构红利外溢：Transformer 已渗透科技各领域——日常在用的 LLM(GPT-5、Claude 等)、越做越好的视觉模型(部分已上手机)、语音、生物、视频、机器人([0:15])
- LLM 本质 = 放大到数十亿参数的 Transformer，在互联网规模的通用文本上以 next token prediction 预训练；规模化带来涌现能力(emergent abilities, seminal paper:只训通用文本就自发出现数学、推理等能力)和 zero-shot/few-shot 泛化(见过的数据够多,全新任务也能快速上手)([0:16])
- 预训练是训练第一阶段：从随机初始化开始，目标是把尽可能多的知识和基础能力装进模型；海量多样文本使模型逼近人类语言的天然分布——数据是 AI 模型的燃料，预训练的根本就在数据([0:17])
- 为什么专门研究小模型与数据：①算力门槛——复现 GPT-4/GPT-5 量级训练动辄数百万美元；②小模型打开新用例——手机端日常任务、与个人目标更对齐；③小尺度发现的技术可迁移回大模型提升效率与能力；④理解小模型如何更有效，也可能反哺对人类语言习得认知机制的理解([0:18])

### 五、数据侧四连击：婴儿规模、双语、RAG 与 CGLS

- Baby scale 项目：人类儿童 0-13 岁仅接触约 1000 万~1 亿词，比达到类似泛化/抽象/推理能力的 LLM 少几个数量级；用单个儿童真实转录(听到+说出的)训练语言模型，在 Zorro(语法)、WS 与 comms(语义理解,字幕原文如此)、EWoK(基础世界知识)四个基准上看 scaling——正趋势存在但信号噪声大，不同家庭数据训出的模型表现差异很大([0:20])
- 换用最高 2 亿 token 的干净合成对话数据(TinyDialogues)后 scaling 更干净；小尺度实验外推后落在直至 RoBERTa-base(讲者回忆约 200-300 亿 token 预训练)的广义 scaling 曲线上；scaling 依任务而异——语法的 Zorro 好于世界知识 EWoK，说明单个儿童的语言环境可能不足以习得通用世界理解、需要外部数据；对各家庭语料做语言学分析并与最终性能相关联，发现起作用的还有语义多样性、对话数量、分布散度等质量因素——小尺度下质量重于数量，与儿童语言习得研究一致([0:23])
- 双语项目：检验针对人类的"融合假说"(fusion hypothesis,多语环境儿童要平衡冲突信息、可能拖累母语习得)是否适用于 LM；英语+西班牙语各 5000 万混成 1 亿 token 同时训练(非先后)，另做句级与词级 code-switching(语码切换)实验——多语模型困惑度与英文基线持平甚至略低，基准表现持平；暴露结构(妈妈固定说英语 vs 按说话人随机等)无显著影响；数据规模比模型规模更关键：模型变小无碍，数据从 1 亿词降到 2000 万词才显著变差([0:25])
- RAG scaling(Karan)：RAG = 在 LLM 外挂领域文档库 + 检索器，查询时把最相关文档喂进上下文；给定固定 token 预算，预训练与检索 token 之间存在最优分配前沿；小模型从 RAG 获益大、大模型很快饱和——以"每 1 个检索 token 等价节省的预训练 token"衡量，存在交叉点：每参数约需 4 个预训练 token(1B 模型需约 4B token)才有效利用 RAG；充分预训练的大模型(如 3B)对通用 web 检索增益趋零(信息早已参数化记住)，领域专属文档则是另一回事([0:29])
- CGLS(Curriculum Guided Layer Scaling,Karan)：动机是人类边上学课程边长脑子——能否小模型+简单数据起步、训练中逐步加层、数据由易到难同步升级?此前 stacking(复制编码层再训)的问题是相邻层学重复内容(Midas 2024)；CGLS 在 124M 与 1B 尺度上胜过同尺寸随机训练(甚至胜过同课程但全程最大尺寸训练)，且从 20 亿 token 扩到 200 亿 token 领先差距进一步拉大；意外结果：1B 尺度上随机基线困惑率反而优于 CGLS(CGLS 赢在推理任务)，未来方向包括难度定义本身、超参调优、迁移到图像/医学影像([0:33])

### 六、后训练与智能体：推理、偏好与自我改进

- 四个项目总纲(Steven)：数据效能不只是数量，而是质量、结构与使用方式；婴儿规模项目说明家庭间差异主要由数据组成与质量驱动，双语项目说明两种语言可无干扰习得、暴露结构无关，CGLS 说明模型随课程同步生长能提升下游性能(至 1B 尺度)，RAG scaling 说明最优性能来自参数化学习(预训练)与外部记忆(检索)的平衡——总之一句话：有效的语言建模靠的是更聪明的数据利用策略([0:35])
- 推理增强型后训练：chain-of-thought prompting 让模型像人一样先想再答(把难题分解成子步骤)，说明模型权重里"知道的比直接回答时表现出来的多"；扩展方向：tree-of-thoughts(多推理路径 + 多数投票等评估择优)、把中间推理外化成代码交给解释器执行(数学类任务收益大)、Socratic questioning(自我提问模块生成子问题、分治递归求解)以及把组合任务表述为计算图([0:37])
- 基于反馈的后训练谱系：RLHF(从人类对两个回答的排序训练奖励模型再强化学习)→ DPO(免 RL、免独立奖励模型,直接优化偏好)→ RLAIF(人类主观、有偏且昂贵,用现成 LLM 给偏好替代)→ GRPO(DeepSeek 提出,对一组回答做组内相对排序而非二元偏好,反馈更细粒度,数学等任务表现提升)([0:40])
- 过程监督(process supervision / process rewards)：很多任务天然多步，与其只在终点给奖励，不如对中间推理步骤做标注与评估——单步更准带来更好的最终答案，同时减少 reward hacking([0:42])
- AI 智能体与自我改进：agent = 感知环境 → 推理/规划 → 行动 → 观察结果 → 反思迭代的闭环(如 Claude Code(字幕误作 Cloud Code)跑完脚本检查编译是否通过再决定重试)；模型由此能从过去的错误中迭代改进；再配记忆库(如 GPT 现在的 memory,可存历史教训)、工具调用/网络搜索/数据库查询，把外部结果融入最终回复([0:44])

### 七、超越语言：视觉、CLIP 与脑科学

- 应用版图：DeepMind AlphaFold(遗传学/蛋白质)、医学语言模型、AlphaGo(讲者口误说成 chess——AlphaGo 下围棋,国际象棋是 AlphaZero/AlphaZero 系)、图像生成等，AI 正在接管每个领域([0:45])
- ViT(Vision Transformer)：逐像素当 token 太贵(28×28 的小图展平也近 1000 个 token)，于是把图像切成 patch、编码为更短的 token 序列；且 patch 表示学习本身就是很好的表征学习算法([0:46])
- 为什么用 Transformer 换掉多年好用的 CNN：CNN 带强归纳偏置——局部性假设(4×4 卷积核隐含该尺度内相关)，小数据下学得快但成为性能天花板；Transformer 几乎无先验、对输入假设极少，必须靠大数据喂养，但数据够大时上限更高([0:47])
- CLIP 开启的另一大转向：文本与图像各用一个编码器映射成向量，用图文配对数据训练两者对齐表征([0:48])
- 神经科学应用(Karan 的研究)：fMRI 测的是血氧变化，信号噪声大、高维、多为相关波动而非电极式的稳健激活——关键不是绝对值而是信号间相关性；大脑可分解为稳定性较好的 7/17 个网络(视觉中枢、调控注意力与感官的显著性网络、负责"白日梦"的 DMN 默认模式网络)；其工作把网络划分作为先验喂给 Transformer——不是随机 mask patch，而是 mask 掉整个网络、让模型用其余脑区预测它，学到更稳健的嵌入：能按疾病状态聚类(对照 vs MCI 轻度认知障碍,后者易发展为阿尔茨海默病)，能探测网络间依赖与可预测性(视觉中枢可预测、皮层下记忆相关区域相对独立)，并发现阿尔茨海默病人 DMN 受影响不成比例——或可指导药物开发与病程机制研究([0:51])

### 八、挑战清单与 Transformer 之后：幻觉、记忆、对齐、JEPA 与 SSM

- 幻觉(hallucination)：模型编造不存在的事实/引用/细节却语气自信，知识缺失时不表达"我不知道"；成因假说：①模型优化的是"最可能"而非"最真实"(next token prediction 训练目标使然)；②缺乏接地/世界模型(grounding)；③用户提示本身模糊、信息不足诱发编造；后果是信任与可靠性受损，法律/医疗等高风险领域尤甚，且因语气自信而难以检测、真伪又依赖语境，至今没有统一([0:55])
- 幻觉统一定义(Steven 的论文)：核心思想是幻觉 = 世界建模错误——模型通过预训练学到内部世界模型，而任务有外部参考世界模型(摘要任务的源文档、开放域 QA 的真实世界、agent 的网页环境)，当学到的世界模型与参考矛盾时即为幻觉；数学框架三要素：参考世界模型(何为真)、视角 view(模型实际能看到的信息,如检索所得)、冲突策略(信息源冲突以谁为准,如角色扮演中"哈利·波特是女孩"应以用户设定为准)；同一输出在此设定是幻觉、在彼设定正确；该定义把幻觉与规划错误区分开(点不存在的按钮=幻觉,信念正确但选错策略=规划错误)，让假设显式化、可跨基准比较，并支撑可合成构造的 HalluWorld 基准(操纵三要素批量生成幻觉样本,后续发布)([0:58])
- 长期记忆与持续学习：当前模型基本无状态(stateless)，跨会话记忆靠外挂——向量数据库检索、把过往信息压缩进上下文、列表/图等结构化存储；缺的是可靠更新(新信息与旧信息冲突时覆盖还是并存?记忆过长时按什么标准剪枝?)；理想是部署后持续学习(lifelong/continual learning)，讲者立场：真持续学习应更新权重(模型的大脑)，仅上下文/inference-time 学习不算；现有 model editing(如 Rank-One Model Editing, ROME)只能改简单事实、且无法把变更传播到关联事实——把"Bob 的爸爸是 Justin"改掉，他姐妹的爸爸也得同步改，这类联动有上百条，模型编辑做不到([1:00:00])
- 可解释性与对齐：超大模型是难以理解的黑盒——mechanistic interpretability 用 circuits(回路)、features(特征)等拆解内部表征，弄清模型"真正在想什么"而非只看输出；对齐方面，模型会抄捷径、可能学到训练者不知道的隐藏目标，分布偏移下行为漂移；具体失效模式：reward hacking(优化奖励而非真目标)、CoT 忠实性(faithfulness——输出的推理步骤可能是事后编造而非真实依据,需因果干预检验)；工具箱：RLHF/RLAIF(本身又易被 reward hacking)、过程监督(考察单步而非只看结果)、Constitutional AI(Anthropic 提出,给模型一部成文"宪法"做后训练约束)、scalable oversight(模型监督模型,应对人力无法看管海量超强大模型)([1:05:00])
- Transformer 之后：注意力对序列长度是二次方复杂度、长上下文推理常失败、且(有争议但讲者认同)未必真正学到有效的世界模型——两条新兴替代路线：①世界模型与 JEPA(Yann LeCun 提出,Joint Embedding Predictive Architecture)：不再预测原始 token 而预测潜在表征，聚焦潜在结构、不建模低层噪声，更数据高效、抽象泛化更好、更接近人类"预测世界状态而非像素"的学习方式；②SSM(State Space Models)：以连续状态更新维护压缩内部状态(类似 RNN 的 hidden state)，线性时间复杂度、长序列长上下文更强，代表是选择性 SSM 架构 Mamba，代价是某些场景不如 attention 灵活、研究尚早期；彩蛋：下两讲恰好都不讲 Transformer——Hazel Nam 讲 JEPA/世界模型，Albert Gu(字幕作 Albert Goo)讲 Mamba/SSM([1:10:00])

## 核心概念速查

| 术语 | 一句话解释 |
| --- | --- |
| Self-Attention 自注意力 | 用 Query/Key/Value 三组矩阵对序列内 token 做软匹配打分，让每个词学会"该关注哪里"。 |
| Positional Encoding 位置编码 | 注意力本身不含顺序信息，给每个位置附加向量，让模型感知词序。 |
| Contextual Embedding 上下文嵌入 | 同一个词按上下文赋予不同向量，解决静态嵌入无法区分 bank(银行/河岸)一类歧义的问题。 |
| Emergent Abilities 涌现能力 | LLM 随参数规模扩大，在数学、推理等未专门训练的任务上自发出现的能力。 |
| RAG 检索增强生成 | 检索器按用户查询从文档库挑出相关内容塞进 LLM 上下文，用外部知识改善输出。 |
| CGLS 课程引导层缩放 | 小模型+简单数据起步，训练中逐步加层并同步提升数据难度，解锁模型生长(stacking)的收益。 |
| DPO 直接偏好优化 | 免强化学习、免独立奖励模型，直接用人类偏好数据训练模型偏好被选中的回答。 |
| Process Supervision 过程监督 | 对中间推理步骤给奖励/标注，而非只看最终答案，提升步骤质量并减少 reward hacking。 |
| ViT 视觉 Transformer | 把图像切成 patch 编码为 token 序列再喂给 Transformer，几乎无归纳先验、大数据下上限更高。 |
| JEPA 联合嵌入预测架构 | LeCun 提出的世界模型路线：预测潜在表征而非原始 token，不建模低层噪声、更接近人类学习方式。 |

## 自测题

1. Transformer 相比 RNN/LSTM 的三大优势是什么?
   > 训练可并行(整段序列一步上 GPU)、长上下文扩展性更好(如今可达百万 token 级)、能直接访问上下文中全部历史 token 而 RNN 只能压缩进 hidden state。
2. 讲者提出的幻觉统一定义由哪三个组件构成?
   > 幻觉=世界建模错误，由参考世界模型(定义何为真:文档/数据库/真实世界)、模型视角 view(模型实际能看到什么)、冲突策略(信息源冲突时以谁为准)三要素共同决定。
3. RAG scaling 的关键发现是什么?
   > 预训练不足的模型根本用不好 RAG，交叉点约在每参数 4 个预训练 token；小模型从 RAG 获益大，大模型充分预训练后对通用 web 检索增益趋零(领域专属文档另当别论)。
4. Baby scale 项目(单个儿童语料训练 LM)的核心结论?
   > 儿童级小语料训练可行但高度依赖任务(语法好于世界知识)，小尺度下数据质量(语义多样性、对话数量、分布散度)比数量更重要，且家庭间差异显著。
5. CGLS 是什么?有什么意外结果?
   > Curriculum Guided Layer Scaling：小模型+简单数据起步、训练中逐层加深并同步提升数据难度；124M/1B 尺度上推理任务胜过随机训练，但 1B 尺度困惑率反而劣于随机基线。
6. 双语"融合假说"(fusion hypothesis)在小语言模型上验证结果如何?
   > 不成立：英西各半混训困惑度与英文基线持平甚至略低，暴露结构(谁说哪种语言、句级/词级 code-switching)无关紧要，数据规模比模型规模更关键。
7. ViT 为什么切 patch 而非逐像素?与 CNN 的根本差异?
   > 逐像素 token 数太大太贵(28×28 小图也近千 token)；CNN 带局部性归纳偏置适合小数据，Transformer 几乎无先验、假设更少，大数据上学得更好。
8. JEPA 与 SSM 各自的核心思想是什么?
   > JEPA(LeCun)预测潜在表征而非原始 token，避开低层噪声、更数据高效、更接近人类学习；SSM 以连续状态更新维护压缩内部状态，线性时间复杂度，代表架构是 Mamba。
