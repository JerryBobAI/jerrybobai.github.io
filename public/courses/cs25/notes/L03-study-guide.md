## 一句话概览

本讲的中心论点：SSM/线性模型与 Transformer 的真正分歧不在效率(效率论证是"红鲱鱼")，而在自回归状态的定义——注意力像缓存一切的"数据库"(KV cache)，SSM 像固定尺寸压缩的"大脑"，由此镜像地推出"精确检索/回查"与"在线、压缩、构建抽象"两类能力的取舍。讲者以 MambaByte(字节级语言建模约 2 倍数据效率)、DNA 建模(约 3 倍)与 H-Net(端到端动态分块、可多层嵌套)证明：Transformer 只在数据已被正确编码(tokenizer/patch 化)时最强，一旦直接面对字节、DNA 等未编码数据，SSM 的压缩归纳偏置就根本性占优。这些线性层已进入 Hunyuan、Qwen、Nemotron 等生产级混合大模型，混合层比稳定在线性：注意力约 3:1 至 10:1。

## 分节要点(带时间锚点)

### 一、开场：次二次架构浪潮与生产落地

- 过去两三年"次二次/线性"替代架构大爆发：Mamba(带火了后续整条线)及其续作 Mamba 2、一个月前刚发布的 Mamba 3；精炼老 LSTM 的 xLSTM(LSTM 是 Transformer 之前最主流的循环模型)；DeltaNet 及其与 Mamba 2 结合的 Gated DeltaNet；把递归视为测试时优化的 Test-Time Training(TTT) ([0:01])
- 线性层已进入生产级大模型：混合架构 Jamba(AI21)、Zamba(Zyphra)、Samba(微软)；腾讯 Hunyuan 数百亿~千亿参数；最新 Qwen 基于 Gated DeltaNet；Kimi-Linear；AI2 新发布的 Olmo 混合版；NVIDIA Nemotron 3(同样数百亿~千亿级)用 Mamba 2——这类模型早已不是论文玩具 ([0:03])
- 命名可互换：state-space models、linear attention、(modern) recurrent models、linear RNN、linear models 如今泛指这一族；hybrid 指线性层与二次注意力层交错；本讲不纠缠单个模型的细节，而是拉远聚焦它们与注意力之间的高层取舍 ([0:04])

### 二、两种推理形态：缓存一切 vs 压缩成状态

- 本讲聚焦自回归建模(next-token prediction)的两个理由：它是当下最重要的建模范式(尤其语言)；它也是理解各序列模型取舍的最佳透镜 ([0:05])
- 注意力的推理画像：预测下一 token 时，与上下文中每个历史 token 做两两比较——因此必须缓存每个 token；KV cache 只是 Transformer 定义方式的产物，更高层的概括是"Transformer 就是一个存储缓存的模型"，这一存储决定了它的计算特性：内存与计算随上下文规模增长，摊销到整段生成后计算按二次方增长，这就是"二次方模型"的来历 ([0:07])
- SSM 的推理画像：token 流入时不再显式存储，而是全部压进一个固定状态(讲者画成一颗蓝球)，原始 token 随即丢弃、模型只通过状态与数据交互；每步推理常数时间、整段序列线性时间——这就是"线性模型"的来历，也是两族模型的本质分野 ([0:08])

### 三、现代 SSM 的三大要素

- SSM 的定义：一类特殊的线性递推——标量输入 x 经向量 B 升维后并入隐藏状态的变换；与老 RNN 的两点不同：递推之后不施加非线性(异于 GRU/LSTM)，且隐藏状态规模远大于老 RNN ([0:09])
- 要素一"大状态"：一维输入对应 N 维状态(N 通常 64~128,约为输入的一百倍)；自回归状态是上下文的压缩瓶颈——上下文全部被压进状态里，状态越大能记住的越多，这对语言这类信息密集模态至关重要 ([0:10])
- 要素二"选择性(selectivity)"：把递推参数定义成输入自身的函数(Mamba 相对老 SSM 与 LSTM 的关键差异)——模型看着输入来控制递推：想忽略新输入就令 A=1、B=0(保旧态、不写入)，想覆盖旧上下文就令 A=0；状态更新函数的表达力因此大增 (讲者现场口误先说反了 A/B,随即自行纠正) ([0:11])
- 要素三"高效计算"：前两个要素让模型表达力暴涨，也导致按递推逐步计算训练基本不可行——这条线的核心技术工作是重写计算：初代 Mamba 用 associative scan(利用递推的线性结构并行化)，Mamba 2 与 Gated DeltaNet 等则完全改写为分块矩阵乘法(chunked matrix multiplication) ([0:13])
- 三要素单独看都有先例(2020 年的线性注意力已有状态扩张、经典 RNN 本就是门控式选择性、老线性 RNN 已追求高效计算)，Mamba 是首个把三者合一的模型，也首次证明循环模型在困惑度这类粗粒度指标上能与 Transformer 抗衡；当下最被验证的两个变体是 Mamba 2 与 Gated DeltaNet(GDN 略强但略慢，按需选择，两者也是大规模混合模型最常用的)，Mamba 3 刚发布、大规模检验还需时间 ([0:15])

### 四、自回归状态：数据库 vs 大脑

- 中心论点：序列模型的取舍可以通过它们的"自回归状态"(autoregressive state)来理解——即生成过程中步与步之间驻留在内存里的东西：SSM 是固定尺寸的矩阵状态，注意力是 KV cache；状态的定义决定了模型的取舍与归纳偏置 ([0:16])
- 类比一：Transformer 像数据库——为见过的每个 token 存一份表示，序列越长数据库越大，且能对库中任意元素精确回查 ([0:17])
- 类比二：SSM 像大脑——固定尺寸，把见过的一切压缩进状态；由此得到长板 statefulness：天生适合在线场景，以恒定速率消费信息、实时与世界交互(和大脑一样永远在线)；压缩还带来一些微妙的好处(本讲后面的 H-Net 实验会回应这一点) ([0:18])
- 由类比推出的短板与混合架构：固定状态缺乏细粒度回忆/检索能力，needle-in-a-haystack、associative recall 这类"从上下文里挖出精确信息"的合成任务吃力——人脑同样记不住精确的数字串；而人类智能=大脑处理单元+外部工具(草稿本、数据库)的组合，这一类比直接启发混合模型；多个组独立消融出惊人一致的层配比：早期约 10:1(SSM:注意力)，当下至少 3:1~4:1——且这是纯性能角度(与效率无关)就想要的配比，引出"压缩对智能是否根本重要"之问 ([0:21])

### 五、Transformer 的边界：数据须在正确的抽象层级

- "Transformer 喂啥都行"大体成立但有细节：注意力在数据处于合适抽象层级时才最有效；实用管线里都有相当可观的 encoder 步骤把数据变成适合注意力的形式——视觉里 ViT 把图像切成 patch(vision tokens)再编码，语言里这一步叫 tokenizer；这一步不仅关乎效率，更决定 Transformer 能捕捉哪些特征与变换 ([0:23])
- tokenizer 声名不佳但多数人不当真：Karpathy 推文列举过一串 edge case(拼写、提示结尾空格等)，大多可用好数据与工程技巧绕开；但若能消灭 tokenizer，这些修复就白赚；而且哲学上值得做——AI 的本义是从原始数据自动学习、越端到端越好，更通用、更少特征工程的模型更能吃到大模型规模的收益，这正是 bitter lesson ([0:26])
- 实证一 MambaByte：不用 BPE、直接字节级语言建模，同尺寸同数据的 Mamba 大幅优于滑动窗口注意力，数据效率差约 2 倍；即便换成全局注意力、因字节序列太长而多花 2 倍算力，仍比 Mamba 略差——这是同模型尺寸、同数据、同序列长度下的本质差距，而非"注意力跑得慢" ([0:28])
- 实证二 DNA：Mamba 论文里对 DNA 碱基序列做自回归建模，匹配参数或匹配算力后 Mamba 的效率约 3 倍——在没有 tokenizer 的设定里，架构差距同样显著；这类现象也出现在其他非语言/替代词表数据上 ([0:29])

### 六、H-Net(上)：从"为何如此"到模型内动态分块

- 启发式解释：其一，数据有噪声/冗余 token 时，为每个 token 花缓存与算力不划算——读英文时抹掉不少字符仍能认出单词，并非每个 token 都有意义；其二，softmax 注意力可视为 hard attention(一次只看一个 token)的软化，注意力在"盯单个单元有意义"的数据上才强——人读文字注意的从来是词或更粗的语义层，单个字符、单个 DNA 碱基没有语义；视觉 patch 介于两可(有的信息密集、有的只是一片天空)，所以该领域的取舍不那么清晰 ([0:30])
- 佐证：Mamba 论文发布后不久的引用分布里，语言应用只占约 10%——它实际被当作通用序列模型，大量用于时间序列、音频、尤其视觉；没有良定义 tokenizer 的领域，隐式压缩型模型相对更占优 ([0:33])
- H-Net 登场：Albert Gu 组的近期工作(主要由学生 Hwang 完成，文字稿中名字被消音标注)，端到端层级网络(hierarchical network)，直接吃原始数据，靠数据依赖的分块(data-dependent chunking)在模型内部隐式完成"tokenize"；本质上是一个关于压缩的通用神经网络架构 ([0:34])
- 与 BPE 对照：BPE(byte-pair encoding)是离线的启发式合并规则，把字符攒成 token；H-Net 只见原始字节(词表约 256)，边界预测发生在模型内部；训练可视化显示模型初期大量探索，随后稳定到与空格高度吻合的边界，还能找出语义有意义的子词以及跨词的语义词组 ([0:36])
- 架构：字节序列 → 轻量 encoder → 路由机制逐位置预测"是否为块边界" → 被判为块的段落各自压缩成一个表示 → 主网络(默认用 Transformer——它在词/token 上久经考验;也可以是另一个 H-Net,从而多层嵌套)→ decoder 展开回原始分辨率做自回归预测；粗看与"tokenizer+Transformer"管线同构，只是 tokenize 搬进了模型内部 ([0:38])

### 七、H-Net(下)：标度行为与压缩归纳偏置的证据

- 关键工程事实：凡接触字节级数据的外层 stage 强烈受益于用 SSM(呼应字符级实验里 SSM 的优势)；分块是离散优化问题、训练不稳定且难做，但调通之后可以训出完全免 tokenizer 的模型，scaling 表现合理，并能超过标准 tokenize 管线 ([0:40])
- 标度行为：固定模型尺寸下单阶段 H-Net 起初逊于 Transformer 基线(黑线)，数据足够后交叉反超且 scaling 更好——特征工程本质是归纳偏置，数据受限时占便宜、吃规模红利少(bitter lesson 的又一实例)；嵌套两级分块的 H-Net scaling 更好(代价是参数更多、训练更难) ([0:42])
- BPE 对照实验：把 H-Net 直接跑在 BPE token 上，会先吃到 BPE 的"免费红利"；但字节输入+多加一级分块的 H-Net 最终学到优于 BPE 的特征——规律是：任何设定下 BPE 模型都不错，但只要能扔掉 BPE、端到端学分块，模型就会更好 ([0:43])
- 关键消融：单阶段 H-Net 全程跑在 BPE token 上、只改 encoder/decoder 的层型——纯 Transformer 外层明显更差，encoder/decoder 换入 Mamba 层即大幅变好，且各配置算力匹配；原本预期外层只见 BPE token、放 Transformer 应无妨甚至更好，事实相反 ([0:44])
- 教训：SSM 的收益不止于"看的是低分辨率数据"，更在于一种面向压缩的隐式归纳偏置——有限尺寸状态不只是效率手段，而是根本不同的归纳偏置；这是迄今关于"有限状态不只是为了效率"的最好证据；压缩与"创造抽象"(字符→词→有意义的短语)根本相关，而创造更好的抽象正是分块的目标 ([0:45])

### 八、总结与 Q&A：效率是红鲱鱼

- 主论点与 DNA 标度律：对 DNA 做正式 scaling law(每个点是一个 flop 预算，扫模型大小与数据量)，H-Net 一系呈惊人的线性趋势；与语言不同——语言里不同架构的标度线通常只是平移(恒定幅度改进)，DNA 上 H-Net 发现了现成 tokenizer 找不到的模式、根本性更优地 scaling(语义 tokenizer 在 DNA 上很难定义，替代架构的差距比语言更大)；由此收束主论点——Transformer 极强，但前提是数据已被正确编码；数据未编码或难以编码时需要不同的模型，建模的未来不会只有 Transformer，架构设计仍有巨大改进空间 ([0:49])
- 总结 SSM 侧：流行印象是"更高效但可能更弱"的替代品；效率是个红鲱鱼(red herring)——SSM 在做不同的建模：stateful + compressive，由此带来状态跟踪(state tracking,本讲未展开)、构建抽象(H-Net 所示)等不同类型的收益；其优缺点是一体两面，都源自大脑式自回归状态的定义 ([0:50])
- 总结 attention 侧：强项是对上下文特定细节的关注、出色的 recall/retrieval(恰是 SSM 吃力处)；短板并非二次方效率，而是高度依赖数据的分辨率与语义——分辨率从 BPE 换成字节，表现剧变，"被给定的 token 绑架"(beholden to the tokens)，它无权改变 token 对自己的含义；架构设计的图景是"黑箱把算力与数据转化为智能"，中心问题只有一个：我的模型是否用好了每一个 flop ([0:53])
- Q&A(上)：backprop 之问(Chris Ré 组博士生;文字稿转写作 Chris Ray)——大脑不可能保留多份副本做 BPTT，必有别的求解器?Gu：我们很可能处在整个训练设定(从架构到 backprop)的局部最优；backprop 对长程依赖施加物理内存约束——序列装不进内存就学不到相应依赖；为在 GPU 上高效而牺牲的真递归(true recurrence)表达力值得找回，彻底重想象约束可能带来根本更好的模型；chunking 之问——分块是长期看极关键的原语，本工作只是第一步、不是终点，尚未在大规模验证 ([0:58])
- Q&A(下)：H-Net 机制——越过首层编码后没有任何查找表，块表示就是对 chunk 的池化(直接复制或 pool)，全部在 embedding 空间进行；大脑类比只是粗略的概念证明(分块概念直接源自认知心理学)；可探索把长上下文迭代压缩成高层"记忆摘要"供内层模型注意——长上下文建模的潜在用例；微型模型——OpenAI parameter golf 挑战里有人训 Mamba 3 base 成绩不错，但其消融显示极小模型掺一点注意力仍很关键；可解释性——SSM 与线性注意力有深层对应，可画类注意力图：attention 有时像 hard attention 锐利聚焦，SSM 则总是弥散地把一切挤压在一起 ([1:04:00])

## 核心概念速查

| 术语 | 一句话解释 |
| --- | --- |
| SSM/线性模型家族 | 用固定尺寸状态压缩历史的线性递推序列模型；SSM、线性注意力、(现代)循环模型、linear RNN、linear models 等称呼如今基本同义 |
| KV cache | 注意力为逐 token 两两比较而缓存全部历史表示的状态；内存与计算随上下文增长，摊销后计算二次方——"二次方模型"的根源 |
| 自回归状态(autoregressive state) | 生成步与步之间驻留内存的全部信息：SSM=固定矩阵，注意力=KV cache；决定模型的取舍与归纳偏置 |
| 选择性(selectivity) | 递推参数定义为输入自身的函数，模型按内容决定记什么、忘什么；Mamba 区别于老 SSM/LSTM 的关键要素 |
| associative scan | 利用递推线性结构把训练计算并行化的扫描算法(初代 Mamba)；Mamba 2/Gated DeltaNet 改用分块矩阵乘法 |
| 混合模型(hybrid) | 线性层与二次注意力层交错；多个组独立消融一致给出线性：注意力约 10:1，当下至少 3:1~4:1 |
| hard attention | 一次只看单个 token 的理想化注意；softmax 注意力是其软化，由此可启发式界定注意力的适用数据 |
| H-Net | 端到端层级网络：路由机制在模型内部预测字节序列的块边界并压缩成表示，主模型可嵌套另一个 H-Net 实现多级分块 |
| 动态分块(dynamic chunking) | H-Net 的核心思想：数据依赖地把细粒度数据压成更高层语义单元；与 BPE 不同，它端到端可学习、可多级组合 |
| bitter lesson | 更通用、更少特征工程的模型更能吃到大模型规模的收益；H-Net 对 BPE 管线的交叉反超是其又一实例 |

## 自测题

1. 为什么说"效率差异"是理解 SSM 与 Transformer 取舍时的红鲱鱼?
   > 两者本质是不同的建模方式：SSM 是 stateful+compressive(擅长在线、状态跟踪、构建抽象)，注意力强在精确 recall/retrieval；真正的取舍源自各自自回归状态(大脑态 vs 数据库态)的定义，而非快慢本身
2. 现代 SSM 相比老 RNN 的三大要素是什么?
   > 更大的状态(一维输入配 64~128 维状态，约百倍于输入)、输入相关的选择性参数(selectivity)、让训练可行的高效计算重写(associative scan / 分块矩阵乘法)；Mamba 首次把三者合一
3. "Transformer 像数据库、SSM 像大脑"的类比推出哪些可验证的行为差异?
   > 数据库可精确回查任意历史元素→注意力擅长检索/associative recall；大脑固定压缩、记不住精确字符串→SSM 检索弱但永远在线、恒定速率；人类智能=大脑+外部工具，对应混合模型及线性：注意力约 3:1~10:1 的层比
4. MambaByte 实验说明了什么?为什么说它排除了"只是注意力慢"的解释?
   > 字节级建模中同尺寸同数据的 Mamba 数据效率约 2 倍于滑动窗口注意力，且全局注意力多花 2 倍算力仍更差——同模型尺寸、同数据、同序列长度下仍有本质差距，故是建模本质而非速度
5. 为什么注意力在字符级与 DNA 数据上表现差?给出两条启发式。
   > 其一，数据含噪声/冗余 token 时缓存每个 token 不划算，并非每个 token 都有意义；其二，softmax 注意力是 hard attention 的软化，擅长"一次盯一个有语义单元"的数据，而单个字符/DNA 碱基没有语义
6. H-Net 如何在模型内部实现"tokenize"?
   > 字节过轻量 encoder 后，路由机制逐位置预测块边界，每块压缩成一个表示送入主模型(默认 Transformer,可嵌套另一个 H-Net)，decoder 再展开回字节分辨率做自回归预测；越过首层编码后没有任何查找表
7. H-Net 在 BPE token 上更换 encoder/decoder 层型的消融为何关键?
   > 纯 Transformer 外层明显更差、换 Mamba 层大幅变好且算力匹配——说明 SSM 的收益不止于低分辨率数据，而在面向压缩的隐式归纳偏置，是"有限状态不只是效率手段"的最佳证据
8. DNA 上的标度律与语言标度律有何质的不同?
   > 语言中不同架构的标度线通常只是平移(恒定幅度改进)；DNA 上 H-Net 发现现成 tokenizer 找不到的模式，标度呈线性且根本性更优——因为 DNA 难以定义语义 tokenizer，免编码架构优势被放大
