# L03 · Identity Mappings — 何恺明解剖自己的 ResNet

《Identity Mappings in Deep Residual Networks》(2016, ECCV) · 何恺明， Xiangyu Zhang, Shaoqing Ren, Jian Sun · [arXiv:1603.05027](https://arxiv.org/abs/1603.05027)

## 1. 一句话

ResNet 作者团队的自我追问：**跳连为什么真的有效？** 通过把网络递归展开 + 一组教科书级的消融实验，他们证明了答案——**跳连的力量来自一条「无任何阻碍的信息高速公路」**，任何挡在路上的东西（投影、ReLU、缩放、dropout）都会收费。由此改进出的 pre-activation 结构（ResNet v2），就是今天 Transformer 里 `Pre-LN + 干净残差通路` 的直系祖先。

## 2. 它之前的世界：一个有效但说不清的黑盒

2015 年 ResNet 发表后，一个问题悬在半空：**跳连为什么有效？** 当时的主流解释有两种，互相打架：

**解释 A（梯度视角）**：跳连让梯度有无损回传通道（上一篇讲的 `+1`）。

**解释 B（集成视角）**：Veit et al. (2015) 提出，ResNet 行为上像**大量浅网络的集成**——每条跳连创造一条路径，n 个 block 有 2ⁿ 条路径，有效深度其实很浅。他们的证据：删掉训练好的 ResNet 的个别层，性能只轻微下降。

如果解释 B 是对的，那跳连的「任意两点直通」性质就不是关键，**路径多样性**才是——这会导致完全不同的后续架构方向。

何恺明团队的回应方式不是打嘴仗，而是做实验：**systematically 把跳连的各种性质逐一破坏，看哪种破坏致命**。这篇论文也是一份方法论教材——如何解剖一个「有效但说不清」的黑盒。

## 3. 核心思想

### 3.1 分析工具：把网络递归展开

先把一个残差 block 写成通用形式：

```
y_l = h(x_l) + F(x_l, W_l)     ← h 是跳连上的变换，F 是旁路卷积
x_{l+1} = f(y_l)               ← f 是加法之后的操作（v1 里是 ReLU）
```

原版 ResNet（v1）里 `h(x) = x`（恒等），`f = ReLU`。关键一步：**如果 h 和 f 都是恒等映射**（h 什么都不做、加法之后也什么都不做），把 L 个 block 层层代入展开，会得到一个极美的式子：

```
x_L = x_l + Σᵢ F(xᵢ, Wᵢ)
```

读一遍这个式子，两边各有一个深刻含义：

**前向（信号怎么流）**：任意深层的位置 `x_L` = 浅层原信号 `x_l` **原封不动地保留** + 一路累积的所有增量。用 git 类比：**最终代码 = 初始 commit + 全部增量 patch 的叠加**。初始状态永远在场，从未被覆盖——这就是「深网络至少不比浅网络差」的数学形态。

**反向（梯度怎么流）**：对上式求导：

```
∂loss/∂x_l = ∂loss/∂x_L · (1 + ∂ΣF/∂x_l)
```

那个 **`1`** 又出现了——梯度从任何深层直接、无衰减地通向任何浅层，求和项只是「额外改道选项」。上一篇说的「高速公路」，在这里有了精确的数学表述。

于是论文的中心假设成型：**ResNet 的有效性来自这个展开式成立，而展开式成立的前提是 h 和 f 都是恒等映射。任何偏离恒等的操作，都在污染这条通路。**

### 3.2 消融：给高速公路设置各种「收费站」，看哪个致命

这是全篇最漂亮的部分。他们只改跳连上的 `h(x)`，其余全部不动，在 CIFAR-10（164 层）和 ImageNet（152 层）上对比：

| 变体 | h(x) 是什么 | 效果 |
|---|---|---|
| (a) 原版 | `h(x) = x` 恒等 | 基线，最好 |
| (b) 常数缩放 | `h(x) = 0.5x` | 掉点 |
| (c) 门控 | `h(x) = g(x)·x`（g 可学习） | 掉点 |
| (d) 1×1 卷积投影 | `h(x) = W·x` | 浅层影响小，**深层严重掉点** |
| (e) dropout | 恒等 + 随机失活 | 掉点 |
| (f) 无跳连 | `h(x) = 0` | 崩溃（退化回 plain 网络） |

共同规律：**只要 h 不是恒等，就掉点**。最值得注意的是 (d)：1×1 投影在 34 层网络里几乎无害（上一篇的消融也看到了这点），但在 **164 层 CIFAR 上错误率从 5.46% 翻倍到 11.76%**——深度放大了「收费站」的伤害。类比：高速路上设一个收费站，短途感觉不到，长途（深网络）就堵死了。

(d) 的门控变体 (c) 尤其有说服力：哪怕让网络**自己学**一个门控系数、理论上它完全可以学会「全开」，性能依然更差——说明问题不是「变换学不好」，而是**「存在变换本身」就成了阻碍**。这直接反驳了集成解释的预测，支持「通路解释」。

结论一句话：**keep a clean information path——高速公路上不能有任何收费站。**

### 3.3 f 的问题：ReLU 站错了位置

消融同样指向 `f`（加法之后的操作）。v1 的结构是：

```
v1: conv → BN → ReLU → conv → BN → (+x) → ReLU ← 问题在这
```

加法刚完成，ReLU 立刻把结果「削一下」（负值归零）——信号每过一个 block 都被迫非负，`x_l` 的原样传递被反复打断。展开式的成立条件被 `f ≠ identity` 破坏了。

**v2（pre-activation）的改法**：把 BN + ReLU 全部挪到卷积**之前**，加法之后什么都不放：

```
v2: (BN → ReLU → conv) → (BN → ReLU → conv) → (+x) → 直接交给下一个 block
```

注意妙处：BN/ReLU 没有消失，它们变成了**旁路 F 的预处理**——「先洗洗手再来改代码」，而主干道彻底无阻碍。这样 `h = f = identity` 严格成立，展开式 `x_L = x_l + ΣF` 逐字为真。

### 3.4 结果：更深的网络终于「越深越好」

- CIFAR-10：v2 在 164 层 5.46% → 5.04%，200 层继续降，**1001 层训练误差依然单调下降**（v1 在这个深度已经开始劣化）
- ImageNet 152 层：v2 单模型 top-5 验证错误 **4.92%**（v1 是 5.71%）
- 不换数据、不换任务、不动优化器——**只重排了 ReLU 和加法的相对位置**，性能就提升一截。架构研究的杠杆率可见一斑

## 4. 为什么在这份 List 里

1. **它把「让梯度/信号活下去」从工程直觉升格为第一性原理**：残差通路上不能有任何东西。这条原则此后成为架构设计的铁律——现在打开任何一个 GPT 的代码，每个 block 都是 `x = x + Sublayer(LN(x))`，加法之后空无一物，Norm 在子层之前。**GPT 的 Pre-LN 结构就是本文 v2 的直系应用**。可以说：读不懂这篇，就看不懂 Transformer 结构图里那些「为什么 Norm 在那、为什么加法后什么都没有」
2. **方法论示范**：面对「有效但说不清」的黑盒，正确的解剖姿势是——数学分析给出假设（展开式）、控制变量消融验证（h 的六种变体）、极端条件压力测试（1001 层）。这套组合拳比结论本身更值钱
3. Ilya 把它**单独**列进 List 而不是当作 ResNet 的附注——这份 List 要的是机理理解，不是结论背诵。Transformer 时代的人如果只读过 ResNet 原文，会以为 post-activation 无所谓；读过这篇才知道 Pre-LN 从哪来

**Q1：把残差网络递归展开得到的式子是什么？它对前向和反向各说了什么？**
