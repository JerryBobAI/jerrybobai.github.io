# L16 · Relational RNN — 记忆不是一条向量，是一张实体关系图

《Relational Recurrent Neural Networks》(2018, NeurIPS) · Adam Santoro, Ryan Faulkner, David Raposo, Jack Rae 等 10 人 · DeepMind · [arXiv:1806.01822](https://arxiv.org/abs/1806.01822)

## 1. 一句话

L15 的关系模块从「空间里的物体」搬进「时间里的记忆」：**关系记忆核 `RMC`(Relational Memory Core)把 LSTM 那条不断被覆写的单一隐向量，换成 M 个 slot 组成的记忆矩阵，每一步让 slot 之间跑一轮多头自注意力互相通气，再各自走 LSTM 式门控更新**。记忆从此是一张可以随时互查的实体关系图，不是一条胶卷——跨时间关系推理的任务上，它把卡在 30% 以下的 LSTM 拉到 91%。

## 2. 它之前的世界：一条被覆写的胶卷，和一排不串门的保险柜

LSTM(→ L07)的记忆是**一个**隐向量/细胞状态向量。每来一步新输入，门控决定写多少、留多少——但所有信息挤在同一个向量里，新覆旧、互相干扰。想记住「第 3 步的钥匙颜色」和「第 7 步的锁位置」再比较?它们在同一根胶卷上早已互相叠写。论文原话：LSTM 把所有信息打包进一个公共记忆向量，**分区存放(compartmentalization)先天不足**。

反方向也病着。记忆增强网络(→ L14 NTM、`DNC`)把记忆做成 slot 矩阵——一排保险柜，分区没问题；但柜子之间**不交流**，各存各的。关系推理的起点恰恰是「我记的 A 和我记的 B 有什么关系」。两头各缺一半：**LSTM 有交互无分区，NTM/DNC 有分区无交互**。

还有一个洞：注意力(→ L10 Bahdanau)能回看历史，但那是「检索」，不是「让已记住的内容彼此连线」。

## 3. 核心思想

### 3.1 记忆矩阵 + slot 之间跑注意力

RMC 的记忆是矩阵 M：N 个 slot(行)，每行 F 维。每一步，slot 之间先跑一轮**多头点积自注意力**(`MHDPA`,就是 → L12 Transformer 那套)：

```
A_θ(M) = softmax( M·W_q · (M·W_k)ᵀ / √d_k ) · M·W_v
```

类比开例会：每个 slot 拿自己的内容当 Query 问一圈，其他 slot 当 Key/Value，按相关度把别人的信息按比例抄回来。三个关键设定：

- 注意力发生在**同一时间步的记忆之间**，不是跨全部历史 token——历史已压缩进 slot，注意力在压缩后的状态上跑
- **多头**：不同 head 用不同投影——slot 可对不同对象传不同信息；行切 slot、列切 head，两层分区
- 输出 M̃ 与 M 同形状，是「提议更新」，不是最终记忆

### 3.2 新信息怎么进来：把 x 拼进队伍再开会

写入和交互用**同一个注意力**搞定：

```
M̃ = softmax( M·W_q · ([M; x]·W_k)ᵀ / √d_k ) · [M; x]·W_v
```

把新观察 x 拼进 [M; x] 一起参与注意：Query 只来自旧 slot，Key/Value 来自旧 slot 加新输入——slot 数不变(记忆尺寸守恒)，新信息按相关度被「吸」进各 slot。同一套机制既管互通又管写入，没有一个多余的零件。

### 3.3 门控更新：每个 slot 走一遍 LSTM

拿到提议更新 M̃ 后，每个 slot 独立走标准 LSTM 式门控(→ L07)：

```
m_{i,t} = σ(f_{i,t} + b̃_f) ∘ m_{i,t-1}  +  σ(i_{i,t}) ∘ g_ψ(m̃_{i,t})
          └── 遗忘门保旧 ──┘      └── 输入门写新(新内容先过 g_ψ 处理)┘
```

还是「让梯度活下去」的老配方：加法更新 + 门控，长程梯度畅通。论文还试了按 slot 整行开关的 memory gating——「逐单元微调」之外多了「整条记忆启停」的粒度。

最漂亮的一点：**所有 slot 共享同一套参数**——加 slot 数不加参数。于是「容量 = slot 数 × slot 维度」和「参数量 ∝ 单 slot 维度」是两个独立旋钮：有的任务要更多但不更大的记忆，语言建模反过来。

```
        x_t(新输入)
           │
           ▼
   [ M_{t-1} ; x_t ] ──多头自注意力──> M̃(slot 间通气 + 摄取新息)
                                          │ g_ψ + 输入门
   M_{t-1} ──────遗忘门──────>  M_t(新记忆)──> 输出 / 下一步
```

## 4. 实验逻辑

- **定制毒物 Nth Farthest**：流式输入 8 个随机向量，最后问「离参考向量 m 第 n 远的是哪个」。难点：必须对**所有两两距离**做隐式排序，而且 m 可能最后才出现——先记好全部，等线索到了再连线。结果：LSTM 和 DNC 的最佳批次准确率都**上不了 30%**，RMC 稳定 **91%**。注意力分析拍到解题姿势：参考向量出现前，输入写进一两个 slot；一出现，**所有 slot 齐刷刷转头盯住那几个 slot**——「等参照物到了再建索引」
- **RL 迷宫(viewport 部分可观测)**:Mini Pacman 只给周围 5×5 视野，幽灵动向和吃过的豆全靠记。RMC 677 分 vs LSTM 550；全观测下 1159 vs 598，近翻倍。更难的 BoxWorld(钥匙-锁-宝石链):RMC 解出 **98%** 关卡，ConvLSTM 只有 **73%**
- **程序执行**(`Learning to Execute`——Zaremba 与 Sutskever 2014 的老题,Ilya 本人合著)：读伪代码，输出执行结果。RMC 全面不输 LSTM/DNC/EntNet，而且去掉 teacher forcing 训练反而更强
- **语言建模**：WikiText-103、Project Gutenberg、GigaWord 三个数据集同时做到当时最好，困惑度(`perplexity`:平均每步在多少个等效候选词里犹豫,越低越好)比已发表最好结果**降 1.4-5.4(相对提升 5-12%)**。彩蛋：这里只用了 **1 个 slot + 4 个头**——分区可发生在 head 里，不必在 slot 里
- 诚实条款：作者明说这些只是「功能证据」——题解得更好，但不能断言内部真在做关系推理

## 5. 为什么在这份 List 里

1. **记忆第一次成为「设计对象」**。从 RNN 到 LSTM 到 NTM，记忆进化是「容量」故事；RMC 把问题换成「记忆的组织方式」——结构先验再次胜过堆容量，和 L15「架构=先验」一脉相承
2. **两条路线在此握手**：RMC 直接把 Transformer 的自注意力借来当记忆管理器——注意力从此不只是序列处理器，还是循环状态内部的组织者。作者里的 Jack Rae 随后把这条线推进成 Compressive Transformer；而「上下文窗口当记忆」的 Transformer 主线，本质是 RMC 的无门控极限版
3. **学习即压缩**：slot 矩阵加注意力，是把无界的历史流压成一张「可随时互查的关系表」——压缩的产物不是摘要，是结构

## 6. 织进网里

- **← L15 关系推理**：同一班底「关系」暗线第二级。RN 是一次前向里的全配对，RMC 是每个时间步都跑一遍的关系模块；物体换成了记忆 slot
- **← L07 LSTM**：RMC 的门控更新原样继承 LSTM；病灶也是它——单一向量无分区、时序覆写
- **← L14 NTM**：记忆增强线的另一支；NTM/DNC 有 slot 无交互，RMC 补上交互这一半
- **↔ L12 Transformer**：MHDPA 借自 Transformer，但用在「同一步的记忆之间」；反过来，Transformer 的上下文窗口可视为「无限 slot、只增不删、无遗忘门」的 RMC——两种记忆观互为镜像
- **→ L20 Scaling Laws**：RMC 精心设计的 slot 与门控，后来被「把窗口拉长 + 规模推大」更粗暴地覆盖——精细结构先验 vs 暴力规模，这张 List 反复出现的张力

## 自测题

1. LSTM 和 DNC 各自的记忆病灶是什么?RMC 补的是哪一块?
   > LSTM 全部信息挤一条向量——有交互无分区，新覆旧；DNC 的 slot 各存各的——有分区无交互；RMC = slot 矩阵 + 每步 slot 间自注意力，分区与交互同时成立。
2. RMC 的注意力发生在什么之间?和 Transformer 的注意力位置差在哪?
   > 同一时间步的 M 个记忆 slot 之间(新输入 x 拼进 [M;x] 一起算)；Transformer 跨全部历史 token——RMC 用注意力管理循环状态，不是用它替代循环。
3. 易混淆：Nth Farthest 难在哪?为什么恰好杀死 LSTM?
   > 要对全部两两距离做隐式排序，参考向量还可能最后才出现；LSTM 单向量装不下 8 个向量及其相互距离、还要等线索到再连线，最佳批次准确率上不了 30%，RMC 91%。
4. 跨篇：RMC 与 L15 的 RN 是什么关系?
   > 同一思想的时序版：slot 间多头注意力是 RN「两两配对推断关系再汇总」的软加权版；RN 作用于空间物体、一次前向，RMC 作用于时间记忆、每步一遍。
5. 方法论：RMC 做语言建模只用 1 个 slot + 4 个头，说明什么?这条线后来为何被规模盖过?
   > 分区可做在 slot 行也可做在 attention 列，结构旋钮是任务相关的；「拉长上下文窗口 + 加大规模」用更粗暴的方式解决同一问题——精细记忆先验被规模摊平(呼应 L20)。
