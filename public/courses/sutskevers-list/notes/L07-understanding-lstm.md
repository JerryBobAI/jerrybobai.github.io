# L07 · Understanding LSTM Networks — 给记忆修一条带闸门的传送带

《Understanding LSTM Networks》（2015, 博客） · Christopher Olah · [colah.github.io/posts/2015-08-Understanding-LSTMs](https://colah.github.io/posts/2015-08-Understanding-LSTMs/)

## 1. 一句话

LSTM 解决 vanilla RNN「记不住长事」的方案，核心只有一个动作：**在每步都被完全重写的隐状态旁边，加一条默认「什么都不做」的 cell state 传送带——更新以加法为主、线性通过，再用三道 sigmoid 门分别控制删什么、写什么、露多少**。记忆从此可以跨几十步存活；「给会衰减的乘法链修一条受控直通道」，正是本课「让梯度活下去」主线在时间维度的落地。

## 2. 它之前的世界：传话游戏传到第 50 手

vanilla RNN 的一步就一行式子：

```
hₜ = tanh(W · [hₜ₋₁, xₜ])      ← 隐状态是唯一的记忆
```

残酷之处在结构里：**每一步，h 都被全新的 tanh 输出完全覆盖**——旧记忆想活，只能靠自己被「复述」进新向量。这就是传话游戏：每过一手重述一遍，没有存档选项。前向：第 1 步的信息传到第 50 步早已面目全非；反向更致命——梯度沿时间链连乘，每步乘一个 tanh 导数（≤1）和一份权重矩阵。打个量级比方：每步衰减到 0.9，50 步后只剩约 0.5%，梯度消失；略大于 1 则爆炸。Hochreiter（1991）和 Bengio 等人（1994）早已把病灶分析透。

你以为是「RNN 记忆容量不够」。其实是「记忆的**写法**不对」——每次全量重写，根本没给「保持不变」留选项。还有个更妙的困惑：理论上 RNN 连图灵完备都做得到（→ L06 的程序观），实践里长依赖怎么就学不会？答案是：**表达能力 ≠ 可学习性**——能表达和能学到，中间隔着一条工程要修的路。

## 3. 核心思想

### 3.1 第一性原理推门控：记忆要活得久，先要一条「默认什么都不做」的通道

想让一段记忆跨 50 步存活，最朴素的需求是：**它有权利什么都不发生**。vanilla RNN 里没有这个选项，每步强制全量重写。LSTM 的解法是把「记忆」拆成两个角色：

```
vanilla:  hₜ = tanh(W·[hₜ₋₁, xₜ])          每步全量重写，旧记忆必被冲刷

LSTM:     cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ c̃ₜ         旧记忆「选择性遗忘」+「选择性写入」
          hₜ = oₜ ⊙ tanh(cₜ)                对外暴露多少，另设一道门
```

`c`（cell state，单元状态）是传送带——Olah 原文的比喻：它沿整条时间链直通，**只经历少量线性操作**（乘一个 0~1 的门、加一项候选）。信息想待着不动，令 fₜ≈1、iₜ≈0 即可，一步都不受损。

你应该立刻认出这个结构：**cₜ = fₜ⊙cₜ₋₁ + iₜ⊙c̃ₜ 和 ResNet 的 y = x + F(x) 同构**（→ L02 残差的「+1 直通通道」）。f≈1 时传送带就是恒等映射，梯度沿它回传时每步只乘一个约等于 1 的数，而不是乘一整个 tanh 导数矩阵。ReLU 救的是空间深度（层间），LSTM 救的是时间深度（步间），同一个工程第一性。

### 3.2 三道门：删除权、写入权、暴露权

所有的门都是同一个零件：一层 sigmoid（输出 0~1，可理解为逐维的音量旋钮 / 软开关），乘到信号上就是「按比例放行」。三道门，三种权限：

- **遗忘门 fₜ（该删哪段记忆）**：读 [hₜ₋₁, xₜ]，给旧记忆 cₜ₋₁ 的每一维打一个 0~1 的保留系数。例：语言模型记着「旧主语是单数」，一读到新主语，这一维就调向 0
- **输入门 iₜ + 候选 c̃ₜ（该写什么）**：c̃ₜ = tanh(...) 是「想写进去的新内容」（−1~1 的值），iₜ 决定每一维写入的比例。为什么要拆两条？**「要不要写」和「写什么值」是两个独立自由度**——iₜ 用 sigmoid 出比例，c̃ₜ 用 tanh 出内容，混成一条就少了一个表达维度
- **输出门 oₜ（该暴露多少）**：c 里存着的东西不等于此刻要用。hₜ = oₜ⊙tanh(cₜ) 决定哪些维度当下对下游可见。工程类比：进程内存里的数据，不等于都写进了日志

### 3.3 逐行读一个时间步

把 Olah 的六步走查压成代码。情景：模型读到「小张」接替「老李」当了主语——

```python
# 四道门共用同一份输入 [h_prev, x]，各自一套权重矩阵
f     = sigmoid(Wf @ concat(h_prev, x) + bf)   # 1. 遗忘门：「老李」那一维记忆 → 调低
i     = sigmoid(Wi @ concat(h_prev, x) + bi)   # 2. 输入门：为「小张」开写入通道
c_new = tanh(Wc @ concat(h_prev, x) + bc)      # 3. 候选内容：新主语的性别、单复数（−1~1）
c     = f * c_prev + i * c_new                 # 4. 传送带：选择性遗忘 + 选择性写入
o     = sigmoid(Wo @ concat(h_prev, x) + bo)   # 5. 输出门：这一步要不要用主语信息
h     = o * tanh(c)                            # 6. 工作记忆：只暴露相关维度给下游
```

逐行的看点在第 4 行——全部秘密：新信息是**加**上去的，不是拿新向量替换旧向量；门只做受控删改。第 5、6 行是 `h` 与 `c` 的分工：`c` 长期记忆（传送带，直通下一步），`h` 工作记忆（本步输出 + 下一时刻门控的输入）。管线图：

```
     遗忘门 fₜ                输入门 iₜ
        │                        │
 cₜ₋₁ ──[×]──┐        c̃ₜ ──[×]──┐
             └─────── ⊕ ─────────┘──→ cₜ ──→ 传给下一步（传送带直通）
                    加法：写入，而非替换
                                  │
                            tanh ──[×] oₜ（输出门）──→ hₜ
```

### 3.4 变体：一段话带过

门控框架定型后微调很多，Olah 文末清单有三类：**peephole 连接**（Gers & Schmidhuber, 2000——让门也偷看 cell state，从「只看工作和输入」升级为「参考库存」）；**遗忘门与输入门耦合**（不独立决定删和写，直接 fₜ = 1 − iₜ，写入多少就删多少）；**GRU**（Cho et al, 2014——门合并版：update gate zₜ 一肩挑起遗忘与写入，hₜ = (1−zₜ)⊙hₜ₋₁ + zₜ⊙h̃ₜ，且 c 与 h 合并成单一状态，参数更少）。Olah 自己的结论很克制：变体互有胜负，没有普适赢家——重要的是「受控直通通道」这个骨架，不是门的数量。

## 4. 文章怎么展开论证

Olah 这篇是「先直觉、后式子」写作方法论的教科书（与本课撰稿规范同款）：先给传送带比喻和三道门的白话权限表，让读者心里有图纸，再把全部公式集中列出——式子只是类比的精确化，读者在「确认」而非「硬啃」。通篇没有一行梯度推导，vanishing gradient 的解法却已不言自明——直觉图纸里的「线性直通」早把答案画了出来。

论证材料还有两块：

1. **图示系统本身就是论证工具**：黄盒子 = 可学习的神经网络层，圆圈 = 逐点运算，线分叉 = 复制，线合并 = 拼接。这套图例让 LSTM 第一次对非数学背景的人可读——此文此后成为入门 RNN 的事实标准材料，图示的贡献不亚于内容
2. **背景清单提供动机**：写作时点（2015 年 8 月）LSTM 已在语音识别、机器翻译背后挑大梁（Google 语音搜索与翻译 2015 年前后切换到 LSTM）——不是学院玩具，是当时序列任务的统治架构

## 5. 为什么在这份 List 里

1. **「让梯度活下去」主线的序列篇**。L01 的 ReLU 让梯度在层间不衰减，L02 的残差给梯度修了直通道，L07 的 cell state 把同一招搬到时间维——三个案例同一工程第一性：给会连乘衰减的链修一条默认不动的直通通道
2. **门控 = 受控直通通道，是记忆类架构的种子思想**。一旦接受「记忆需要一条可读写的受控通道」，下一步就是把一条传送带升级成一整面记忆墙——→ L14 NTM 用门控读写头操作外挂记忆矩阵，→ L16 关系 RNN 把对记忆的操作程序化
3. **又一次「迟到的爆发」**。LSTM 1997 年由 Hochreiter & Schmidhuber 提出，却要等 2013 年后算力与数据齐备才统治序列任务，2017 年后被 Transformer 接棒——「架构早就在，等的是模型 × 数据 × 算力组合到位」，L01 的剧本重演。表达能力 ≠ 可学习性 ≠ 可部署性，这条时间线值得咀嚼

## 6. 织进网里

- **← L06 Karpathy RNN**：玩具很惊艳，但隐状态每步全量重写、长依赖学不牢——这篇正面开刀，传送带让 Karpathy 的迷你程序终于能「记长事」
- **← L02 ResNet / ← L03 Identity Mappings**：y = x + F(x) 与 cₜ = fₜ⊙cₜ₋₁ + iₜ⊙c̃ₜ 同构；恒等映射让直通道更干净，f≈1 就是时间维的 identity
- **→ L08 RNN 正则化**：LSTM 解决「记不住」，不自动解决「训得稳」——dropout 在循环网络里怎么打才有用，是下一块工程拼图
- **→ L10 Bahdanau Attention**：记忆压力的另一种解法——与其把所有历史压进一个状态向量，不如允许模型回头直接看原文；与门控互补而非替代
- **→ L14 NTM / → L16 关系 RNN**：门控读写从「一条传送带」泛化为「一整面记忆墙 + 读写头」（NTM 外挂记忆）与「记忆上的程序」（关系 RNN）——本篇是这条记忆演化线的起点

## 自测题

1. vanilla RNN 的长依赖病灶，前向和反向各是什么表现？
   > 前向：隐状态每步被全量重写，早期信息像传话游戏逐手失真；反向：梯度沿时间链连乘（每步乘 tanh 导数和权重矩阵），几十步后消失或爆炸——所以「理论上能表达长依赖，实践学不到」。
2. 写出 cell state 更新式；f≈1、i≈0 时发生了什么？它与 ResNet 的哪句话同构？
   > cₜ = fₜ⊙cₜ₋₁ + iₜ⊙c̃ₜ；f≈1、i≈0 时旧记忆原样直通、一步不受损，梯度每步只乘约 1 的数——与 ResNet 的 y = x + F(x) 同构，「+1 直通通道」思想在时间维复刻。
3. 输入门 iₜ 和候选 c̃ₜ 为什么是两条式子而不是一条？各自的取值范围与分工是什么？
   > 「要不要写」与「写什么值」是两个独立自由度：iₜ 用 sigmoid 出 0~1 的写入比例，c̃ₜ 用 tanh 出 −1~1 的候选内容；合成一条会丢一个表达维度。
4. GRU 相对 LSTM 砍掉了什么？它的 update gate 怎么把遗忘和写入合成一个动作？
   > 把 c 与 h 合并为单一状态、门从三道减到两道；update gate zₜ 一肩挑：hₜ = (1−zₜ)⊙hₜ₋₁ + zₜ⊙h̃ₜ——写入多少就遗忘多少（互补耦合），参数更少、效果大体相当。
5. LSTM 1997 年就发明，为什么 2015 年前后才爆发？这印证了 List 的哪条世界观、又铺向哪两篇？
   > 表达能力 ≠ 可学习性 ≠ 可部署性：架构早就到位，要等算力与数据齐备门控优势才兑现（模型 × 数据 × 算力 → 涌现的迟到案例）；门控 = 受控直通通道，铺向 L14 NTM 的外挂记忆与 L16 关系 RNN。
