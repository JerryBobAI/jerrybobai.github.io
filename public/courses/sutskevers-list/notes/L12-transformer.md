# L12 · Attention Is All You Need — 一步全局，终结串行时代

《Attention Is All You Need》(2017, NIPS) · Vaswani, Shazeer, Parmar, Uszkoreit, Jones, Gomez, Kaiser, Polosukhin · Google Brain / Google Research 八人团队 · [arXiv:1706.03762](https://arxiv.org/abs/1706.03762)

注意作者栏：这是这份 List 里少数 Ilya 没有参与的重要论文——Google 的八人团队写的。但读完你会发现，它恰好补上了 Ilya 世界观缺的那块地基：此后 GPT 的一切，都从这一篇开始。

## 1. 一句话

Transformer 做的事：**把序列模型里唯一的串行管道——RNN 的递归——整个拆掉，只留自注意力：每个 token（词元，模型处理文本的最小单位）一步看全所有 token**。两 token 间的信息路径从 O(n) 压到 O(1)，训练全程并行，GPU 终于吃得满；BLEU 甩开此前所有 SOTA（含 ensemble，多模型投票），训练成本只有零头。此后的一切——GPT、BERT、Scaling Laws——地基都是这一篇。

## 2. 它之前的世界：RNN 的两宗罪

2017 年机器翻译的最强方案是 seq2seq + 注意力（→ L10）：RNN 编码器逐词读完源句，解码器每步回头翻书。注意力治好了「整句压一个向量」的病，但没人动过底下的 RNN 骨架。这篇论文把 RNN 本身推上被告席，数了两宗罪：

**宗一：串行——时间步不能并行，GPU 吃不满。** RNN 的定义就是 `h_t = f(h_{t-1}, x_t)`：算第 t 步必须先算完第 t−1 步，句内并行从数学上就被禁止。类比：流水线上有一万名工人，工序却规定必须一个人做完再交接给下一个人——典型的负载均衡灾难。GPU 上万个核，大部分只能围观同一个句子的时间步排队。句子越长越致命，加大 batch 也救不了（显存先卡死）。2016 年的 ByteNet、ConvS2S 试图用卷积换掉 RNN：并行性拿到了，但卷积核视野有限，远处的信息要一层一层传话——治了宗一，宗二还在。

**宗二：长程依赖——两 token 间信息路径 O(n)。** 第 1 个词到第 100 个词，信息要走 99 站隐状态，每站一次有损中转。这条 O(n) 的长链，正是 L06/L07 梯度病根、L08 噪声敏感的病根所在——RNN 系的顽疾全都住在这条路上。

当时的直觉是「模型不够强，加数据加算力就行」。论文说：不对，**是架构不让算力进场**。两宗罪同一个根：信息混合必须逐站中转。解法一句话：砍掉中间商。

```
两 token 间的信息路径（论文 Table 1 的核心对比）：
  RNN        O(n)        逐站中转，句内串行    ← 两宗罪俱全
  卷积       O(log n)    逐层传话，句内并行    ← 治了宗一
  自注意力   O(1)        一步直达，句内并行    ← 两宗罪同时消掉
```

## 3. 核心思想：自注意力，加一副现成的骨架

### 3.1 自注意力：每个 token 同时看所有 token

L10 的注意力是解码器回头看编码器：Q 来自解码器，K/V 来自编码器——两边是两个不同的句子。这篇把同一机制搬进句子内部：**每个 token 以自己为查询，向全句所有 token（包括自己）提问「谁和我有关」，所有 token 同时作答，按相关度加权汇总**。自己看自己，所以叫 self-attention（自注意力）。

两个后果直接宣判 RNN 死刑：

1. **信息路径 O(1)**：token i 到 token j 一步直达，不再逐站中转——L06～L08 那一整族病根被连锅端
2. **训练全并行**：所有提问同时发、同时答，整句一次矩阵乘法算完，GPU 的上万核全部有活干

### 3.2 Q/K/V：一次按内容的加权检索

怎么描述「谁和谁有关」？论文给了一个工程上极干净的三角色设计——本质是一次按内容的加权检索：

- **Query（Q）＝我在找什么**：查询词
- **Key（K）＝我有什么标签**：索引
- **Value（V）＝我的实际内容**：正文

每个词向量 x 经过三个投影矩阵，变出三重身份：`q = xW_Q`、`k = xW_K`、`v = xW_V`。匹配度靠**点积**：两个向量方向越一致，点积越大——「sat 在找动作的主语」，「cat 的标签」正好对上，分就高。

```
句子「The cat sat on the mat」，sat 发起查询：

q_sat · k_The = 1  ──softmax──► α = 0.03 ┐
q_sat · k_cat = 4  ───────────► α = 0.64 │ 四个分数过 softmax
q_sat · k_on  = 2  ───────────► α = 0.09 │ 归一成权重（和为 1）
q_sat · k_mat = 3  ───────────► α = 0.24 ┘

输出 sat 的新表示 = 0.03·v_The + 0.64·v_cat + 0.09·v_on + 0.24·v_mat
                    └──── 按相关度调出的一勺「期望笔记」────┘
```

矩阵视角一句话：`Q·Kᵀ` 得到 n×n 打分矩阵（每行是一个 token 对全句的相关度）→ 逐行 softmax → 乘 V。全部 token 一步并行，这就是自注意力的全部。

与 L10 打个对照：那里的打分是小前馈网络（加性注意力，additive attention），这里直接用点积（乘性注意力，dot-product attention）——少了可学的打分网络，更快更简单，效果相当。

### 3.3 缩放：点积为什么要除以 √d_k

点积有个隐藏坑：**维度越大，点积的量级越大**。若 q、k 的各分量独立、均值 0 方差 1，点积是 d_k 项求和，方差随维度线性涨——64 维点积的量级约是 1 维的 8 倍。大输入喂进 softmax 是灾难：输入一大，输出就饱和成 one-hot（一个权重≈1，其余≈0），而饱和点的梯度≈0——L01 里 sigmoid 饱和杀梯度的老病，在 softmax 身上还魂。

解法朴素到不像话：**除以 √d_k**，把点积方差归一回 O(1)，softmax 留在有梯度的工作区：

```
Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V
```

d_k = 64，就除以 8。又是那条贯穿全程的主线：**让梯度活下去**。

### 3.4 multi-head：多组关系子空间并行

单次点积只有**一种相似度标准**，而语言里的关系是多维的：主谓、修饰、指代、语义相近、位置邻近……用一锅 512 维的点积汤去匹配，所有关系搅在一起。论文的解法是通道分组：**把 512 维切成 8 份，每份 64 维各自配一套 Q/K/V，独立做注意力，8 个输出拼接后再线性融合**。

8 个头＝8 个并行的「关系子空间」：每个头在自己的维度子空间里，用一套专属的匹配标准找关系。类比 8 个并行的搜索引擎，各自用自己的打分标准（一个按关键词、一个按语义、一个按作者），最后汇总检索结果。注意这笔账：8 头 × 64 维＝512 维，**multi-head 并不比单头贵**。

佐证在论文之外：后来的可解释性研究（对 BERT 等模型的逐头解剖）发现，不少头确实专盯固定模式——有的头稳定跟踪句法关系，有的头专管指代（代词→先行词）。**头的分工不是人设计的，是训练自己长出来的**——L01 的「层级特征自动形成」换了个架构还在重演。消融（→ 第 4 节）显示单头明显更差，头数过多也开始回落——甜点位在中间。

### 3.5 位置编码：顺序从结构先验降级为输入特征

自注意力有个天生死穴：**它对顺序完全无感**。把输入 token 打乱，打分矩阵只是行列重排，每个位置收到的还是同一锅信息——「猫吃鱼」和「鱼吃猫」在它眼里是同一句。这不是 bug，是机制本身：点积只看「谁和谁像」，不看「谁在谁前面」。

回忆 L09 的洞见：**顺序是先验，不是数据的固有属性**。RNN 把顺序焊死在递归结构里（先验过强，吃不了集合型数据）；自注意力把顺序整个扔了（先验为零）——矫枉过正。解法不是改回串行，而是**把顺序从结构先验降级为可插拔的输入特征**：给每个位置生成一个位置向量，直接加在词向量上：

```
x = embedding(token) + PE(position)
```

正弦编码一句话带过：用不同频率的 sin/cos 给每个位置生成「指纹」——不同位置指纹不同，相邻位置指纹平滑变化；纯公式、零参数。论文消融显示它与可学习的位置编码效果几乎一样（论文还猜想正弦形式有望外推到训练时没见过的更长序列）。后来 GPT、BERT 都用可学习版本——具体形式可以换，「必须注入」不能省。

这条线值得标记：L01 讲「架构＝先验」，L09 讲「顺序是先验」，本篇把顺序这个先验从「焊死在结构里」降级成「加在输入上」。**先验变少了，模型更依赖数据**——这颗种子到 L20 的 Scaling Laws 里会长成参天大树。

### 3.6 整体结构：现成的骨架 + FFN + 编解码器

逐项看，没有一个组件是这篇发明的——L01 的组合智慧重演：

**(1) 残差 + LayerNorm（层归一化，把每个 token 的特征拉回稳定尺度）：每层都走恒等通路。** 每个子层外面套一条跳连：

```
y = x + Sublayer(LN(x))      （现代 pre-LN 写法）
```

论文原文是先相加再归一：`LayerNorm(x + Sublayer(x))`（post-LN）；从 GPT-2 起的实现普遍把 LN 挪到子层之前（pre-LN），恒等通路更干净、深栈更稳。两种排法精髓一致，而且是 L02/L03 的直系应用：**默认走恒等通路，子层只学「对恒等的修正」**。编码器 6 层 × 2 子层、解码器 6 层 × 3 子层，全模型十几个残差通路——梯度从任何一层直达任何一层。没有这副骨架，深栈的注意力根本训不动：让梯度活下去的主线，从 ReLU（L01）到残差（L02/L03），在这里继续。

**(2) FFN：逐位置前馈。** 注意力管「跨位置混合」，FFN 管「位置内加工」——两层全连接（512→2048→512，ReLU），每个位置独立过同一个网络。类比：注意力是开会交流，FFN 是回工位消化。注意力输出的是「别人信息按权重的混合」，FFN 负责把它加工成新表示。

**(3) 编码器-解码器与 cross-attention。**

```
源句 ──► 编码器×6 (self-attn + FFN) ───► 全句笔记 (K, V)
                                            │
                       cross-attention      │ Q 来自解码器
                       （开卷翻书）◄─────────┘
                                            ▼
已生成部分 ──► 解码器×6 (masked self-attn + cross-attn + FFN) ──► 下一词
```

解码器的 self-attention 有一个关键改动：**因果掩码（causal mask）**——生成第 i 个词时，把第 i 之后所有位置的打分置 −∞，softmax 后权重为 0，只许看过去。L10 里这由 RNN 的时序天然保证，自注意力一步全局会「偷看答案」，掩码是补上的因果律。而 cross-attention 就是 L10 的「开卷翻书」在无序世界的重生：Q 来自解码器，K/V 来自编码器输出，打分从加性换成 scaled dot-product。

一句诚实的补充：推理时解码器逐词生成，仍是串行的——本篇的并行红利在**训练**侧；推理侧的补救（KV cache 等）是后来的工程故事。

## 4. 实验逻辑

**主战场**：WMT 2014 翻译基准，英德（约 450 万句对）+ 英法（约 3600 万句），指标 BLEU（机器翻译自动评分，衡量与人工参考译文的 n-gram 重合度）。

**主结果**（论文 Table 2）：

- 英德：**28.4 BLEU**，超过此前最好成绩——**含 ensemble**——2 BLEU 以上
- 英法：**41.8 BLEU**，单模型当时最优
- 成本：big 模型 8 块 P100 训练 **3.5 天**。论文报告的训练总 FLOPs 量级：英德约 2.3×10¹⁸，此前 SOTA 的 GNMT+RL 约 1.8×10¹⁹（约八分之一）；英法约 9.6×10¹⁸，对照 ConvS2S 约 1.5×10²⁰（不到十分之一）——**零头**

读法：模型并没有更大（参数量与对手同量级甚至更小），赢的不是堆预算，是**并行性红利**——宗一消掉，训练墙就塌了，别人用十倍的电，它用十分之一。另外 base→big 同架构推大线性涨分（英德 27.3→28.4），这是 scaling 曲线的雏形（→ L20）。

**消融链条**（论文 Table 3，趋势为主）：

- **头数**：单头（h=1）比最佳设置差约 0.9 BLEU；头数过多也开始回落——多头必要，甜点位在中间
- **d_k 太小（16）明显变差**：点积匹配需要每个头有足够的维度容量，切太碎每头装不下一个完整关系
- **位置编码**：正弦 vs 可学习，效果几乎一样；但这一项「必须存在」——没有位置信息，模型退化成词袋
- 更大模型 + dropout 带来稳定增益

## 5. 为什么在这份 List 里

1. **Ilya 世界观的胜利时刻**。AlexNet 立起的信念是「模型×数据×算力→涌现」；RNN 时代的真瓶颈恰是算力进场受阻（串行）和信息路径太窄（O(n)）。Transformer 把两堵墙同时拆掉，而且它先验极少、几乎不吃结构红利——**从数据里学一切的架构，才能从无限喂料里持续涨分**。L20 Scaling Laws 验证的可扩展性，物理载体就是这篇的自注意力栈。论文自己已经露出苗头：同架构推大，分数线性涨。
2. **GPT 是本篇的直系后代**。GPT-1（2018）一句话说完：**把 Transformer 的解码器单独拿出来，删掉编码器和 cross-attention，只留因果掩码 self-attention，放到「预测下一个词」这个可以无限喂料的任务上放大**。GPT-1 论文作者栏的末位正是 Ilya——「足够大的模型 + 自注意力 + 无限喂料」三件套就此集齐。标题「Attention is all you need」的深层含义：当信息混合机制收敛成一个原语（自注意力）之后，剩下的全部是规模问题。
3. **「组合而非发明」的方法论闭环**。自注意力＝L10 的注意力搬进编码器内部，点积＝老掉牙的相似度度量，multi-head＝通道分组的工程常识，残差+LN＝L02/L03 现成的骨架，位置编码＝L09 洞见的工程解法。论文没有发明任何一个组件，却完成了范式替换——与 AlexNet 的革命方式一模一样。这份 List 欣赏「聪明排列＞暴力堆料」（L04 语），而这一次，排列直接通向 scaling。

## 6. 织进网里

- **← L10 Bahdanau 注意力**：软注意力出生（解码器开卷翻书）；本篇把同一机制搬进句子内部、两侧同源（self），打分从加性换成 scaled dot-product——「翻书」升格为「书内词互相翻」
- **← L11 Pointer Networks**：注意力即选择的硬形态；本篇保留软选择的加权求和本质，把它做成通用底座
- **← L02/L03 ResNet 线**：残差+LN 子层（pre-LN 形态 `y = x + Sublayer(LN(x))`，论文原文 post-LN）是恒等映射的直系应用；十几个残差通路撑起深栈，梯度处处可达
- **← L09 Order Matters**：顺序是先验——本篇把这条洞见工程化：顺序从焊死的结构降级为位置编码这种可插拔输入
- **→ L13 Annotated Transformer**：逐行实现本篇，把 Q/K/V、掩码、位置编码全部落成可跑代码
- **→ L20 Scaling Laws**：验证本篇的可扩展性——自注意力 + 极少先验＝吃数据不噎的架构，scaling 曲线的物理载体
- **→ GPT**：解码器单独拿出来放大，Ilya 世界观「足够大的模型 + 自注意力 + 无限喂料」的载体

## 自测题

1. Q/K/V 各扮演什么角色？两个 token 的匹配度怎么算出来？
   > Q＝我在找什么（查询词）、K＝我有什么标签（索引）、V＝我的实际内容（正文）；匹配度＝Q·K 点积（方向越一致分越高），softmax 归一成权重后对全部 V 加权求和。
2. scaled dot-product 为什么除以 √d_k？不除会发生什么？
   > 维度大→点积是 d_k 项求和、方差随维度线性涨→softmax 输入过大直接饱和成 one-hot→梯度≈0（L01 sigmoid 饱和还魂）；除以 √d_k 把量级归一回 O(1)，softmax 留在有梯度的工作区——让梯度活下去。
3. multi-head 为什么优于 single-head？可解释性研究发现了什么佐证？
   > 单次点积只有一种相似度标准，而语言关系多维（主谓/修饰/指代/邻近）；512 维切 8 份各配一套 Q/K/V 独立匹配再拼接（8×64＝512，不比单头贵），单头差约 0.9 BLEU；后续逐头解剖发现有的头稳定跟句法、有的头专管指代，分工是训练自己长出来的。
4. 自注意力为什么必须注入位置编码？不注入会怎样？
   > 点积只看「谁和谁像」不看「谁在谁前面」，打乱输入顺序打分集合只是重排，「猫吃鱼」和「鱼吃猫」同句——退化成词袋；L09：顺序是先验，本篇把它从结构降级为可插拔输入（位置向量加到词向量上，正弦公式或可学习向量皆可，消融显示两者几乎等效）。
5. `y = x + Sublayer(LN(x))` 对应哪两篇的思想？没有它 Transformer 为什么训不动？
   > L02 ResNet（残差跳连）+ L03 Identity Mappings（默认恒等通路、子层只学对恒等的修正）；十几层注意力+FFN 的深栈全靠残差通路让梯度直达任何层，否则反向传播逐层衰减，重演 L01 时代「深层不可训练」的老病。
