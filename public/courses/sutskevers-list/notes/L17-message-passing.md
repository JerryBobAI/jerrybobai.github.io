# L17 · Message Passing — 结构化数据上的卷积

《Neural Message Passing for Quantum Chemistry》(2017, ICML) · Justin Gilmer, Samuel S. Schoenholz, Patrick F. Riley, Oriol Vinyals, George E. Dahl · Google Brain · [arXiv:1704.01212](https://arxiv.org/abs/1704.01212)

## 1. 一句话

`MPNN`(Message Passing Neural Network)用一条四步流水线——**沿边算消息、聚合进收件箱、更新顶点状态、读出全图向量**——把七八种图神经网络收编成同一模板的「填空题」，然后在量子化学基准 `QM9` 上把 13 个分子性质全部做到当时最优、11 个进化学精度。它给出这张 List 最一般的数据结构观：**图 = 比序列、网格更一般的数据结构，消息传递 = 结构化数据上的卷积**。

## 2. 它之前的世界：一个领域，八套方言

图数据无处不在：分子是原子加化学键的图，社交网络是用户加好友的图，知识图谱是实体加关系的图，场景是物体加空间关系的图。2017 年之前，「在图上跑神经网络」是一盘散沙：Duvenaud 的分子卷积、`GG-NN`、Interaction Networks、Kearnes 图卷积、`DTNN`、Kipf 与 Welling 的 `GCN`……每个模型一套记号一套叙事，无法公平比较，外人看不出是近亲。

化学这一侧是 L01 之前的既视感：**特征工程当道**——Coulomb 矩阵、分子指纹喂给现成模型，正是 2012 年前视觉「SIFT + SVM」的翻版。手工特征还有硬伤：Coulomb 矩阵不满足图同构不变——写法等价的两个分子，喂进去是两个不同输入。你以为缺的是「一个更强的模型」——其实缺的是**统一框架 + 一块足够硬的试金石**。

## 3. 核心思想

### 3.1 四步流水线：消息 → 聚合 → 更新 → 读出

MPNN 把图上学习抽象成 T 轮消息传递 + 一次读出：

```
消息:  m_v^{t+1} = Σ_{w ∈ N(v)} M_t( h_v^t, h_w^t, e_vw )
更新:  h_v^{t+1} = U_t( h_v^t, m_v^{t+1} )
读出:  ŷ        = R( { h_v^T | v ∈ G } )
```

工程类比一个部门群聊：

- **消息函数 M**：每个顶点只和邻居通信：邻居 w 按自己的状态 h_w 和边 e_vw(键型、键长)编一条消息发给你
- **聚合 Σ(收件箱)**：把收到的消息**求和**——邻居发信先后不影响结果，集合语义(呼应 → L09)
- **更新函数 U**：顶点拿旧状态加收件箱总和刷新自己，实战里就是 GRU(→ L07 门控,让梯度活过 T 轮)
- **读出 R**：T 轮后把所有顶点状态汇总成全图向量。**R 必须对顶点排列不变**——同一分子换原子编号，输出不能变(图同构不变性:图换写法、语义不变)

顶点视角的一步：

```
   b ──e_ab──> M ──┐
   c ──e_ac──> M ──┼─> 收件箱 a:Σ 全部消息 ──U(h_a, Σ)──> h_a^{t+1}
   d ──e_ad──> M ──┘                     (× T 轮,再 R({h_v}))
```

### 3.2 八种方言，一张填空表

论文把代表模型逐个塞回模板，每个只是 M/U/R 的不同填空：Duvenaud 分子卷积 = 「邻居状态、边」拼接；`GG-NN` = 按边类型查矩阵乘 + GRU 更新；Interaction Networks = 吃「两端状态 + 边」的 MLP；`GCN`(Kipf & Welling)= **度归一化的邻居加权平均**，推导出来惊人地素。统一之后，比较模型 = 比较填空。回头看 L04：CNN 只向网格固定邻域发信、核即共享的消息函数——**卷积本来就是消息传递的特例**，MPNN 把「邻居」从网格解放到任意图。

### 3.3 量子化学实战：QM9

`QM9`：约 13.4 万个有机小分子(不超过 9 个重原子,H/C/O/N/F)，13 个性质由 `DFT`(密度泛函理论:量子化学的标准近似算法,准但贵)算好当标签——HOMO、LUMO、HOMO-LUMO 能隙 Δε(电子从最高占据轨道跳到最低空轨道所需能量,决定分子吸什么光)、原子化能、偶极矩等。两个标尺：`DFT 误差`(DFT 对真实值的偏差)和**化学精度**(chemical accuracy:化学界公认达标线)——先追平 DFT，才谈替代它。

DFT 贵：9 个重原子的分子单核 CPU 约 1 小时，17 个重原子要 8 小时。MPNN 推理比它**快约 30 万倍**。

最优配方三件：**边网络消息函数**(连续边特征——键型加原子距离——过小网络生成 d×d 矩阵去乘邻居状态,替代「按离散边类型查表」)、**set2set 读出**(→ L09 的集合读出,比「顶点状态求和」更能表达全图)、**显式氢原子**(氢从「数一下」升级成图节点)。结果：13 个目标全部当时最优，**11/13 进化学精度**；只用分子拓扑、不给空间距离，也有 5/13 达标。

加分细节：化学键只连近邻，但电子相互作用不止于键——库仑排斥、色散这类「隔空」影响像散射信号穿远程空间，纯键图上没有通路。修路方案有二：**虚拟边**(给未连键原子对补一条「虚拟边型」,消息直达)和 **master node**(连着所有顶点的全局草稿板,每轮读写)；无空间信息时显著涨点。

## 4. 实验逻辑

- **主战场 QM9**，对照组：5 种手工特征表示(Coulomb 矩阵、BoB 等)和 2 个已有图网络(GG-NN、Kearnes)
- **消融链条**(无空间信息,看「长程交互」的贡献)：GG-NN 基线 → 加虚拟边 → 加 master node → 读出换 set2set，逐级上涨，最终 5/13 达化学精度；空间信息全开加最优配方后 11/13
- **反直觉消融**：pair message(消息同时看两端,理论上表达力更强)实测**输给**边网络——平均误差比 1.53 vs 3.98,13 目标里 11 个更差。结论朴素：复杂组件难训，简单组件先跑通
- 训练细节诚实：T 取 3-8 步足够；单目标训练普遍好于 13 目标联合训练，个别差 40%

## 5. 为什么在这份 List 里

1. **数据结构的一般化收官**：网格(L01-L04)、序列(L06-L08)、集合(L09)、带软选择的完全图(→ L12)——图把这一切收进同一框架，「注意力」和「卷积」都是消息传递的方言
2. **学习即压缩的实体证据**：端到端学出的消息传递把昂贵的 DFT 量子计算压进权重——推理快约 30 万倍、11/13 达化学精度，是「学习替代手工特征与物理近似」最硬核的实验场之一
3. **架构先验的第三块拼图**：图同构不变性焊在读出 R 的形态里，和 CNN 的平移不变、RN 的顺序不变同源——先验写在结构上，不写在损失函数里

## 6. 织进网里

- **← L15 关系推理**：「关系」暗线第三级。RN 是**完全图**上的消息传递(每对物体硬算一遍)；MPNN 按**真实结构**稀疏传信——一个证明「全连也行」，一个证明「按边走更省」
- **← L09 Order Matters**：set2set 读出正是该文的产物；聚合求和的顺序无关性同一根源
- **← L07 LSTM / ← L04 Dilated**：更新函数用 GRU；卷积 = 网格上的定邻消息传递，MPNN 是它的推广
- **→ L12 Transformer**：本 List 最大的合流点。注意力 = 「软邻接矩阵上的消息传递」——MPNN 的邻接由边硬定、消息权重学出来；自注意力的邻接权重由内容(QK)现算，等于**完全图上的 MPNN**。论文结论自己埋了「对入边消息加注意力」的方向，GAT 随后落地，Transformer 走到尽头
- **→ L20 Scaling Laws**：QM9 上「一次训练替代百万次模拟」，后来放大成大模型「学习替代模拟世界」的母题

## 自测题

1. MPNN 四步流水线各是什么?哪两步必须保持排列不变，为什么?
   > 消息 M 沿边算、聚合 Σ 收件箱求和、更新 U 刷顶点状态、读出 R 出全图向量；Σ 和 R 必须排列不变——图同构不变(分子换原子编号输出不能变)，否则同一分子两种写法两种答案。
2. 为什么说「卷积是消息传递的特例」?
   > CNN 只向固定网格邻域发信、卷积核即共享的消息函数、滑窗 = 权值共享的 M；MPNN 把「邻居」从网格解放到任意图的边——结构化数据上的卷积。
3. 易混淆：虚拟边 / master node 解决什么问题?为什么化学里尤其需要?
   > 消息只沿真实边走，T 步只能传 T 跳，远程相互作用(库仑/色散这类不止于化学键的隔空影响)没有通路；虚拟边给未连键原子对补边、master node 做全局草稿板，无空间信息时涨点显著。
4. 跨篇：MPNN 与 L12 自注意力在「传信息」上的共同点与差别?
   > 都是「集合上按关系传信息」：MPNN 邻接由边硬定、消息权重学出来；自注意力邻接权重由内容 QK 现算——完全图上的软消息传递；MPNN 结论自己提出「对入边消息加注意力」。
5. 世界观：QM9 的胜利印证了哪条 Ilya 式信念?数字链条是什么?
   > 学习即压缩：端到端学出的消息传递把昂贵 DFT(单分子 1-8 小时)压进权重，推理快约 30 万倍，13 目标全部当时最优、11/13 进化学精度——从数据学表示替代手工特征与物理近似。
