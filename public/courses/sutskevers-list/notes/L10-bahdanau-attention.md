
# L10 · Bahdanau Attention — 注意力的出生证明：从死记硬背到开卷考试

《Neural Machine Translation by Jointly Learning to Align and Translate》(2015, ICLR) · Dzmitry Bahdanau, Kyunghyun Cho, Yoshua Bengio · [arXiv:1409.0473](https://arxiv.org/abs/1409.0473)

## 1. 一句话

这篇论文干的事：**拆掉「整句压进一个固定向量」的硬约束，让解码器每生成一步都能回头翻看编码器的全部笔记**——对源句每个位置打分、归一、加权求和，出本步专属的上下文向量。句子再长也压不瘪，而「哪个词对准了哪个词」没人教过，是训练的免费副产品。这就是注意力机制（attention）的出生证明。

## 2. 它之前的世界：把一整本书塞进一句摘要

2014 年，神经机器翻译（NMT，用一个网络端到端学翻译）刚被提出：不再拼装短语表、语言模型、对齐模型，而是**一个大网络**读句子、出译文，主流形态叫 seq2seq 编码器-解码器（encoder-decoder）——编码器把**最后一个隐状态 c 当作整句的意思**，解码器从 c 逐词生成译文。Sutskever 同年的 LSTM 版本已逼近打磨多年的 phrase-based 统计系统（基于短语对翻译）。

但架构埋着一颗雷：**c 的长度固定**——5 个词也好 100 个词也好，统统压进同一个 1000 维向量。类比：任何大小的文件都塞进固定 4KB 的压缩包，再要求凭它还原原文，长文必有信息被丢。这是闭卷考试：念完就收走原文，凭记忆作答，记忆槽大小跟题目长度无关。

后果很快被量化：Cho 等人同年发现**句长一涨、性能断崖**——Figure 2 的句长-BLEU 曲线（BLEU：机器翻译自动评分，与人工参考译文的重合度）里，seq2seq 随句长急剧下滑，30 词往上接近跳水。

当时的直觉是「向量太小，加大向量」。这篇说方向错了：**问题不是记性差，是不许回头看**——人类译者从不先压整句再翻译，而是边看边译、视线来回扫。解法不是造更大的记忆槽，而是把考试改成开卷。

## 3. 核心思想

### 3.1 每一步一个专属上下文向量：开卷考试的「翻书」动作

原架构全程共享一个 c；新架构改成每步自己的 c_i：`p(y_i | y_{<i}, x) = g(y_{i-1}, s_i, c_i)`。生成第 i 个词前先「翻书」，三步：

**① 打分**：用小前馈网络 a 给每一对（解码器上一状态 s_{i-1}，编码器第 j 位置的笔记 h_j）打相关度分：`e_ij = v_aᵀ · tanh(W_a · s_{i-1} + U_a · h_j)`。两边线性映射后**相加**再过 tanh，故名 additive attention（加性注意力）——对照一年后 Transformer 的点积打分（→ L12）。

**② 归一**：softmax 压成和为 1 的分布：`α_ij = exp(e_ij) / Σ_k exp(e_ik)`

**③ 加权求和**：`c_i = Σ_j α_ij · h_j`

直觉：α_ij 是「译第 i 个词该参考第 j 个源词的程度」。工程视角：这是一次**按内容的加权检索**——查询是解码器状态，索引是编码器全部中间状态，返回加权混合。

### 3.2 编码器升级：给每个词写一条「读过上下文的批注」

注意力要对准，前提是每个位置的表示值得对准。单向 RNN 的隐状态只见过前文——第 j 个词的向量里没有它右边发生了什么。论文改用双向 RNN（BiRNN），左右各读一遍，拼接成注释（annotation）：`h_j = [→h_j ; ←h_j]`。每条批注**既读过上文也读过下文**，且因 RNN 偏爱近期输入，天然聚焦词 j 邻域；每个位置都有自己的出口，信息不必再挤 x_Tx 一处。

### 3.3 全可微：对齐不是隐变量，是计算图的一部分

传统统计机器翻译把「对齐」（哪个源词对应哪个目标词）当独立隐变量，用单独算法（如 EM）先估出来再喂给翻译系统——两阶段两目标，互不通气。这篇的处理：α_ij 直接躺在计算图里，梯度穿过 softmax 一路回传，打分器和双向编码器与翻译**联合训练，对齐是学出来的副产品**。为什么必须「软」？argmax 硬挑唯一位置不可导、梯度断流；软化成概率混合，梯度才能流过每个位置——**让梯度活下去**的又一次胜利。

### 3.4 可视化：注意力矩阵就是一张词对齐图

把 α_ij 画成灰度矩阵（横轴源句、纵轴译文），亮块路径就是自学成才的对齐：词序一致时沿对角线走，非单调处才见真章：

```
Figure 3(a)：European Economic Area → zone économique européenne
（法语形容词后置，模型自学）

             European  Economic  Area
zone            ·         ·       █    ← 先指到名词
économique      ·         █       ·    ← 回看一格
européenne      █         ·       ·    ← 再回看一格
```

另一死角：`the man` → `l'homme`。硬对齐两两锁死，可 the 选 le/la/les/l' 取决于后词；软对齐让模型**同时看两个词**。

## 4. 实验逻辑

- **主战场**：WMT'14 英→法，3.48 亿词平行语料，3 万词表（低频词映射成 [UNK]），对照彼时最强的统计系统 Moses
- **关键对照**：RNNencdec（原版 seq2seq）vs RNNsearch（本文模型），各训两档——≤30 词句（-30）与 ≤50 词句（-50），其余配置全同

| 模型 | BLEU 全测试集 | BLEU 无 UNK 句 |
|---|---|---|
| RNNencdec-30 | 13.93 | 24.19 |
| RNNsearch-30 | 21.50 | 31.44 |
| RNNencdec-50 | 17.82 | 26.71 |
| **RNNsearch-50** | **26.75** | **34.16** |
| Moses（统计 SOTA） | 33.30 | 35.63 |

- **判决性证据**：RNNsearch-30（只见 ≤30 词句）**反超** RNNencdec-50——涨的不是数据量，是「能不能回头看」；句长曲线上 RNNencdec 跳水，RNNsearch-50 到 50 词以上仍不掉
- **定性分析**：30+ 词长句样例里 RNNencdec-50 后半段脱离原文、RNNsearch-50 全程忠实；对齐矩阵（Figure 3）与语言直觉吻合
- **意义标定**：NMT 提出仅一年，单模型端到端（单 GPU 训约 5 天）无 UNK 句 BLEU 已到 34.16、逼近 Moses 的 35.63；全测试集 28.45 对 33.30 仍有差距——两年后整个领域换轨 NMT

## 5. 为什么在这份 List 里：压，还是检索

1. **「视野」主线的推倒重来**：← L04 Dilated Convolutions 讲「视野要宽」，但空洞卷积再指数扩张，视野仍是**预先固定的采样图案**；注意力改成**全局软选择**——视野天生是全句，「看哪里」按内容动态学出来，是通往 L12 前的最后一个平台
2. **对「学习即压缩」的张力**：这篇的解法不是把压缩器造得更好，而是**拒绝压瘪**——保留全部中间状态，另学检索器。该压还是该检索，是此后架构争论的原型问题
3. **软化离散选择**：不可导的硬对齐换成可导的概率混合，端到端训练才成立——→ L11 Pointer 直接把分布当输出，→ L14 NTM 内容寻址是同一手法

## 6. 织进网里

- **← L06/L07 RNN/LSTM**：骨架完全继承 seq2seq，RNNsearch 的 gated 单元就是 GRU 一族——RNN 时代架构潜力的最后一座高峰
- **← L09 Order Matters**：同一作者 Vinyals 的姊妹篇——那篇问「集合输入怎么定顺序」，本篇问「输出怎么按需读输入」；下一篇他亲自动手
- **→ L11 Pointer Networks**：一行手术——α_ij 从「混合上下文的配料」升为「输出分布本身」，注意力从「读」变「指」
- **→ L12 Transformer**：最大伏笔：打分换成 QK 点积，「每步重算注意力 + RNN 顺序依赖」一次解决——注意力即网络，循环退场；此后的 copy、pointer-generator、检索增强全是「α_ij = 对位置的分布」的子孙

## 自测题

1. 经典 seq2seq 的瓶颈是什么？论文用哪个对照证明瓶颈在「固定向量」而非「数据不够」？
   > 整句压进固定长度的最后隐向量 c，句长超 30 词 BLEU 跳水；证据：RNNsearch-30（只见 ≤30 词句）反超 RNNencdec-50（21.50 对 17.82）——涨的不是数据量，是「能不能回头看」。
2. 写出注意力上下文的三步计算链，并说明「每步一个 c_i」改掉了什么？
   > e_ij=a(s_{i-1},h_j) 打分（additive 小网络）→ softmax 归一成 α_ij → c_i=Σ α_ij·h_j 加权求和；改动：生成 y_i 用专属 c_i，而非全程共享同一个压扁向量——从死记到开卷。
3. Bahdanau 的对齐与传统统计机器翻译的对齐，本质区别在哪？为什么必须「软」？
   > 传统：对齐是隐变量，先单独估出再喂翻译系统，两阶段；本篇：α_ij 在计算图内与翻译联合训练，是学出的副产品；必须软是因为 argmax 不可导、梯度断流，软化成概率混合才能端到端。
4. 「让模型看到该看的地方」这条线，从 L04 到本篇到 L12 是怎么演进的？
   > 空洞卷积改采样排列扩固定视野（设计更固定的看）→ 注意力按内容动态软选择（看哪里学出来）→ Transformer 注意力即网络本体、循环退场（看即网络）。
5. Ilya 的世界观是「学习即压缩」，这篇的解法看似反其道而行——这个张力说明什么？
   > 固定向量是极限压缩且失败了；解法是保留全部中间状态、另学检索器——压缩不是一味压紧，架构创新有时是拆掉瓶颈而非优化瓶颈。
