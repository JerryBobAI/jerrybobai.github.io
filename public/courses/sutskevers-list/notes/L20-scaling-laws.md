# L20 · Scaling Laws — 把「大力出奇迹」变成一张预算表

《Scaling Laws for Neural Language Models》(2020, arXiv 技术报告) · Jared Kaplan 等（OpenAI + Johns Hopkins）· [arXiv:2001.08361](https://arxiv.org/abs/2001.08361)

## 1. 一句话

这篇论文做的事：**把「模型变大到底换多少性能」从信仰变成可以计算的定律**——语言模型在没见过的数据上的损失，随参数量 N、数据量 D、算力 C 各自按幂律平滑下降，横跨七个数量级看不到拐点；给定预算怎么在三者间分配，论文直接给出指数。Ilya 八年前那条「规模推到位、能力会涌现」的定性信念，至此第一次有了能写进预算表的数学形式。

## 2. 它之前的世界：规模是信仰，不是科学

2012 到 2019，「模型更大更好」是共识直觉，但始终停在直觉。认真回答三个问题，手里都没有定律：

**曲线会不会拐弯？** 加参数的收益，完全可能是 S 型曲线——中途饱和，后期白花钱。零散证据互相矛盾：`BERT-large`（3.4 亿）比 `BERT-base` 强，`GPT-2`（15 亿）更强，但「会不会撞墙」没人敢打包票；反对派还有个听着很专业的论据：参数多了必然过拟合。

**算力该怎么分？** 给你一笔固定的 GPU 预算，是训 10 亿参数的模型只喂一小部分数据，还是训 1 亿参数的模型喂到收敛（损失不再下降）？每个实验室每周都在做这个决策，依据全是手感。

**形状重要吗？** 同样 1 亿参数，做成深窄还是浅宽？各家调法不同，像手艺，不像科学。

所以当时的世界是：**规模的有效性有一堆经验证据，却没有一条定律**。经验只告诉你「往大了走大概没错」，但给定明年 10 倍预算，没人能告诉你损失会降到多少。这篇论文的野心，是给「大力出奇迹」补上物理学。

## 3. 核心思想

### 3.1 实验设计：把「规模」本身当自变量

一般论文的自变量是架构技巧，因变量是榜上名次；这篇论文反着来：**架构固定（decoder-only `Transformer`），把规模当自变量**，狂扫：

```
模型数量：  400+ 个
参数量 N：  10³ → 10⁹（非嵌入参数，从千级玩具到十亿级，七个数量级）
数据量 D：  10⁸ → 10¹⁰ token 量级（WebText2 互联网语料，约 22GB 文本）
```

「非嵌入参数」指不含输入/输出查找表（`embedding`）的参数——只数真正干活的权重。控制变量的办法朴素而狠：固定两维、狂扫一维，再联合拟合——更像物理系的扫频实验，而非打榜。

### 3.2 幂律：双对数坐标上一条不拐弯的直线

主测量是 `cross-entropy loss`（交叉熵——模型在没见过的文本上预测下一个词的「惊讶程度」，越低学得越好）。注意没有用任何榜单准确率：要找定律，先选干净的因变量。

结果：损失和参数量服从**幂律（power law——两个量取对数后呈直线的关系）**：

```
L(N) ∝ N^-0.076          （α_N ≈ 0.076，论文拟合值）
```

画在双对数坐标（log-log）里：

```
log 损失
 │ ●
 │  ●
 │   ●
 │    ● ●
 │       ● ●               ← 双对数坐标
 │           ● ● ●
 │                ● ● ● ●     斜率恒定 = -0.076
 │                          ● ●
 └─────────────────────────────────
   log N:  10³       10⁵        10⁹
```

这张图有三层读法：

1. **直线意味着定律**。S 型会饱和，散点叫噪声，而七个数量级内一条直线走到底，「撞墙」没有出现；用万级参数的数据画延长线，能直接预测十亿参数区的损失。
2. **指数小，但翻倍便宜**。α=0.076 意味着参数翻倍损失只降约 5%——单看寒酸，但翻倍可以一直做：每次翻倍买到固定比例的进步，预算越大复利越多
3. **三条幂律并存**。数据维度 `L(D) ∝ D^-0.095`，算力维度 `L(C) ∝ C^-0.050`；单维度看，数据的幂次反而略高于参数

一个诚实的注脚：损失不会降到零，存在不可约下限（自然文本自身的熵——语言固有的随机性，谁也预测不了）。幂律描述的是「可学的那部分」怎么被吃掉；这个「文本的熵」在 L25 Kolmogorov 篇还会重逢。

### 3.3 配平：模型大小是主导维度

三个维度各有一条幂律，值钱的问题是：**给定算力预算 C，怎么在 N 和 D 之间分配？**

先记一笔工程账：训练成本有著名近似 `C ≈ 6·N·D` FLOPs（每参数每 token，前向约 2 次浮点运算、反向约 4 次）——N 和 D 乘在一起花钱。

固定预算下拟合最优组合，答案是一对指数：

```
N_opt ∝ C^0.73         D_opt ∝ C^0.27
```

翻译：**算力翻 10 倍，模型约 ×5.5，数据约 ×1.9**——预算大头砸给模型，数据按幂次跟上。反直觉之处在于：这意味着「大模型少训几步」胜过「小模型训到收敛」。机制在收益递减：小模型训到后期，每个 token 的边际进步趋近于零；同样一笔算力，花在大模型的「青春期」产出高得多。操作策略是**早停**——预算花完就停，不追「训不动」。

类比：同样一个月预算，「雇更强的工程师干三周」胜过「雇实习生干满一个月」——买他的高峰时段，单位时间产出更高。

### 3.4 反直觉之二：大模型每 token 学得更多

样本效率是全文最锋利的发现之一：**同样一段文本喂下去，大模型提取的信号更多**。表现：达到同样损失，大模型需要的数据明显更少——固定 token 数比较，它的损失曲线整体压在小模型之下。

这回应了流行质疑：「模型大、数据少，不是浪费吗？小模型多训几步补回来。」补不回来。控制算力后，「大模型 + 少数据」的损失始终低于「小模型 + 多数据」——**参数效率与数据效率同向**，「深而大」在两个维度上都赢。

用压缩的眼光看：交叉熵本质是压缩长度，大模型每 token 学得更多，就是压缩率更高——同一个 token，小模型只能榨出表层统计规律，大模型能榨出语义结构。

### 3.5 反直觉之三：过拟合什么时候来，算得出来

「参数多了必然过拟合」是当时最流行的反对意见。论文的回应不是辩驳，是把过拟合本身变成定律。

联合拟合 `L(N, D)`（论文尝试多种函数形式，结论一致）：数据不再跟上时，损失脱离 `L(N)` 直线，掉到**位置可提前预测的平台**上——不是玄学式崩溃，是平滑、可算的偏离。由此直接推出数据跟进规则：

```
D ≈ N^0.74             （模型 ×8 → 数据 ×5）
```

读法：参数涨 8 倍、数据涨约 5 倍，损失就还在「数据管够」的直线上。**scale 不是免死金牌**——它是带约束的预算表：只堆参数不堆数据，损失会停在平台上，而平台在哪论文已替你算好。

## 4. 实验逻辑

- **主战场**：held-out 交叉熵，不打榜。基准准确率混杂了任务与格式因素，损失才是「学到多少」的纯净测量——选对因变量，定律才找得到
- **控制变量**：固定两维扫一维 → 三条单变量幂律 → 联合拟合 `L(N, D)` → 固定预算最优化，每一步都是前一步的推论
- **形状不敏感（关键消融）**：同样参数量，深窄 vs 浅宽，损失差异很小（合理范围内）。它把「怎么排布参数」降级为次要问题——总量才是主导项；后来「架构趋同、规模竞赛」的源头在此
- **临界 batch size（批大小——一次前向同时喂的样本数）**：太小浪费算力，太大浪费数据；存在随损失幂律移动的临界值——「数据与算力的汇率」
- **外推被检验**：用小规模实验拟合的直线预测更大规模的损失，实测吻合——「可外推」是验证过的，不是信念

手册第一次大规模执行只隔了四个月：同年五月挂出的 `GPT-3`（1750 亿参数、约 3000 亿 token）就是按这套配平直接定的盘子——模型优先、数据按幂次跟上、训练不追收敛。从结论到当时史上最大模型的立项，没有间隔期。

## 5. 为什么在这份 List 里

1. **这是 Ilya 世界观的定量时刻，全课程主线的汇聚点**。L01 里那条信念是定性的：「模型 × 数据 × 算力推到足够大，能力会涌现」——2012 年那是一次赢了但不可复制的押注。2020 年，同一条信念变成 `L(N) ∝ N^-0.076`：涌现不再等待验证，而是可以预订、可以写进预算表。八年闭环：AlexNet 第一次实证 → 本篇变成科学 → GPT 系列工程化执行。Ilya「不下注深度学习之外的东西」的底气从此质变：从赌徒直觉，变成科学家定律
2. **学习即压缩拿到曲线级证据**。交叉熵就是压缩长度，大模型每 token 学得更多 = 更好的压缩器；这条线往后通向 L21/L22/L25 的 MDL 与 Kolmogorov 篇
3. **范式转移：从手艺到工程**。在它之后，「要不要做千亿模型」不再靠 taste，靠查表。科学史反复上演同一幕：一个领域从艺术变成工程，常常始于一条被画直的线

## 6. 织进网里

- **← L01 AlexNet**：信念的起点——「规模够大会涌现」在 2012 年是少数派押注；本篇把它变成可计算的幂律，八年闭环，主线在此汇聚
- **← L02/L03 ResNet 线**：深度变免费，是「加参数」这条路能走到百亿千亿而不崩的前提——没有残差连接，七个数量级的扫描根本不存在
- **← L19 GPipe**：训得动——pipeline 并行把装不进单卡的大模型拆到多设备上，「算力预算」才有操作意义。定律要被执行，先得有工程
- **→ GPT 系列 / Chinchilla**：GPT-3 是手册的第一个大型应用；两年后 DeepMind 的 Chinchilla 修正了配比——数据该给得更多（大致与模型同比例增长，约 20 token/参数），「模型优先」偏了；但幂律框架毫发无损，修正发生在指数层面，不在形态层面

## 自测题

1. 幂律在什么坐标下是什么形状？三个维度的幂次大约是多少？直线不拐弯意味着什么？
   > 双对数坐标上直线，`L(N)∝N^-0.076`、`L(D)∝D^-0.095`、`L(C)∝C^-0.050`；七个数量级无饱和拐点——小模型数据可外推预测大模型损失，「撞墙」在扫描范围内不存在。
2. 固定算力预算，N 和 D 该怎么分？为什么「大模型少训几步」赢？
   > `N∝C^0.73` 主导、`D∝C^0.27` 跟随（算力 ×10 → 模型约 ×5.5、数据约 ×1.9）；小模型训到收敛时边际收益趋零，算力花在大模型损失曲线仍陡峭的「青春期」更划算，操作上是早停。
3. 「大模型数据少是浪费，小模型多训几步能补回来」错在哪？
   > 样本效率上大模型每 token 提取的信号更多，同 token 数下损失整体更低；控制算力后「大模型+少数据」始终优于「小模型+多数据」——参数效率与数据效率同向，补不回来。
4. 数据不跟上参数时会发生什么？数据该怎么跟进？
   > 损失脱离 `L(N)` 直线、掉到位置可预测的平台（平滑可算，非玄学崩溃）；跟进规则 `D≈N^0.74`（模型 ×8 → 数据 ×5）——scale 不是免死金牌，是带约束的预算表。
5. 这篇和 L01 的信念是什么关系？为什么说是「八年闭环」？
   > L01 是定性实证（规模推到位→能力涌现，一次押注），本篇把它变成可计算幂律（涌现可预订、可写预算表），2012→2020；四个月后 GPT-3 按手册立项，闭环完成。
