# L06 · The Unreasonable Effectiveness of RNNs — 没人教括号，它自己学会了配对

《The Unreasonable Effectiveness of Recurrent Neural Networks》(2015, 博客) · Andrej Karpathy · [karpathy.github.io/rnn.html](http://karpathy.github.io/rnn.html)

## 1. 一句话

这篇博客用「预测下一个字符」这一个朴素目标训练了一个小型 `RNN`（循环神经网络，带隐状态、按时间步滚动的网络），模型就自己长出了语法、缩进、括号配对，甚至写出了节奏靠谱的伪莎士比亚戏剧——**没有任何一条规则被人显式教过，它们全部是「降低预测误差」这个单一目标的副产品**。标题里的 unreasonable effectiveness（不合情理地有效）说的就是这件事：这么简单的机制不该这么强，但它就是强；而且看模型生成一段文本，就是给它做能力体检最直观的方式。

## 2. 它之前的世界：生成文本 = 手写语法？

2015 年，深度学习已经在图像上翻了天（L01–L04），但「让机器生成文本」在很多地方仍被当作程序问题：语法解析器、模板系统、n-gram（只看前面固定 N 个词的统计模型）。这些做法的共性：**人把「语言的结构」翻译成规则或模板，机器负责查表填空**。规则写得越细，系统越僵硬；换个领域（从戏剧换到代码），几乎推倒重来。统计派的 n-gram 好一点，但天花板明显——它把「看过多少历史」硬编码成固定窗口，想看更长历史，状态组合数指数爆炸，数据永远不够填表。

你以为是「机器要生成好文本，得先教它语法」。这篇博客的答案是 B：**只教一件事——预测下一个字符，语法是它为了考高分自己发明的手段**。

还有一个当时容易被忽略的背景：CNN 只吃固定形状的东西（固定分辨率的图、固定类别数的标签），而文本、代码长度不定，还要求「读到哪、记到哪」——世界需要一个能边读边记、长度自适应的架构。

## 3. 核心思想

### 3.1 字符级语言模型：一次前向传播，每个位置都在考试

`字符级语言模型`（character-level language model）做的事：给一段文字的前文，预测下一个字符的概率分布。字符级意味着词表极小——莎士比亚文本的词表只有约 65 个字符（大小写字母、标点、空格），不用分词、不用词典，任何输入都是一串 one-hot 向量。

一个容易漏掉的关键细节：训练时**不是只对序列末尾算 loss**。模型扫过 "HELL" 时：

```
输入  H      E      L      L
目标  E      L      L      O      ← 每个位置都有标准答案
loss  +      +      +      +      ← 每个时间步都计损失，加在一起训
```

一次前向传播等于同时考了 4 道题，监督信号便宜到奢侈。推理时反过来：采样一个字符 → 拼回输入 → 再预测 → 滚动生成，模型就这样「写」出一整段文本。

### 3.2 展开：同一组权重反复使用，隐状态负责传话

RNN 的全部机制一句话说完：**每个时间步跑同一个函数，它看两个东西——当前输入、上一步的隐状态（hidden state，一份被不断重写的摘要），输出新的隐状态和当前预测**。按时间展开（unroll）看就一目了然：

```
 t=0      t=1      t=2      t=3
  │        │        │        │
  H        E        L        L         ← 输入字符
 [W]      [W]      [W]      [W]        ← 同一组权重，每步复用
  │   h→   │   h→   │   h→   │
  ▼        ▼        ▼        ▼
 h₀ ─────→ h₁ ─────→ h₂ ─────→ h₃      ← 隐状态：一条传话链
  │        │        │        │
 预测E?   预测L?   预测L?   预测O?
```

两个直觉，不需要 BPTT（沿时间反向传播）的任何数学：

1. **同一组权重反复使用**：文本是 10 个字符还是 10 万个，参数量不变。这是「权值共享」从空间维（L01 的卷积核滑过整张图）搬到时间维（同一个函数滚过整个序列）。
2. **隐状态是传话人**：第 t 步只看得到 xₜ 和 hₜ₋₁，「前文的一切」都被压缩在 hₜ₋₁ 这份摘要里传过来。用工程话说：h 是一块**每步被整块覆写的缓存**，旧值想活下来，只能靠自己被「复述」进新值——它更像草稿本，不是档案库。

训练时梯度沿这条时间链往回传（博客贴出的核心代码就几十行，前向反向一次算完），代价是：传得越远，梯度链越长、越容易衰减。这个隐患这里只埋种子，L07 正面开刀。

### 3.3 温度采样：一个旋钮控制「保守 vs 放飞」

模型每步输出的是词表上的概率分布，采样前先除以温度 T 再归一化：

- **T 低（如 0.5）**：分布变尖锐，高概率字符几乎垄断采样 → 文本保守、通顺，但爱原地绕圈重复
- **T = 1**：分布原样采样，博客的默认档
- **T 高（如 1.5）**：分布被抹平，冷门字符也敢选 → 文本放飞、更有「创意」，但语法开始崩坏

博客为同一个莎士比亚模型摆出了低温 / 原温 / 高温三档样本，差异一眼可辨。工程视角：温度是**生成时的探索率旋钮**——训练完不动权重，只调它。这个旋钮今天原样活在所有 LLM 的采样参数里。

### 3.4 RNN 是「有状态的迷你程序」

Karpathy 文末最想让人带走的，是一个视角转换：**把 RNN 看成一个带循环和内存（隐状态）的小程序**——输入是函数参数，隐状态是局部变量，权重是这个程序的「源代码」。他还提醒：配上合适的权重，RNN 理论上图灵完备（能模拟任意程序）。

博客的可视化给这个观点提供了肉眼证据：把 Linux 代码喂给训练好的模型，逐字符记录每个隐状态单元的激活，能看到有的细胞**只在注释里点亮**、有的**盯着字符串引号的内部**、有的**对行首缩进敏感**——这些不是谁设计的功能，是梯度下降从「预测字符」的压力里压出来的子程序。训练 RNN 因此更像「编译」出一个程序，而不是手写它。

## 4. 文章怎么展开论证：四个样例就是四组实验

博客的论证方式非常工程师：不画架构大图，直接甩样本，让你自己被击中。

- **样例一 · 莎士比亚全集**：生成的人物名是莎士比亚式拼写但词典里查不到，对白节奏对、舞台指示格式对、大小写习惯对。不看原文，你很难断定这不是莎翁残稿
- **样例二 · Linux 内核源码**：生成的 C 代码语法成立——`#include` 待在文件头、缩进层级正确、**花括号全部配对**、函数体结构完整。注意缩进和括号配对是长程结构：一个 `{` 可能要等几十上百个字符之后才有对应的 `}`，模型没有任何「括号计数器」，却把这条约束学到了
- **样例三 · Wikipedia 的 XML 转储**：`<page>`、`<title>`、`<text>` 等标签全部正确开合，文章编号递进、URL 格式合法——连「结构化数据」这种看似与语言天赋无关的东西也照学不误
- **样例四 · 教材的 LaTeX 源码**：`\begin{proof}` 有对应的 `\end{proof}`，小节编号按序递进，甚至画图的坐标代码都有模有样。LaTeX 环境配对比 HTML 标签更苛刻，照样拿下

四个样例合起来的论证力度：**同一套代码、同一个目标函数**，领域从戏剧到 C 到 XML 到 LaTeX 全部通吃——结构不是被教的，是被预测误差逼出来的。这是消融思想的反面用法：不靠「减掉组件看掉点」证明必要，靠四个领域的「涌现一致性」证明单一目标函数的充分。

## 5. 为什么在这份 List 里

1. **全 List 唯一「动手玩」的篇目**。别的篇目读论文，这篇你今晚就能跑一遍，亲眼看到「生成 = 预测」：一个能持续准确预测下一个字符的模型，必然已把数据里的规律（拼写、语法、缩进、配对）压进了权重，生成只是把压缩后的规律重新展开。这是「学习即压缩」的第一次直观体验，也是 → L21 MDL、→ L25 Kolmogorov 那条理论线的感官地基
2. **「涌现」的序列版第一次现身**。L01 的涌现是「规模推上去，分类能力断层」；这里的版本更便宜也更深刻——只优化一个朴素目标，没人教的层级结构自发出现。「模型 × 数据 × 算力 → 涌现」在序列任务上的同源证明
3. **「RNN = 有状态的迷你程序」是 Ilya 谱系里一脉相承的程序观**，直接通向 → L14 NTM（把记忆做成可读写的模块）乃至后来的神经可微编程

## 6. 织进网里

- **← L05 CS231n**：CNN 管线吃固定尺寸输入、吐固定类别输出；RNN 把权值共享从空间滑窗搬到时间滚动，输入输出从此任意长。两篇合读是「架构跟着数据形状走」的一组正反案例
- **← L01 AlexNet**：「让梯度活下去」主线在此换战场——ReLU 救的是空间深度的梯度；时间维度上梯度沿隐状态链连乘的问题这篇刚埋下，下一讲引爆
- **→ L07 Understanding LSTM**：本篇唯一但致命的局限——隐状态每步被完全重写，长依赖学不牢（生成越长，越容易「忘了」开头）。LSTM 的传送带就是来修这个的
- **→ L08 RNN 正则化**：字符级模型训起来并不省心，过拟合与训练稳定性是下一块工程拼图
- **→ L21 MDL / → L25 Kolmogorov**：「预测得好 ⇔ 压缩得好 ⇔ 学到了真规律」，这篇是这三者相等的最便宜实验室

## 自测题

1. 字符级语言模型训练时，监督信号怎么给？和「只预测序列末尾」的任务差在哪？
   > 每个时间步都以「下一个真实字符」为目标各算一份 loss、相加一起训——一次前向同时考所有位置；监督信号密度高到奢侈，这是字符级模型小数据也能学起来的原因之一。
2. 温度采样里 T=0.5 和 T=1.5 的样本分别什么样？调温改的是什么、不改的是什么？
   > T 低分布尖锐、保守通顺但爱重复，T 高分布抹平、多样放飞但语法崩坏；只改采样时对 logits 的缩放（探索率旋钮），不动训练好的权重。
3. 博客说「没人教模型语法」，括号配对到底是谁教的？规则写在损失函数里吗？
   > 不在。损失函数里只有「下一个字符的负对数似然」这一条；配对、缩进、嵌套这些长程规则是降低预测误差的最优手段，被数据逼出来的副产品——易混淆点就在「目标函数里没有语法」。
4. 隐状态的「传话人」角色带来什么收益、埋下什么病灶？这篇读完后自然通向哪一篇？
   > 收益：一段摘要传话，长度自适应、参数共享；病灶：每步被完全重写，前文信息不断冲刷、梯度沿时间链连乘衰减，长依赖学不牢——通向 L07，用加法为主、受门控的 cell state 传送带正面解决。
5. 「生成 = 预测 = 压缩」这句话怎么讲？它通向 List 的哪条线？
   > 能准确预测下一个字符，等价于已把数据规律压进权重，生成只是把压缩后的规律重新展开——「学习即压缩」的直观形态，通向 L21 MDL 权重与 L25 Kolmogorov 复杂度的理论线。
