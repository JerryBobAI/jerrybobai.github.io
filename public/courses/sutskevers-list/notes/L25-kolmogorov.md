# L25 · Kolmogorov Complexity — 「学习即压缩」的公理化地基

《An Introduction to Kolmogorov Complexity and Its Applications》(教材, 3rd ed. 2008, Springer) · Ming Li, Paul Vitányi · 章节「Complexity, Randomness, and Incompleteness」· [教材页](https://link.springer.com/book/10.1007/978-0-387-49820-1)

注意：这是这份 List 里唯一的教材条目。前三讲的压缩理论（L21/L22 的 MDL、L23 的 sophistication）反复引用的「最短描述」，全部压在这一章定义的量上——读它是给整批理论补地基。

## 1. 一句话

Kolmogorov 复杂度 `K(x)` = **打印出 x 并停机的最短程序长度——「x 压不压缩得动」的数学极限**；它对任何通用机器至多差一个常数（不变性定理，所以是对象的内在属性而非工具属性），不可计算（归功于停机问题）但可以从上方逼近（你能找到越来越短的程序，只是永远不知道是不是最短）——全课程「学习 = 找更短程序」的世界观，公理化地基就压在这一个定义上。

## 2. 它之前的世界：「乱」没有定义

1965 年之前，「随机」是概率论的领地，但概率论只会回答一类问题：给定分布 P，串 x 出现的概率多大。反过来问——**眼前这一个具体的串，随机吗？**——概率论哑口无言：单串没有概率属性，只有生成过程的属性。Shannon 熵同样是信源层面的期望：你可以说「公平硬币的信源熵是 1 bit/符号」，但「π 的前十亿位比某个随机表乱不乱」它管不着。

这是当时数学界真实的空白：直觉里「乱」明明分程度——千位硬币正反序列很乱，千位 π 小数也很乱，但你知道 π 能用十行程序算出来，硬币序列不能。**「乱」要成为科学概念，必须定义在对象本身上，而不是生成它的过程上。**

1965 年 Kolmogorov 给出答案（同期 Solomonoff 从归纳推理出发、Chaitin 独立提出）：**随机 = 不可压缩**。一个串是随机的，当且仅当不存在比它本身更短的程序能生成它。这一定义把「乱」从统计学问题变成描述长度问题——本章就是这条遗产的完整公理化。

## 3. 核心思想

### 3.1 定义：最短程序

固定一台通用图灵机 U：

```
K_U(x) = min { |p| : U(p) 输出 x 并停机 }
```

例：串「01 重复 500 次」（1000 字符）的程序约 30 字节——K ≈ 30；同长度的真随机串，最短程序基本只能「打印它自己」——K ≈ 1000+。**K 是压缩的极限**：任何压缩器（gzip、bzip、神经网络）压出来的长度都是 K 的上界近似——它们都是在有限程序空间里「找更短程序」，只是各有限制。

### 3.2 不变性定理：常数之差，工具无关

换一台通用机 V 会怎样？让 U 先执行一段「V 解释器」（模拟 V 的固定程序，长 `c_{U,V}`），再跑 V 的最短程序：`K_U(x) ≤ K_V(x) + c_{U,V}`。对换方向同理——**任意两台通用机的 K 至多差一个常数**，且常数与 x 无关。

这正是「内在属性」的含义：用 Python 还是 C 写压缩器、指令集怎么选，影响的只是那笔固定的解释开销；对象本身的可压缩性跨越工具稳定存在。类比：git diff 换算法差的是常数，两次提交的真实差异差的是量级。工程上可以放心谈「这个数据的 K 大概多大」——误差被常数吸收。

### 3.3 不可计算 + 从上方逼近

K 不可计算，而且**连可计算的上界函数都不存在**（不存在可计算的 f 使 `f(x) ≥ K(x)` 恒成立）。反证一击：若 f 存在，则程序「从小到大找第一个满足 `f(x) ≥ n` 的 x」能输出一个 `K(x) ≥ n` 的串，而这个程序本身只长 `log n + c`——n 大时自相矛盾。这是停机问题的化身：要断言「长度 ≤ n 的程序都不是 x 的更短程序」，等于断言一批程序都不停机——没人能做到。

但可以从上方逼近：枚举所有程序、陪着跑（dovetailing，白话短注：给每个程序轮流分时间片，让不会停机的程序也跑一点、却永远卡不死总调度），一旦谁打印出 x 就记下其长度——记录只降不升，收敛到 K。K 是 upper semicomputable（白话短注：能算出越来越紧的上界，但永远不知道离真值还有多远）。实践里 gzip 是钝刀、神经压缩器是快刀，都是这条逼近路上的不同位置——**你能找到越来越短的程序，但永远不知道是不是最短**。

### 3.4 随机性 = 不可压缩：π 的教训

计数论证一眼看清分布：长 n 的串共 `2^n` 个，而长度 < n−k 的程序至多 `2^{n−k}` 个——所以 **`K(x) < n−k` 的串占比 < 2^{−k}**：几乎所有串都不可压缩。Kolmogorov 随机串（`K(x) ≥ n − O(1)`）与 Martin-Löf 随机（通过一切可枚举统计检验）后来被证明等价——「压不动」与「过不了任何随机性检验」是同一件事的两种说法。

关键辨析是 π：前十亿位小数「看起来乱」、通过一切常见统计检验，但 spigot 算法十行——`K(π 的前 N 位) ≤ log N + O(1)`，深度可压缩。这就是伪随机（pseudo-random）：**随机性和「看起来乱」的区别不在长相，在压缩极限**——乱是表象，无结构才是本质；凡是能被短程序生成的「乱」，再乱也是伪随机。

顺手另一组辨析：K 与 Shannon 熵——Shannon 是分布层面的期望、给定分布可计算；K 是单串层面的量、不可计算。前者需要「信源」，后者什么都不需要——这正是第 2 节说的「定义在对象本身上」。

### 3.5 结构函数与 sophistication：勾回 L23

本章还埋着 L23 的伏笔：Kolmogorov 结构函数（structure function）——问「允许模型带 m 比特随机余项时，最短的模型描述多长」；把余项预算放松到恰好够用的临界点，对应模型的最小复杂度，就是 sophistication 的形式化老家。L23 的 complextropy、L24 的「粗粒化态压缩 ≈ K(S)」，都是这个家族在可计算世界里的代理——**「结构 + 余项」这套分账法，从 1965 年一路用到今天的表征学习**。

## 4. 章节怎么组织论证

教材章与论文不同，说服力在「定义—定理—反例」的骨架，外加把抽象钉在具体物上的大量例子：

- **定义先行，立刻免疫工具之争**：给出 K 后第一条定理就是不变性——先解除「换台机器怎么办」的疑虑，后面所有讨论才站得住
- **例子密集**：几乎每个抽象定义都跟着具体串、具体程序，定义与例子交替出现，把「最短程序」钉在可想象的物件上
- **正负结果交替推进**：不变性（正）→ 不可计算与无上界函数（负）→ 从上逼近（正）→ 几乎所有串不可压缩（正，计数定理）→ Berry 悖论的形式化与 Gödel 不完备的联线（更深的不可能性）——反复演练同一件事：**算法世界里什么能算、什么永远不能算**
- **概率化收尾**：从有限串的 K 走向无限序列的 Martin-Löf 随机与算法概率（Solomonoff 的 `2^{−K}` 先验）——为 L27 用 `2^{−K}` 给智能定纲铺好最后一段路
- **习题即定理**：不少核心事实放进习题——教材明示「这里要自己推才算懂」

## 5. 为什么在这份 List 里

1. **它是 L21/L22 MDL 的理论极限**。MDL 用真实压缩器找「最短描述」，K 是那个「最短」的严格定义——没有这一章，MDL 只是经验法则；有了这一章，它是「可计算近似与不可计算极限、关系明确」的纲领
2. **它是 L23/L24 的度量基础**。sophistication、complextropy、结构函数全部定义在 K 上；L24「压缩只能给上界」的实验纪律，就是 upper semicomputable 的现场执行
3. **它是全课程世界观的公理化地基**。「学习 = 找更短程序」——SGD 在可微空间里搜更短的隐式程序（L12 的架构是程序空间的先验），Scaling Laws 是搜索的统计规律（L20），VLAE 把码长写成损失（L26），Legg–Hutter 用 `2^{−K}` 给智能定纲（L27）。一份 AI 论文书单以一章 1960s 的理论教材压阵，Ilya 的立场写在选单上：**深度学习实践是这门理论的粗糙近似，而理论的纯粹形态值得先读懂**

## 自测题

1. `K(x)` 的定义是什么？为什么说它是「压缩的数学极限」？
   > K(x)=打印 x 并停机的最短程序长度；任何压缩器的输出都是 K 的上界近似——gzip/bzip/神经压缩器都是在有限程序空间里「找更短程序」，K 是它们逼近而不及的极限。
2. 不变性定理说了什么？为什么它让 K 成了「对象的属性」而非「工具的属性」？
   > 任意两台通用机的 K 至多差一个与 x 无关的常数（一台机器可携带另一台的解释器）：K_U(x) ≤ K_V(x)+c——换语言/机器只差常数，对象的可压缩性跨工具稳定，被长度增长吸收。
3. K 为什么不可计算？「可以从上方逼近」又是什么意思？
   > 无可计算上界函数（否则「第一个 K≥n 的 x」程序长 log n+c，自相矛盾；断言「无更短程序」=断言一批程序不停机）；从上逼近=枚举程序 dovetail 跑、记录只降不升收敛到 K——能找越来越短的程序，永远不知是否最短。
4. π 的前十亿位「看起来乱」却不随机——用 K 说清「伪随机」和「看起来乱」的区别。
   > 随机=不可压缩（K(x)≥n−O(1)，几乎所有串如此）；π 前 N 位可由 spigot 算法约 log N 位的程序生成——深度可压缩；乱是表象、无结构才是本质，能被短程序生成的乱再乱也是伪随机。
5. 本篇如何同时是 L21 MDL 的极限、L23 的地基、全课程世界观的公理化？
   > MDL 用真实压缩器逼近「最短描述」，K 给「最短」严格定义；sophistication/complextropy/结构函数定义在 K 上；「学习=找更短程序」——从 SGD 到 2^{−K} 智能定纲，全部压在这个定义上。
