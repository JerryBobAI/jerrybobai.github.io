# L05 · CS231n 课程笔记 — CNN 时代的完整操作手册

《Convolutional Neural Networks for Visual Recognition》课程笔记（2015 起） · Andrej Karpathy, Fei-Fei Li 等 · [cs231n.github.io](https://cs231n.github.io/)

清单里唯一不是论文的条目。前四篇讲的是 CNN 的「为什么」，这份课程笔记补全的是「怎么用」——从张量怎么摆、参数怎么算、训练怎么调，到经典架构怎么演化、拿到新任务怎么站在巨人肩膀上。它是一份操作手册，也是这份 List 唯一的「地基教材」席位。

## 1. 一句话

**CS231n 把卷积网络从「论文里的成果」拆成了「可动手的设计空间」**：每一层有坐标纸式的张量观、每一步训练有可诊断的信号、每一个经典架构都在谱系表上有坐标——读完它，前面四篇论文里的每个数字你都能亲手算出来。

## 2. 它之前的世界：论文是成果汇报，没人给你施工图

2015 年想入坑深度学习是什么体验？论文读得懂思想、读不懂细节——AlexNet 不会告诉你 `stride 4` 是怎么定的，ResNet 不会告诉你 1×1 卷积 Bottleneck 的显存账。开源代码凤毛麟角，PyTorch 要两年后才发布。

## 3. 核心思想

### 3.1 卷积层的坐标纸：一切设计从张量账开始

CS231n 给卷积层的第一份礼物是**张量观**：数据不是「图片」，是 `H × W × D` 的三维体（高、宽、通道深度）。卷积层做的事有三件套约定：

- **输出空间尺寸**：`out = (W − F + 2P) / S + 1`（W 输入边长、F 核边长、P 零填充、S 步幅）
- **参数量**：`(F · F · D_in + 1) · K`（一个核 F×F×D_in 个权重 + 1 个偏置，共 K 个核——勾连 L01：权值共享让参数量和图片大小无关，就是这条公式的直接读数）
- **输出深度 = 核的数量 K**：每个核扫整张图产出一个「观点图」

用这套账验算 AlexNet：conv1 用 96 个 11×11 核扫 224×224×3 输入（stride 4），参数 = `(11×11×3 + 1) × 96 ≈ 3.5 万`——6000 万参数的大头不在卷积而在全连接（fc6 一层就是 `7×7×256×4096 ≈ 1 亿级` 的量级账）。**会算这笔账，才叫「看懂」一个架构**；后来所有省参数的设计（1×1 降维、全局池化替代 FC）都是在这张账单上动刀。

### 3.2 感受野折算：每一层都在「借钱」看世界

卷积的隐账目是**感受野**：3×3 核叠两层，每个位置实际看的是 5×5 的输入区域。CS231n 给了折算直觉：每过一层，视野向两侧各扩 `(F−1)×下一层步幅乘积`。这条账连向 L04——空洞卷积的全部戏法，就是把「视野随深度的线性折算」改成指数折算，参数一分不加。

池化（pooling）在课程里被定位成「廉价的双重身份」：一半是降采样省算力，一半是「小幅平移不变」的先验注入——但代价是位置信息不可逆丢失（L04 讲过，这对分割是灾难）。**学完操作手册再看论文，你会看到每个设计选择都在这张利弊表上**。

### 3.3 训练实战包：从损失曲线读出病灶

课程的后半部分是一套**诊断手册**——训练不收敛时按什么顺序查：

- **初始化不能全零**：所有神经元同起点 → 同梯度 → 永远学成同一个东西（对称性不破除）。要小随机数，最好配 He/Xavier 方差标定——否则信号逐层放大或衰减，又是「让梯度活下去」主线的前哨
- **SGD + 动量**：动量 = 重球滚下山坡，震荡方向互相抵消、一致方向加速——训练曲线抖动立刻变小
- **学习率是第一超参**：loss 爆炸 → 太大；loss 龟速 → 太小；配合阶梯衰减（每若干 epoch 砍半）
- **过拟合三板斧**：数据增强（L01 的裁剪/翻转）、Dropout（L01 的随机失活）、L2 正则
- **BatchNorm**：把每层输入分布拉回稳定区间，训练对学习率的敏感度大降（L02 说过：ResNet 能用大学习率，BN 是幕后搭档）

这套手册的价值不在知识点本身（今天每一条都有更好的替代），而在**「训练是可诊断的工程」这个视角**——出了问题不是玄学，是按 checklist 排查的工程活。

### 3.4 架构谱系表：给四篇论文装上坐标系

CS231n 的经典架构章节把 2012-2015 的演化画成一条谱系：

```
LeNet (1998)   手写数字,5 层,卷积思想验证
   ↓
AlexNet (2012)  L01  GPU+大数据引爆,大核大步猛压分辨率
   ↓
VGG (2014)      全网 3×3 小核堆深度——「小核多次」优于「大核一次」
   ↓
GoogLeNet (2014) Inception 并行多尺度分支 + 1×1 卷积降维省算力
   ↓
ResNet (2015)   L02  跳连解锁百层,深度成为超能力
```

两个谱系级规律值得划线：**小核化**（11×11 → 3×3，参数省、非线性多、视野靠堆叠补）和**省算力化**（1×1 降维、全局池化替代全连接）——几乎此后所有 CNN 设计都在这两个方向上继续走。读论文时把新架构往这张表上一放，它的「新」在哪里立刻显形。

### 3.5 迁移学习：别从零训，站在 ImageNet 肩膀上

CS231n 传播最广的实战观点是**迁移学习（transfer learning）**：把在 ImageNet 上训好的模型拿来，换掉最后的分类头，用自己的小数据微调。操作手册给了张决策表：

| 你的数据量 | 做法 |
|---|---|
| 很少（几百张） | 冻结全部卷积层只训新分类头（线性分类器） |
| 中等 | 冻结浅层（通用边缘/纹理），微调高层 |
| 很多（百万级） | 全网微调，预训练权重只当起点 |

理论根据就是 L01 那个「4096 维语义指纹」发现——倒数第二层学到的通用视觉表示，本来就是可迁移的。**「预训练→微调」从此成为深度学习的默认工作方式**，GPT 时代的「预训练大模型 + 下游微调」是同一根思想线的直系后代。

## 4. 课程怎么展开论证

作为教材，CS231n 的叙事结构本身值得学：**每一章回答上一章遗留的问题**——讲完卷积就问「那池化必要吗」，讲完全连接就问「参数爆炸怎么办」，讲完训练流程就问「为什么我的 loss 不降」。问题驱动的展开，让每个设计选择都带着「不这样会怎样」的反事实。

这种「从像素到决策」的推演链，正是前四篇论文缺的那口气：论文告诉你「我们这么设计赢了」，课程笔记告诉你「为什么你会想到这么设计」。两相对照，才是完整的学习闭环——这也是它和 L13（把 Transformer 逐行写成代码）共享的教学法基因：**理解 = 能重造**。

## 自测题

1. 输入 32×32×3，用 10 个 5×5 核、stride 1、padding 2 卷积，输出尺寸和参数量各是多少？
   > 输出 32×32×10（(32−5+4)/1+1=32）；参数 (5×5×3+1)×10=760——输出深度=核数，参数量与图片大小无关（权值共享）。
2. 为什么权重不能初始化为全零？正确的做法是什么？
   > 全零导致所有神经元同起点同梯度、永远学成同一个东西（对称性不破除）；要用小随机数并配 He/Xavier 方差标定，防止信号逐层放大或衰减。
3. 迁移学习的决策表：你的数据「很少/中等/很多」时各怎么微调？理论根据是 L01 的哪个发现？
   > 很少=冻结卷积只训分类头；中等=冻结浅层微调高层；很多=全网微调。根据是 AlexNet 倒数第二层 4096 维「语义指纹」是可迁移的通用视觉表示。
4. 经典架构谱系里，VGG 和 GoogLeNet 各自代表哪条演化方向？
   > VGG=小核化（全网 3×3，「小核多次」优于「大核一次」，非线性更多）；GoogLeNet=省算力化（Inception 并行多尺度分支+1×1 卷积降维）。
5. CS231n 作为教材的叙事结构有什么特点？它补上了论文的哪一块？
   > 每章回答上一章遗留的问题（问题驱动展开，每个设计带「不这样会怎样」的反事实）；论文给「这么设计赢了」，它给「为什么会想到这么设计」——补上从成果汇报到施工图的断层。
