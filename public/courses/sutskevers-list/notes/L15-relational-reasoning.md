# L15 · Relation Networks — 关系不是学出来的，是长在架构里的

《A Simple Neural Network Module for Relational Reasoning》(2017, NeurIPS) · Adam Santoro, David Raposo, David G.T. Barrett, Mateusz Malinowski, Razvan Pascanu, Peter Battaglia, Timothy Lillicrap · DeepMind · [arXiv:1706.01427](https://arxiv.org/abs/1706.01427)

## 1. 一句话

关系网络 `RN`(Relation Network)用一个近乎笨拙的公式 **f(Σ g(o_i, o_j))——把所有物体两两配对、逐对推断关系、再求和汇总**——把「关系推理」从「指望网络自己从数据里悟出来」变成「架构自带的能力」。一个模块插上去，`CLEVR` 视觉问答从当时最好的 68.5% 直接跳到 95.5%，超过人类。它的宣言式论点：关系推理应该是**架构先验**，不是学出来的副产品。

## 2. 它之前的世界：CNN 认得每个物体，却看不见「关系」

术语白话：**关系推理(relational reasoning)**=判断「谁和谁有什么瓜葛」的能力——红方块在绿球左边、A 比 B 大、哪两颗球被隐形弹簧连着。

人类把「关系」当内置思维原语：小孩比较两棵树谁离得远，不需要先上「距离比较课」。但对神经网络，关系是老大难：符号主义 AI(逻辑、规则)天生擅长关系，却被「符号接地」问题困住——符号接不上真实世界的像素与噪声，任务一变就脆；深度学习 robust、能从原始数据学表示，却把关系当成「要从数据里学的东西」，数据一少就学不动。

论文用 `CLEVR`(3D 渲染物体 + 组合式问题的视觉问答基准，专为压榨推理设计)把这件事钉死。当时最强的视觉问答架构(ResNet-101 图像嵌入 + LSTM 问题编码 + 堆叠注意力)整体 68.5%，远低于人类的 92.6%；更扎眼的是，在「比较属性」「数数」这类**关系密集**题型上，它和「只按题型猜高频答案」的基线差不多——大家以为瓶颈在视觉处理或语言解析，其实是**推理结构本身缺失**。

## 3. 核心思想

### 3.1 公式：三个零件，一个比一个朴素

RN 的全部定义就一行：

```
RN(O) = f_φ( Σ_{i,j} g_θ(o_i, o_j) )
```

输入 O = {o₁, o₂， …， oₙ} 是一组「物体」向量。逐个拆：

- **g_θ(配对打特征)**：每对物体过一个 MLP，输出就叫「关系」——这两个东西之间有什么瓜葛(甚至有没有瓜葛)。注意 g 不对称：「A 比 B 大」和「B 比 A 大」是两种不同的输入
- **Σ(求和)**：把所有对的关系特征**加总**。直觉：关系推理是大海捞针，但针可能藏在任何一对里——所以别赌哪对重要，把每一对都查一遍，线索累加。求和还白送一个性质：**输出与物体顺序无关**(集合无序，呼应 → L09 Order Matters)
- **f_φ(汇总)**：把累加的关系线索综合成最终输出，也是一个 MLP

三个零件全部可微，端到端训练。图上看，RN 把输入当成**全连接有向图**：物体是节点，每一对都有一条边，g 就是跑在每条边上的函数。

### 3.2 为什么「笨办法」反而省学习成本

表面看，n 个物体要跑 n² 次 g，像在浪费算力；MLP 一次性吃下全部物体不是更快?论文算的是另一笔账：MLP 要在**一份权重里同时学会 n² 个位置各异的同款关系函数**(每个位置都要单独学一遍)；RN 只学**一个** g，共享给所有对——「学 n² 次」变成「学 1 次、跑 n² 次」。这是权值共享思想(→ L01 AlexNet 的卷积核滑遍全图)在关系域的复刻：用计算换泛化，不让 g 过拟合到任何特定物体对。

### 3.3 即插即用：「物体」可以从像素里长出来

RN 吃的是「物体向量」，但论文最妙的一步是：**不需要物体检测器**。像素版的做法：图像过一个相当朴素的 4 层 CNN，得到 d×d 的特征图；把每个空间格子的 k 维向量(附上坐标标签)直接当一个「物体」。至于它对应背景、整个物体还是局部拼块——不管，让训练把「object-like 表示」从上游**诱导**出来。

问题也要进来：「大球在哪」和「有几个大球」关心的关系不同，所以 g 加一个条件槽：a = f_φ(Σ g_θ(o_i, o_j, q))，q 是 LSTM 编码的问题向量。

这引出论文的点睛区分——**processing vs reasoning(处理 vs 推理)**：CNN 是强大的视觉处理器，但未必是好的推理器；插上 RN 后，CNN 被解放去专心干局部视觉处理，推理交给架构里专门的那块。

## 4. 实验逻辑

- **关键对照 Sort-of-CLEVR**(自制简化版，关系题/非关系题分开)：同一个 CNN，配 MLP 在非关系题上轻松、关系题卡死在 63%(「离某物最近/最远」题型只有 52.3%,接近瞎猜)；换成配 RN，两类题都上 94%。**证明 CLEVR 难在关系推理容量，不在语言解析**——全文最干净的一块证据
- **主战场 CLEVR(像素)**：95.5%，超人类(92.6%)，比数据集发布时最强像素模型高 27 个百分点；用的 CNN 小、不精调 ResNet、不靠「问题生成程序」这类特权监督(同期 96.9% 的模型用了)
- **状态向量版 CLEVR**(直接给每个物体的坐标/颜色/材质)：96.4%——RN 对输入形态不挑
- **文本问答 bAbI**(`bAbI`:20 个纯文本推理小任务，正确率过 95% 算「通过」)：把每句话过 LSTM 当「物体」，20 个任务联合训练通过 **18/20**；基础归纳题错误率 2.1%，同期 `DNC`、`EntNet` 等记忆网络在同一题上 52-55% 错误率翻车；两个没过的任务也只差门槛 3.1% 和 11.5%，没有灾难性失败
- **动态物理系统**：桌面 10 颗球，部分球对被隐形弹簧/刚性杆连着——从 16 帧轨迹推断「谁和谁连着」正确率 93%，数「连成几组」95%；同规模 MLP 接近随机。学到的关系推断还能迁移到人体动捕数据，预测走路时的关节连接

消融主线一句话：任何实验里把 RN 换成同规模 MLP，关系题立刻塌方。

## 5. 为什么在这份 List 里

1. **「架构 = 先验」的第二次宣示**。L01 的结论：CNN 把「相邻像素相关」焊进架构，打乱像素就崩。RN 把「输出应是物体两两关系的函数」焊进架构——**约束即能力**：先承认世界由实体和关系组成，模型就不用再从数据里猜这件事。它与「模型×数据×算力」不冲突，而是另一面：好先验换来数据效率，让同样的算力解更难的题
2. **处理与推理分离**的视角：强视觉骨干负责处理，专门结构负责推理。这个分工后来长成「大模型 + 结构/工具」的思路
3. 它是 DeepMind 关系推理系列的起点(Santoro、Battaglia 班底)，直接通向图网络时代——下一篇搬进时间，第三篇搬进分子

## 6. 织进网里

- **← L01 AlexNet**：架构=先验。CNN 焊「平移不变」，RN 焊「万物成对相关」；先验的另一面是盲区——打乱像素崩 CNN，打乱配对结构同样崩 RN
- **← L09 Order Matters**：集合无序性。RN 的 Σ 求和必须顺序无关，和 set2set 解决的是同一个「集合不是序列」问题
- **→ L16 关系 RNN**：RN 从「空间里的物体」搬进「时间里的记忆」——记忆不再是胶卷，而是一组随时互连的 slot
- **→ L17 MPNN**：全配对 RN 就是「完全图上的消息传递」；MPNN 把它推广到按真实结构稀疏传信
- **→ L12 Transformer**：g(o_i, o_j, q) 的「逐对打分 + 汇总」与注意力的「QK 打分 + 加权和」同构；RN 是所有对无差别算满，注意力是学会软选择哪些对值得算——论文结尾自己也预言：用注意力过滤不重要的对，破解 n² 复杂度

## 自测题

1. RN 公式 f(Σ g(o_i, o_j)) 三个零件各干什么?求和 Σ 为什么必须有?
   > g 给每对物体打「关系」特征、Σ 把所有对的线索加总、f 综合输出；Σ 同时保证顺序不变性——关系是无序集合上的函数，排列变了输出不能变。
2. RN 和一次性吃下所有物体的 MLP 比，「学习成本」省在哪?
   > MLP 要在一份权重里学会 n² 个位置各异的同款关系函数；RN 只学一个 g 共享所有对——「学 n² 次」变「学 1 次、跑 n² 次」，用计算换泛化(权值共享思想)。
3. 易混淆：Sort-of-CLEVR 的对照说明了什么?大家原以为 CLEVR 难在哪，实际难在哪?
   > 同一 CNN 配 MLP 非关系题轻松、关系题卡 63%(最近/最远题仅 52.3%)，配 RN 两类都 94%+；说明难在关系推理容量缺失，不是语言解析或视觉处理。
4. 跨篇：RN 与 L12 Transformer 的注意力是什么关系?
   > 同构：逐对函数 g(o_i,o_j,q) 约等于 QK 打分，Σ 约等于加权求和；差别在 RN 全配对无差别算满，注意力软选择值得算的对——论文结尾自己提出用注意力破解 n² 复杂度。
5. 方法论：RN 把什么变成了架构先验?它和 L01 的「架构=先验」如何互相印证?
   > 把「输出应是物体两两关系的函数」焊死在网络形态里(如 CNN 焊平移不变)；能力来自约束——先承认世界由实体+关系组成，模型不必从数据猜起，换来数据效率，代价是对非关系结构不敏感。
