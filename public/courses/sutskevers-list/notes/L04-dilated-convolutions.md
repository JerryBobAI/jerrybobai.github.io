# L04 · Dilated Convolutions — 不花一分钱的大视野

《Multi-Scale Context Aggregation by Dilated Convolutions》(2016, ICLR) · Fisher Yu, Vladlen Koltun · [arXiv:1511.07122](https://arxiv.org/abs/1511.07122)

## 1. 一句话

空洞卷积干的事：**卷积核的 9 个权重不动，只是把采样点「隔开撒」**——3×3 的核立刻拥有 5×5、9×9 甚至覆盖全图的视野，而**参数不增一个、分辨率不降一格**。这个几乎零成本的改动解决了密集预测任务（语义分割）的核心矛盾，也把「感受野」从一个被动副产品变成了主动设计参数。

## 2. 它之前的世界：分类网络的「特性」变成分割的「灾难」

前三篇都在讲**分类**任务——整张图吐一个标签。但视觉还有一大类任务叫**密集预测（dense prediction）**：语义分割（每个像素属于什么物体）、深度估计（每个像素离相机多远）。注意区别：分类是「图里有狗」，分割是「**这 37 万个像素每一个**各自属于什么」。

这里撞上了分类 CNN 的原罪。回忆 AlexNet 的设计：`pooling / stride` 逐级把分辨率减半——224 → 112 → 56 → 28 → 14 → 7。这在分类网络里是**特性**：分辨率降、感受野涨、语义越来越抽象，最后 7×7 的特征图「浓缩」了整图的判断依据，正好喂给分类头。

但对分割是**灾难**：你需要在 224×224 的原图上逐像素输出，而手里的特征图已经被压成 7×7 的马赛克——**位置信息在降采样中不可逆地丢掉了**（pooling 是有损压缩）。2015 年的 FCN（全卷积网络）开创了端到端分割：把全连接改成卷积，再用**上采样**把 7×7 粗糙特征放大回 224×224。但那本质是「先把照片压成马赛克，再努力把马赛克糊回照片」——放大只能插值，细节回不来了。

于是当时的核心两难：

- **要大视野**（context：判断一个像素是「毛」还是「草地」，得看它周围一大片）→ 传统做法是降采样或堆大核
- **要高分辨率**（边界到底在哪，像素级精度）→ 不能丢信息

视野和分辨率，在当时的设计空间里是**跷跷板**：一头起一头落。这篇论文说：不用跷跷板，两个都要。

## 3. 核心思想

### 3.1 空洞卷积：换一种「读法」，不换「眼睛」

标准 3×3 卷积：核贴着输入滑过，每次看紧挨着的 9 个像素。

**空洞卷积（dilation rate = r）**：9 个权重一模一样，但采样点之间**隔 r−1 个像素**——

```
r=1:  ●●●        r=2:  ● ● ●      r=4:  ● · · ● · · ●
     ●●●             ●       ●
     ●●●          ●  ●●●  ●     （● = 采样点，· = 跳过的像素）
                     ●       ●
                  ● ● ●
视野 3×3          视野 5×5          视野 9×9
参数 9 个         参数 9 个          参数 9 个
```

关键账目：**参数量不变（9 个权重）、计算量不变、输出分辨率不降**——视野从 3×3 涨到 9×9，没花任何代价。靠的不是更多参数，而是**采样点的排列方式**。

类比读报纸：普通卷积是逐字读，空洞卷积是**跳读**——同样读 9 个字，跳着读扫过一整段，要点照样抓住。你的识字能力（参数）没变，读法变了。

数学上它等价于「把核内部插零膨胀后再做标准卷积」，所以叫 dilated（膨胀）；也叫 atrous（法语「筛子」——像用筛子筛像素）。

### 3.2 真正的魔法：堆叠时视野指数增长

单层 r=4 只是 9×9 视野，不算惊人。威力在**逐层堆叠、dilation 逐层翻倍**：

```
r = 1, 1, 2, 4, 8, 16, 16 ...
```

每过一层，感受野大致翻倍——7 层之后视野覆盖整张图。对比两条增长曲线：

- 堆 L 层普通 3×3：感受野 = 2L+1，**线性**（VGG 堆 10 层才 21×21）
- 堆 L 层 dilation 翻倍：感受野 ≈ 2^L，**指数**（7 层就 100+）

而且整条链上**没有任何 pooling、没有任何分辨率损失**——像素级信息从头保到尾。这就是「视野与分辨率兼得」的完整答案。

### 3.3 怎么用：一个即插即用的「上下文模块」

论文的实验载体是一个 **context module**：接在分类 backbone（VGG）中段，7 层空洞卷积按 1,1,2,4,8,16,16 堆叠，做「多尺度上下文聚合」；模块内部用**逐点相加的残差连接**（又一个 ResNet 思想的就近应用）。同时把 VGG 前端里最后两级 pooling 的降采样拆掉、换成 r=2 的空洞卷积——保住中间特征图的分辨率。

### 3.4 边界与诚实：gridding 问题

这个技术后来被发现有一个隐患，值得你知道（论文本身没解决）：当 dilation 大、且连续大 dilation 堆叠时，采样点之间出现**大块「从未被看过」的盲区**——特征图上产生棋盘状的格纹（gridding artifact）。直觉：跳读扫要点可以，但跳得太狠，句子中间的关键字全跳过去了。后续工作（HDC 等分解 dilation、DeepLab 的图像级金字塔）都在修补这个洞。这提醒我们「免费午餐」也有边界：**采样上的免费，代价是对「均匀覆盖」的偏离**。

## 4. 实验逻辑

- **战场**：PASCAL VOC 2012 语义分割（该领域标准基准，20 类物体 + 背景，指标 mIoU——每个类别的预测区域和真实区域的重叠率均值）
- **消融链条**（干净利落）：
  - 改造前端（VGG 去降采样 + 空洞卷积）单独：**68.7 mIoU**
  - + 基础 context module（视野到 r=16）：**73.5**
  - + 扩大版 context module（通道翻倍）：**74.7**——当时最优水平，超过了需要 CRF（条件随机场，一种传统后处理）才能到 71.6 的 DeepLab，而且**不需要任何后处理**
- **关键对照**：同参数量的 context module，把 dilation 全设为 1（即纯多堆几层普通卷积）明显更差——证明涨点来自**多尺度视野本身**，不是单纯多加了几层

直系后代：DeepLab v2 的 **ASPP**（并行多分支、不同 r 的空洞卷积再融合）成为分割工业标准的标配；UNet 系、医学影像分割、扩散模型的 U-Net 骨架里都有它的影子。

## 5. 为什么在这份 List 里

Ilya 没有公开讲过为什么选这篇（不像前两篇有明确的世界观线索），从论文本身的地位看，它补全了这张拼图上**正交的一块**：

1. **「感受野」是和「深度」同级的架构自由度**。前三篇走的是垂直轴（怎么深），这篇走水平轴（怎么看宽）。读完这批，你手里有了 CNN 设计的完整坐标系：深度（ResNet）、通路（Identity Mappings）、视野（本篇）
2. **「结构重排白拿性能」的又一案例**：不加参数、不加数据、不动优化器，只改采样排列就解锁新任务能力——和 ResNet「重排 ReLU 位置白拿一截」是同一类智慧。这条「聪明排列 > 暴力堆料」的暗线，Ilya 显然欣赏
3. 它是分割这条线的枢纽（FCN → 本篇 → DeepLab/UNet），而分割是「视觉从认物体到理解空间结构」的必经之路

## 6. 织进网里

- **← L01 AlexNet**：conv1 的 11×11 大核（96×121≈1.2 万参数）买大视野；空洞卷积 9 个参数看 9×9——同一诉求的两次求解，后者优雅得多
- **← L02/L03 ResNet 线**：垂直轴 vs 水平轴；context module 内部的逐点相加也是残差思想的就近应用
- **→ L12 Transformer**：这是本篇埋的最大伏笔——**自注意力一步把视野推到全局**，每个 token 直接看所有 token，感受野问题被彻底溶解。空洞卷积再怎么指数增长也只是「逼近全局」，注意力天生全局。演化终点：CNN 费尽心思扩视野 → Transformer 直接宣布视野问题不存在
- **→ 视觉 Transformer / Swin**：「多尺度」在 Transformer 时代以窗口层级的形式还魂——同一物体在不同图里大小不同，是视觉的永恒问题，换架构也逃不掉

## 自测题

1. 密集预测和分类的核心区别是什么？为什么降采样对分类是特性、对分割是灾难？
   > 分类整图一个标签，分割逐像素输出；降采样丢位置信息不可逆——分类只需要「浓缩判断依据」（特性），分割需要像素级边界（马赛克放大只能插值，细节回不来）。
2. r=2 的 3×3 空洞卷积，参数量 / 计算量 / 视野各是多少？它靠什么「免费」扩大视野？
   > 参数 9 个、计算量不变、视野 5×5；靠采样点隔开撒（排列方式），等价于核内插零膨胀，不靠加参数。
3. dilation 逐层翻倍（1,2,4,8…）堆叠时视野怎么增长？普通 3×3 堆叠呢？
   > 翻倍堆叠视野 ≈ 2^L 指数增长（7 层 100+），普通 3×3 堆叠是 2L+1 线性（10 层才 21×21）；且空洞链全程无分辨率损失。
4. 空洞卷积和自注意力在「视野」问题上的本质区别是什么？
   > 空洞卷积再指数增长也只是「逼近全局」，注意力天生一步全局（每 token 直接看所有 token）——CNN 费尽心思扩视野，Transformer 直接宣布视野问题不存在。
5. gridding 问题的成因是什么？它暴露了「免费午餐」的什么边界？
   > 连续大 dilation 采样点间出现从未被看过的盲区，特征图呈棋盘格纹；免费来自采样排列，代价是对均匀覆盖的偏离——跳读太狠会漏掉句子中间的关键字。
