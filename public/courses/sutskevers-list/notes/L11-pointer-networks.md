
# L11 · Pointer Networks — 注意力从配料升为主菜：输出直接「指」向输入

《Pointer Networks》(2015, NIPS) · Oriol Vinyals, Meire Fortunato, Navdeep Jaitly · [arXiv:1506.03134](https://arxiv.org/abs/1506.03134)

## 1. 一句话

Ptr-Net 对 L10 的注意力只动了一行手术：**softmax 权重不再混进上下文当配料，直接当作输出分布用**——每步输出不再是词表上的分布，而是「输入位置」上的分布，指到哪输出哪。这解锁了一整类任务：**输出字典大小随输入长度变化**的问题（凸包、三角剖分、TSP——答案都是「输入里的某些点」），还买一送一学到长度外推：n=50 训的模型，n=100 照样指得动。

## 2. 它之前的世界：一张铺死在固定词表上的输出层

seq2seq（→ L10 的骨架）有个从未被质疑的前提：解码器每步输出一个 softmax 分布，**铺在一张事先定死的输出词表上**。翻译词表固定 3 万词没问题；但有一大类任务的「词表」天生固定不了：

- **凸包**（把平面点集全围住的最小凸多边形）：答案是输入点的子序列
- **Delaunay 三角剖分**（连三角形网格，每个三角形外接圆内不含其他点）：答案是输入点连成的三角形列表
- **旅行商问题 TSP**（每城恰好访问一次、总路程最短的回路，NP-hard）：答案是输入点的一个排列

三个答案的「字典」就是输入点本身：**n 个点进来，词表就有 n 个词；n 一变，词表跟着变**。seq2seq 在此失语：为 n=50 训的模型输出层就是 50 个槽位，喂 n=60 连合法输出都产不出，只能每个 n 单独训一个。

有人会想：绕开索引，直接回归输出坐标？论文点破此路不通：回归坐标**不再精确绑定输入里的点**，序列一长误差累积、预测发虚（类比视频 seq2seq 越生成越糊）。几何答案必须「指得回去」。

注意这个陷阱：直觉会说「组合优化太难，神经网络做不了」。这篇的回答：**不是任务太难，是输出接口设计错了**。换个接口，问题从「做不了」变成「能学」。

## 3. 核心思想

### 3.1 两个前作的死状，一行手术的刀口

先看凸包（n=50 训 / n=50 测）上两个 baseline 的死状：裸 seq2seq（LSTM）准确率 **1.9%**，多数输出连简单多边形（不自交封闭图形）都构不成；加 L10 式输入注意力涨到 **38.9%**——注意力确实帮着读输入，但输出层仍铺死在 50 个槽上，换个 n 又得重训。

Ptr-Net 的刀口，对比看最清楚：

```
L10 Bahdanau attention（读）:
    u_j = vᵀ·tanh(W₁·e_j + W₂·d_i)     # 对每个输入位置打分
    a   = softmax(u)
    c_i = Σ a_j·e_j                    # ★ 权重是配料：混成上下文
    输出 = 词表 softmax(…)             # 词表固定 → n 变就死

L11 Ptr-Net（指）:
    u_j = vᵀ·tanh(W₁·e_j + W₂·d_i)     # 打分一字不改
    p(C_i | C_{<i}, P) = softmax(u)    # ★ 权重直接就是输出分布
    输出 = 第 j 个输入点               # 词典 = 输入，自动随 n 变
```

打分公式没动，动的是权重的**用途**：从「混合上下文的原料」升为「答案本身」。开卷比喻续上：L10 划完重点仍要**用自己的话写答案**，Ptr-Net 的考题就是「书中第几行」，照抄页码即满分。工程类比：从「检索+改写」变「检索即答案」——返回引用的搜索 API，而非改写型摘要器。

### 3.2 剩下的接口改造：让「词表」从链路里消失

两处配套改动：编码器吃的不再是词向量，而是每个点的**坐标 (x,y)**；解码器要「记得」上一步指了谁——**把上一步指中的输入点 P_{C_{i-1}} 直接复制**当本步输入，不喂输出 embedding。输出字典恒等于输入长度 n——变长输出字典问题从架构上消灭。

### 3.3 通用抽象：「输出 = 输入位置上的序列」

退一步看三个任务共享的形状：**输出 = 输入位置上的序列**——排序、最短路、拷贝、引用、检索全是这个形状。它直通后来的「选择类」机制：copy（从源文本拷词）、pointer-generator 摘要（生成与拷贝按概率混合）、检索增强 RAG（先「指」出相关段落再作答）——本质都是把 softmax-over-positions 当作输出或一部分。L12 的 QK 点积只改打分方式，「权重 = 对位置的分布」原样传了下去。

### 3.4 长度外推：n=50 训练，n=100 照样指

训练 n≤50，测 n=100、200 甚至 500 仍能工作：准确率随距离衰减但远好于随机，面积覆盖一直在 99% 上下——指得没那么准，围出的**形状**还是对的。为什么能外推？打分对**每个输入位置独立计算**，softmax 天然长度自适应；模型学到的是凸包的**几何规则**（哪些点该围住、沿什么方向走），不是 50 格查找表。用「学习即压缩」的话说：训练分布被压进了可外推的规律——压缩成功，即泛化。

## 4. 实验逻辑

三个平面几何任务，输入都是 [0,1]×[0,1] 均匀采样的点集，输出都是索引序列；同一套架构（单层 LSTM，256/512 隐单元，每任务 100 万样本对）通吃、不逐任务调参——「简单且通用」本身就是论证。

- **凸包**：先看 baseline 死状（§3.1 的 1.9% 与 38.9%）；Ptr-Net 在 n=50 达 **99.9%**。论文还讲了个寻宝故事：裸 seq2seq 对「凸包点出现在输入尾部」很差，加输入注意力大涨；作者检查注意力在看什么，发现它**正「指着」正确答案**——这一眼催生了 Ptr-Net。混合长度（5-50）训练的单模型：n=5 92.0%、n=10 87.0%、n=50 69.6%、n=100 50.3%、n=200 22.1%、n=500 1.3%（面积覆盖始终 99%+）——外推 10 倍仍能指
- **Delaunay 三角剖分**：输出本质是集合，论文按三角形内心的字典序排序消除歧义——不排序明显变差（← L09 的呼应）。n=5 时 80.7% 全对，n=10 时 22.6%，n=50 无一全对但三角形覆盖 52.8%——距离精确解尚远，论文没有粉饰
- **TSP**：精确标签用 Held-Karp 动态规划（O(2ⁿ·n²)）只造到 n=20，更大规模拿近似算法的解当标签（A1/A2 为 O(n²)，A3 为 Christofides 算法、保证不超最优 1.5 倍）。5-20 精确数据训练：n=25 几乎完美，n=30 不错，n≥40 崩（仍远好于随机）。最有意思的发现：**拿最差近似算法 A1 的解当标签，学出的模型反而比 A1 更短**——模型在大量次优样本里「平均」出更好策略，模仿超越了老师。诚实的边界：TSP 须约束 beam search（保留多条候选的近似搜索）只产出合法回路，否则 n>20 时 10% 以上实例非法

## 5. 为什么在这份 List 里

1. **注意力三部曲的中坚**：L10 学会「读」，本篇学会「指」，L12 注意力干脆取代循环本身。作者线也接得上——Vinyals 是 seq2seq（Ilya 直系工作）的一作，致谢里明写感谢 Ilya 讨论
2. **「学习即压缩」的实证样本**：n=50 训、n=100-500 部分可用，说明压进参数的是规则（算法形状）而非查找表；纯数据驱动学出 NP-hard 的近似解，是「算法可学习」的早期存在性证明
3. **接口发明的眼光**：大家以为 seq2seq 做不了组合优化是能力问题，论文证明是接口问题——「输出绑定输入位置」让排序、组合优化、copy、检索共享同一出口。今天 LLM 引用原文、工具调用返回索引，祖坟都在这篇

## 6. 织进网里

- **← L10 Bahdanau Attention**：打分公式一字未改，α_ij 从配料升为主菜；解码输入从词向量换成上一步指中的点坐标。注意力语义从「读」变「指」
- **← L09 Order Matters**：同一作者 Vinyals 的姊妹篇——那篇给集合/排列定输出规范，本篇给变长输出字典换接口，合起来是「神经网络做离散问题」的接口工程
- **→ L12 Transformer**：三部曲终点：QK 点积取代 additive 打分，softmax-over-positions 原样继承；多头、因果掩码都是在这个分布上的工程化
- **→ L14 Neural Turing Machines**：论文自己点名：内容寻址的外部记忆同样是「对位置做分布」，Ptr-Net 思路可直接搬过去

## 自测题

1. Ptr-Net 对 L10 注意力做的那「一行手术」是什么？为什么输出字典随输入变长不再致命？
   > 删掉加权混合 c_i=Σa_j·e_j 这步，p(C_i|·)=softmax(u) 直接当输出分布；词典=输入位置，大小恒等于 n，随输入变长。
2. 除打分外，Ptr-Net 的两处接口配套改动是什么？
   > 编码器输入换成点的坐标 (x,y)；解码器把上一步指中的输入点 P_{C_{i-1}} 直接复制当本步输入（不喂词 embedding）。
3. L10 的 +attention 为什么救不了凸包 baseline（只到 38.9%）？L10「读」与 L11「指」的差别一句话是什么？
   > 注意力只改善「读输入」，输出 softmax 仍铺死在 n 个槽上，换 n 必须重训；差别：L10 权重是配料（读），Ptr-Net 权重就是答案（指）。
4. 「注意力即选择」这条线 L10→L11→L12 三步怎么走的？
   > L10 权重混成上下文（读），L11 权重直接当输出分布（指），L12 QK 点积取代循环、注意力即网络；softmax-over-positions 三级跳，直通 copy/检索增强。
5. 「学习即压缩」在长度外推上如何体现？这条论证的边界在哪？
   > 压进参数的是规则（算法形状）而非查找表——压缩成功=可外推=泛化；边界：外推随距离衰减（n=500 准确率 1.3%、TSP n≥40 崩），学到的是近似解。
