# L08 · RNN Regularization — Dropout 打错位置，会毁掉记忆

《Recurrent Neural Network Regularization》(2014) · Wojciech Zaremba, **Ilya Sutskever**, Oriol Vinyals · [arXiv:1409.2329](https://arxiv.org/abs/1409.2329)

注意作者栏：**Ilya 是二作**，三作 Oriol Vinyals 则是接下来几篇序列故事的主角。这不是「别人顺手做的小改进」——这是 Ilya 序列军团在向大模型进军路上，亲手排除的一颗地雷。

## 1. 一句话

Dropout（训练时随机丢弃神经元，L01 讲过的正则化主力）搬进 LSTM 时有个致命细节：**打在循环连接上，每步重采样的噪声随时间累积放大，几十步后直接毁掉记忆；打在非循环的投影处（输入→隐层、隐层→输出），才能既防过拟合又保住记忆**。论文的全部贡献就是这一个落点选择，但它背后是一条更深的价值观：**任何干预都要尊重架构的信息通路**。

## 2. 它之前的世界：大 LSTM 训得动了，却被小数据锁死

2014 年的语境：LSTM（L07）已经把序列建模的梯度问题基本理顺，语言模型、机器翻译眼看着要起飞——同年 Ilya 一作的 seq2seq 正是在这条线上。但想训练「大」的 LSTM 语言模型时，所有人撞上同一堵墙：**过拟合**。

典型惨状是这样的：

```
train 困惑度:  ▁▂▃▄▅▆▇  一路下探 —— 模型在拼命背书
test  困惑度:  ▂▃▄▄▄▄▄▄  早早躺平 —— 没学到新东西，甚至回升
```

原因不难算：当时的标配战场是 Penn Treebank（PTB，经典英文语料库，语言模型的试金石），**训练集不到 100 万词、词表只有 1 万**。而一个像样的两层 LSTM 轻松上千万参数。用 66M 参数去拟合 90 万词的语料，模型的最佳生存策略就是把训练集背下来——记忆，而不是学习。这是 AlexNet「大数据喂大模型」剧本的反面：**数据小、模型大，规模红利还没兑现，先被过拟合勒死**。

解药看起来现成：Dropout 在计算机视觉里已经是标配（AlexNet 3.3 节讲过——训练时每个神经元以一半概率临时置零，逼所有神经元学出冗余、不依赖特定伙伴的特征）。可是社区把它往 RNN 上一搬，**水土不服**：直接套用的效果时好时坏，常见结论甚至是「加了还不如不加」。当时大家的解释倾向于「RNN 太特殊」「时序任务不适用 Dropout」。

这篇论文说：都不是。**Dropout 没有失效，是打错了地方**——它的噪声恰好打在 LSTM 全身最脆弱的那条线上。

## 3. 核心思想

### 3.1 一分钟回顾 Dropout（← L01）

训练时每次前向传播，每个神经元以概率 p 被临时置零，测试时全员上岗。直觉：随机抽人组队训练，谁都不能指望「反正队友会搞定」，于是每个神经元被迫学出**冗余、鲁棒、不依赖特定伙伴**的特征，整体效果近似训练了指数多个子网络再取平均。

注意 Dropout 的本质动作：**往网络里注入随机噪声**，逼网络摆脱对任何单一路径的依赖。在 CNN 里这个动作几乎无脑安全——卷积层之间相互独立地看局部窗口，丢掉一个神经元，信息还能从别的路径绕回来。但「几乎无脑安全」这个性质，在 LSTM 里不成立。

### 3.2 先看清 LSTM 的连线：哪些是一次性的，哪条是反复复用的

把一个 LSTM 语言模型按信息通路拆开，只有两类线：

```
          ① 打这里 ✓                        ② 打这里 ✓
              │                                │
 x_t ──[embedding + input proj]──►  LSTM cell  ──[output proj]──► softmax ──► y_t
                                     │    ▲
                          c_t ───────┘    └────── c_{t-1}
                          （循环连接：记忆的传送带，③ 绝对不打）

 ① 非循环连接：输入 → 隐层的投影。每个词向量只经过它一次。
 ② 非循环连接：隐层 → 输出的投影。每个输出位置只经过它一次。
 ③ 循环连接：c_{t-1}→c_t、h_{t-1}→h_t。这条线被复用 T 次——它就是「记忆」本身。
```

关键区别不在「线的粗细」，在**复用次数**：①② 是一次性通道，一个 token 过一遍就走；③ 是循环通道，序列有多长，它就被走多少遍——L07 讲过，cell state 的传送带正是 LSTM 用来「无损长距离搬运信息」的机制。**一条被反复复用的主干线，和一堆一次性支线，对噪声的耐受度完全不同。**

### 3.3 打错位置：传话游戏怎么毁掉记忆

标准 Dropout 的默认打法是「所有权重矩阵一视同仁地丢」——包括循环连接。问题出在一个容易被忽略的细节上：**每处理一个时间步，Dropout 都会重新掷一次骰子**（重新采样一遍丢弃掩码）。也就是说，记忆信号每往前传一步，就被随机篡改一次。

```
h_1 ─篡改1─► h_2 ─篡改2─► h_3 ─篡改3─► … ──► h_50
        （每步噪声不同、且逐级叠加，没有任何对齐机制）
```

这就是传话游戏：**每传一手，就随机篡改几个词，50 手之后全文早已走样**。第一步丢失的信息，第二步补不回来——第二步自己也在被篡改。噪声不是「抖动」，是**随时间累积的系统性侵蚀**。序列越长，记忆的存活率越低，长距离依赖（LSTM 存在的全部意义）最先阵亡。

换成工程语汇：这相当于往一条被全员复用的主干数据通道上，每秒注入一次不同模式的随机丢包，还期望下游服务正常工作。缓存会脏、状态会漂、最终一致性遥遥无期——这条线本来就不该这么动。

### 3.4 打对位置：只剪支线，不动主干

论文的落点方案因此非常克制：

- **输入侧**（①）：在 embedding 进 LSTM 的投影上打 Dropout——每个输入词向量随机丢一些分量。噪声只作用于「这一次的读入」，效果上等价于对输入做词级随机增强。
- **输出侧**（②）：在 LSTM 出 softmax 的投影上打 Dropout——同理，只影响当前位置的预测。
- **循环连接**（③）：原封不动。记忆的传送带保证干净，长距离信息搬运全程无损。

一句话总结打法：**噪声可以打在「过一次就扔」的支线上，绝不能打在「反复复用」的主干上**。Dropout 依然在防过拟合（它依然在逼各投影层学冗余特征），但记忆通路完整保住了——两头都要到了。

## 4. 实验逻辑：小模型大模型各配一套有无正则的对照

**主战场**：Penn Treebank 词级语言模型。指标是困惑度（perplexity——模型对「下一个词」的平均犹豫程度，可以读作「模型眼里的有效候选词数」，越低越好）。

**实验设计**：两个尺寸的模型，各自跑「有无 Dropout」两版，四条曲线互为对照——

- small：两层 LSTM，每层 200 单元（约 4M 参数）
- large：两层 LSTM，每层 1500 单元（约 66M 参数，是 small 的十几倍）

这个设计的用意很清楚：如果正则只在 small 上有效，那可能只是「小模型本来就不过拟合」的假象；**只有证明「无正则时 large 被 small 打败、有正则时 large 才兑现规模红利」，才能说明过拟合是压死大模型的元凶，而落点正确的 Dropout 是解药**。

**训练动态先看一眼惨状**：不加正则的 large，训练中后期是教科书式的过拟合曲线——训练集困惑度持续下探（模型在背书），验证/测试集早早停滞甚至回升（背书对泛化毫无贡献）。当时最常见的权宜之计是**早停**（early stopping，在验证集开始变差前收手），但早停的本质是「模型还没来得及背熟就被叫停」——它保住了已学到的泛化部分，代价是**大参数量的表达力从来没被用上**：模型实际达到的水平，不比一个小模型强多少。正则化的目标是反过来：让训练可以继续跑很久，参数量的红利能被兑现，而不是提前鸣哨收场。

**数字链**（词级困惑度，论文报告值）：

| 配置 | 无 Dropout | + Dropout（打非循环连接） |
|---|---|---|
| small（2×200） | valid 约 131 / test 约 126 | valid 约 121 / test 约 116 |
| large（2×1500） | valid 约 106 / test 约 102 | valid 约 84 / test 约 81（论文摘要报告 test 81.2） |

三个读法：

1. **large 受过拟合伤害最深，也被正则救得最狠**：test 从约 102 直落到约 81，改善远超 small。参数越多，越需要配套正则——AlexNet 的老课，在序列世界复刻了一遍
2. **最锋利的对照**：带 Dropout 的 large（约 81）明显好过无 Dropout 的 large（约 102），而后者参数是前者的十几倍——**不解决过拟合，堆参数是负资产**
3. 关于「历史坐标」，论文的措辞留有余地：这份 large regularized 的成绩，与此前文献里小型无正则模型反复调优达到的最好结果大致在同一量级。更稳的说法是：它是当时 PTB 词级语言模型的最好水平之一，且是靠「正则 + 大模型」这套可复制的工程打法拿到的，而不是靠某个单点技巧

**消融视角**：所有实验里容量、数据、训练预算全同，唯一变量是 Dropout 的落点。把噪声从循环连接挪到非循环连接，结果天差地别——这是「落点即全部」的最干净证明。

## 5. 为什么在这份 List 里：Ilya 的序列规模化工程篇

1. **Ilya 序列军团的工程地基**。L01 是 Ilya 在视觉上的创世记忆，本篇则是序列方向的关键节点：一作 Zaremba、二作 Ilya、三作 Vinyals——紧接着这批人就做出了 seq2seq。而 seq2seq 用的正是多层大 LSTM，**没有这篇的正则化方案，大 LSTM 在真实语料上根本站不稳**。它是「让序列模型可以放心做大」的那块地基
2. **「正则化也要尊重信息通路」——L03 同一价值观的两面**。L03（何恺明）证明的是：任何挡在残差通路上的**变换**（投影、ReLU、缩放）都要收费，通路必须干净；L08 证明的是：任何打在记忆通路上的**噪声**都会随时间累积放大，噪声必须避开主干。两篇从不同角度收敛到同一句话：**架构里每条线都有分工，干预之前先问「这条线承载什么」**
3. **规模红利的守门人**。这份 List 的主旋律是「把模型做大，能力会涌现」，但本篇给出一个清醒的注脚：规模红利不是裸推参数就能兑现的，**过拟合会先把没配好正则的大模型勒死**。Scaling 是系统工程，不是玄学——这条纪律一直延续到 GPT 时代的每一份训练配方

## 6. 织进网里

- **← L01 AlexNet**：Dropout 的出生地。6000 万参数配 Dropout 是同一课的第一讲——大模型必须配正则；本篇把它搬进序列世界，并补上了「落点」这堂进阶课
- **← L03 Identity Mappings**：通路价值观的镜像。L03 禁止在通路上放**变换**，本篇禁止在通路上放**噪声**——同构的底层判断：干净通路是信息无损流动的前提，任何干预先审「这条线承载什么」
- **← L07 LSTM**：被保护的对象。正因为 cell state 是设计来「无损长距离搬运信息」的传送带，往上面撒随机噪声才等于自废武功——正则化方案必须读懂被正则化的架构
- **→ L09 Order Matters**：Ilya/Vinyals 序列线的下一篇——正则化解决「大模型小数据」，接下来撞上的是另一个隐形假设：RNN 认定输入有顺序，可很多数据的本质是集合
- **→ L10 Bahdanau 注意力**：「每条线有分工、干预先审通路」的思维延续到注意力时代——注意力将重组序列的信息通路，让模型每步自己决定「读哪里」

## 自测题

1. 为什么标准 Dropout 打在循环连接上会毁掉 LSTM 的记忆？
   > 每处理一个时间步都重新掷骰子采样噪声，噪声沿循环连接逐级叠加、无法对齐修复——像传话游戏每传一手随机篡改几个词，50 手后记忆信号面目全非；而循环通路（cell state 传送带）正是 LSTM 存放记忆的干线。
2. 论文里 Dropout 的正确落点是哪些连接？为什么这些位置安全？
   > 只打非循环连接：输入→隐层投影、隐层→输出投影；这些线每个 token 只经过一次，噪声不随时间累积（等效于词级随机增强），记忆通路保持干净，防过拟合与保记忆两头兼得。
3. 「Dropout 在 RNN 上无效」这个流行说法错在哪？
   > 不是无效，是默认打法（所有连接一视同仁地丢，含循环连接）位置错了；只打非循环连接后，large 模型 test 困惑度从约 102 直落到约 81——同一个 Dropout，换个落点从有害变成救命。
4. 跨篇：本篇和 L03 Identity Mappings 的「通路」观点是同一价值观的两面，各自说了什么？
   > L03：任何挡在残差通路上的变换（投影/ReLU/缩放）都收费，通路必须干净；L08：任何打在记忆通路上的噪声都会累积放大，噪声必须避开主干——共识：干预之前先问「这条线承载什么」。
5. 这篇为什么是 Ilya「序列规模化」路线的工程配套？规模红利和正则化的关系是什么？
   > seq2seq 及后续大 LSTM 都依赖这套正则才站得稳；实验证明无正则时 large 反而输给 regularized 的更小配置（堆参数成负资产），配上落点正确的 Dropout 后 large 兑现红利——Scaling 是系统工程，不是裸推参数。
