# L14 · Neural Turing Machines — 给神经网络外挂一块内存条

《Neural Turing Machines》（2014，arXiv 预印本） · Alex Graves, Greg Wayne, Danihelka · DeepMind · [arXiv:1410.5401](https://arxiv.org/abs/1410.5401)

注意作者栏：Alex Graves 是序列建模的老兵——LSTM 长程依赖分析的时代同行者、CTC（语音识别里不用逐帧对齐的训练损失）的发明人。这篇是 DeepMind「记忆增强网络」线的开山之作，名字直接致敬 1936 年的图灵机：控制器 + 纸带 + 读写头，只不过这次，纸带和读写头全部用梯度下降学出来。

## 1. 一句话

NTM 干的事：**给神经网络外挂一块可读写的记忆矩阵——控制器发寻址信号，读写头按「软权重」对全库模糊读写，整块内存参与梯度流动**。于是「怎么用内存」这种程序才有的动作，第一次能被梯度下降学出来：在复制、重复复制、排序三个任务上，网络学会的不是映射，是几行带循环和指针的伪算法。

## 2. 它之前的世界：权重是程序，隐状态是内存条——太小，而且没有地址

L06 的视角转换已经给出：把 RNN 看成一个「有状态的迷你程序」——权重是这个程序的源代码，隐状态是局部变量。顺着这个比喻看漏洞：一个程序只有一个变量，能干什么？

这就是 RNN 系的根本处境。**程序的存储（权重）和运行时内存（隐状态）是分离的，但内存只有一条**：隐状态是固定维度的向量，每一步都被覆写（→ L07），想按内容找回第 3 步存进去的信息？没有地址这种东西——一切只能压缩在这条向量里，靠下一层网络「记得」它在哪几位。容量小是显性的病（→ L07 的传话游戏），**不可寻址是隐性的病**：没有「读写第几格」的操作，就没有算法意义上的存储器。生物的类比很扎眼：人脑没有精确地址寻址，但人会**外挂**——笔记本、草稿纸、黑板。数字计算机更是靠这个赢的：图灵机的全部威力来自「无限纸带 + 读写头」，冯·诺依曼架构的全部威力来自「内存与计算分离」。神经网络这两样都没有。

所以方向似乎很清楚：加内存条。**但真正的难点立刻出现，也是本篇最容易误读的地方——你以为瓶颈是容量，加块内存就行；其实瓶颈是可微性**。「写入第 5 格」是个离散动作：地址是整数，读写是跳变。离散操作处处导数为零，梯度穿不过去，反向传播（BPTT，沿时间展开的梯度回传）断链——内存挂上去了，**训练够不到它，等于没挂**。NTM 整篇论文的核心工程，不是设计内存条，而是设计一套「让读写这个离散动作变得连续可微」的软寻址机制。

## 3. 核心思想

### 3.1 三件套：内存条 + 控制器 + 读写头

```
              输入 xₜ
                 │
         ┌───────▼────────┐   接口参数包: key k(内容特征)、
         │     控制器      │   强度 β、插值 g、移位 s、
         │  (前馈/LSTM)   │───锐化 γ、擦除向量 e、
         └──┬──────────┬──┘   添加向量 a
        读出 rₜ│          │寻址信号
             ▼          ▼
   ┌──────────────────────────────┐
   │   记忆矩阵 M（N 行 × M 列）    │ ← 读写头
   │   行 = 存储位置，列 = 特征      │
   └──────────────────────────────┘
      权重 w = [0.02, 0.01, 0.83, 0.04, …]  ← 和为 1，撒在所有行上
```

- **记忆矩阵**：N 个存储位置，每个位置存一个 M 维向量——真的就是一块 N×M 的矩阵，整个网络的可训练参数之外的一块「外置存储」
- **控制器**：一个小神经网络（前馈或 LSTM，后面细说），负责「思考」：读输入和读头取回的内容，决定下一步做什么、发什么寻址信号
- **读写头**：按权重 w 对记忆矩阵做模糊读写的机制，每步一对

### 3.2 软读写：没有「写第 5 格」，只有「0.83 的第 5 格」

一切秘密在权重 w：它不是选一行，而是**一个和为 1 的分布，撒在所有 N 行上**。

**读**：读出的内容是全部行按权重的加权平均——

```
r = Σᵢ w(i) · M(i)
```

**写**：每个位置按权重先擦一点、再写一点——

```
M'(i) = M(i) · (1 − w(i) ⊙ e) + w(i) ⊙ a
```

e 是擦除向量（0~1 的逐维旋钮），a 是添加向量；w(i)=0.83 的那一行被擦掉 0.83 份旧内容、写入 0.83 份新内容，其余行按各自的小权重被轻微触碰。没有一行被精确选中，也没有一行完全无感。

为什么必须这么「软」？回到第 2 节的病根：**离散选择不可微**。硬读写头「跳到第 5 格」的地址是整数，对它的任何参数没有导数，梯度在读写头处断流，整条「网络学会用内存」的路走不通。软加权让「写哪里」变成参数的连续函数——w 由寻址信号算出，寻址信号由控制器输出算出，一路处处可导，BPTT 全程贯通。这是 L10 软注意力同一手法在「记忆」上的复用（→ 第 6 节），代价同样存在：**用精确性换了可微性**——读写天生是模糊的，「精确寻址」只能靠后面两步（锐化）逼近。这个权衡是全篇最重要的设计决策。

### 3.3 寻址两步走：先按内容找，再按位置挪

权重 w 怎么算出来？两步。

**第一步，内容寻址：拿着「特征」找那一行。** 控制器输出一个 key 向量 k，和记忆矩阵每一行算余弦相似度，乘上一个强度 β（倍率，越大分布越尖），过 softmax：

```
w_content(i) = softmax( β · cosine(k, M(i)) )
```

直觉：像 L12 的 Q/K 问答——「我要找的内容长这样，哪一行和我最像？」softmax 出来的就是分布。这正是 L11 Pointer 那类「把注意力分布当输出」的亲戚：寻址即注意力。

但只有内容寻址不够。想一个具体场景：复制任务里，网络把 20 个向量依次写进第 1～20 格，读到结束符后要回头把第 1 格的内容读出来。此时 key 该是什么？内容都在库里，**「第一格」这个位置概念，内容本身表达不了**。凡是「下一个」「上一个」「回到开头」这类跳转，都需要第二步：

**第二步，位置寻址：在旧权重的基础上挪。** 三个连续的小操作，全可微：

1. **插值（interpolation）**：门 g 把内容寻址的结果和上一步的权重混合——`w = g·w_content + (1−g)·w_prev`。g=1 表示「完全按内容找」，g=0 表示「沿用现在的位置」——「记住我在哪」这个能力全靠这一步
2. **卷积移位（shift）**：控制器输出一个移位分布 s（比如 0.9 的概率右移一格、0.1 不动），权重和这个分布做卷积——「右移一格」被软化成「大部分权重挪到下一行，少量渗到邻居」。循环、跳转全靠它
3. **锐化（sharpening）**：移位是卷积，卷积天然把权重抹糊（每挪一步都渗一点给邻居），所以最后用 γ≥1 把分布重新变尖——每挪一步模糊一点，锐化把它压回去

三步连起来看，是一条清晰的哲学：**每一步都在「可微」和「精确」之间找平衡**——卷积换来的模糊用锐化补偿，内容寻址的犹豫用插值门控制。最终 w 足够尖时，行为上就是精确寻址，但数学上全程连续。

### 3.4 控制器：前馈或 LSTM 都行，角色是「CPU」

控制器用前馈网络：快、简单，但自己没有内部状态——所有中间量必须当场存进记忆矩阵。用 LSTM（→ L07）：自带一条门控传送带，可以把中间数据挂在内部，把「何时访问外部记忆」的决策和「暂存数据」分工。论文两种都试了：前馈控制器在简单任务上学得更快，LSTM 控制器在需要内部暂存的任务上更稳——**NTM 的架构是「CPU + 内存条」，控制器本身就是可替换的 CPU**。每步控制器输出的完整接口参数包（k、β、g、s、γ、e、a）就是这条 CPU 的指令格式。

## 4. 实验逻辑

三个玩具任务的看点从来不是任务本身——复制几个向量有什么难？看点在**泛化**：任务只训练到中等长度，测试时推到远超训练的长度。死记硬背会暴露，**只有学到了算法（循环+指针），才能在没见过的长度上继续跑**。

- **复制（Copy）**：喂一串随机二进制向量+结束符，要求原样输出。网络学到的行为翻译成伪代码，就几行：

```
1  把写头移到位置 0
2  循环: 读入向量 → 写入当前行 → 写头右移一格
3  读到结束符,停
4  循环: 从当前行读出 → 输出 → 读头右移一格
5  输出结束符,停
```

   数字上的关键证据：训练只到长度 20，测试推到 120——NTM 一直保持低位错误（论文报告量级为个位数百分比的向量级误差），而纯 LSTM 基线在长度 30～40 之后错误率断崖上升、长序列上近乎全错；同任务下 NTM 所需参数还更少。**控制流从梯度下降里长出来了**
- **重复复制（Repeated Copy）**：复制 n 遍，n 作为输入给一个标量。这考察「变量」的使用——n 要先存起来，循环计数对着它比。网络学到「存变量 + 循环」的伪算法，并能泛化到训练没见过的 n。论文也诚实记录了失败模式：偶尔重复过头（算法学得像，但不是严格正确的程序）——可微的模糊性偶尔泄漏成行为毛刺
- **排序（Sorting）**：给一串带优先级标签的二进制向量，要求按优先级输出。网络学会的伪算法：读入时给每个向量算优先级、连同内容一起写进记忆；输出时按优先级逐个内容寻址读出。「先计算再按计算结果调度读写」——这已经是带排序子程序的完整小算法
- 另有联想召回、动态 n-gram 等任务（前者考「按内容查表」，后者考「自学统计结构」），结论同向：**外挂可微记忆显著优于把一切压进隐状态**

## 5. 为什么在这份 List 里

1. **「网络能学会算法」是通用智能叙事的早期证据**。Ilya 的世界观是「学习即压缩」：智能的本质是学会生成数据的程序。但在 NTM 之前，「网络学会的」大多是映射（分类、翻译）——控制流始终是工程师写死的。NTM 第一次演示了循环、指针、变量这些**程序原语可以被梯度下降学出来**。这是从「学会函数」到「学会程序」的第一步，也是「足够大的网络终将学会通用算法」这条信念最早的实验支点。L06 那句「RNN 是迷你程序」的比喻，在这里被升级成可验证的主张
2. **记忆与计算的分离，是记忆演化线的起点**。L07 的门控是「内部记忆管理」——传送带再精巧，仍是藏在网络体内的一条向量。NTM 把记忆**外置成显式介质**：容量成为独立的旋钮（N×M 想多大就多大），不再和网络参数绑死。这条线一路演化：DNC（2016，Nature，修复 NTM 寻址缺陷、加了内存分配与时序链接，后来进入 AlphaStar）→ L16 关系 RNN 的记忆矩阵 → 乃至今天大模型的上下文窗口工程
3. **可微分编程思想的起点**。「离散动作软化成可微操作」——这套方法论后来统治了一切：内容寻址≈注意力（→ L10/L12 的 Q/K+softmax 是它的推广形态），Pointer Networks（→ L11）把分布当输出，扩散模型把离散去噪软化成连续场。「梯度流向哪里，智能就能长在哪里」——NTM 是这条工程哲学最彻底的一次表达：连「读写内存」这个最硬件的操作都被软化了

## 6. 织进网里

- **← L06 Karpathy RNN**：「RNN = 有状态的迷你程序」的比喻在此正名——配上外挂内存和可学的寻址，迷你程序第一次真的能执行带循环的算法
- **← L07 Understanding LSTM**：门控 = 内部记忆管理，但记忆仍是一条传送带；NTM 把记忆外置成档案室。控制器用 LSTM 时，相当于给这台机器装了颗「自带工作记忆」的 CPU——内外两级记忆各司其职
- **← L10 Bahdanau / ← L11 Pointer**：内容寻址与软注意力同一手法（按相似度 softmax 软选择），与 Pointer「分布即输出」同一精神；L12 的 Q/K+softmax 本质是把内容寻址推广成通用信息混合机制——寻址即注意力，注意力即寻址
- **→ L16 关系 RNN**：记忆增强线的直系续篇——RMC 明说 NTM/DNC「有分区、无交互」（记忆格之间不交流），用 slot 间注意力补上交互那一半；NTM 开辟的「记忆矩阵」设计空间由它继续耕耘
- **→ L20 Scaling Laws**：一条隐秘的张力——外挂记忆是「用结构换能力」的路线，后来的主流选择了「不外挂，把上下文窗口当记忆，靠规模压过去」。in-context learning 可视为「只增不删的软记忆」的规模版。两条路线的消长，正是这份 List 反复出现的「结构先验 vs 暴力规模」张力

## 自测题

1. NTM 的读写为什么必须是「软」的？读和写各是怎么操作的？
   > 离散寻址（跳到第 i 格）导数为零，梯度穿不过去，BPTT 断链——软加权让「写哪里」成为参数的连续函数；读 = 全部行按权重 w 加权求和 r = Σw(i)·M(i)，写 = 每行按权重先擦后加 M'(i) = M(i)(1−w(i)⊙e) + w(i)⊙a，没有精确选中、全库参与。
2. 寻址两步走各自解决什么问题？为什么只有内容寻址不够？
   > 内容寻址（key 与每行余弦相似度×β 过 softmax）按「长得像」找；位置寻址（插值混合旧权重→卷积移位→锐化）解决「下一个/回到开头」这类与内容无关的跳转——复制任务里内容都在库里，「第 1 格」这个位置概念内容表达不了；移位的卷积模糊靠 γ≥1 锐化压回。
3. 易混淆：复制任务的关键证据是什么？为什么纯 LSTM 崩而 NTM 不崩？
   > 关键证据不是「能复制」而是泛化：训练只到长度 20、测试推到 120，NTM 保持低位错误而 LSTM 在 30～40 之后断崖上升——死记硬背过不了没见过的长度，只有学到「循环+指针」的算法才能继续跑；LSTM 一切信息压在一条被覆写的隐状态里，长度即容量上限。
4. 内容寻址与 L12 的哪个机制同源？控制器用 LSTM 还是前馈，取舍是什么？
   > 同源于注意力（Q/K 打分+softmax 软选择；L10 软注意力、L11 Pointer「分布即输出」是亲戚）——寻址即注意力；前馈控制器快、无内部状态，中间量须当场写外存，LSTM 控制器自带门控传送带可暂存中间量——NTM 是「可替换 CPU + 内存条」架构。
5. 「网络学会了几行伪算法」为什么是通用智能叙事的早期证据？这条线后来被什么路线覆盖？
   > 它演示了控制流原语（循环、指针、变量）能被梯度下降学出——从「学会映射」跨到「学会程序」，是 Ilya「学习即压缩、学会一切程序」信念最早的实验支点；后来的主流不外挂内存，把上下文窗口当记忆靠规模覆盖（in-context learning = 只增不删的软记忆），外挂记忆思想在长上下文/RAG 工程与 L16 的记忆矩阵里延续。
