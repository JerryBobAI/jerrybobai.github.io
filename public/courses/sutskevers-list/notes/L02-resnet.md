# L02 · ResNet — 深度成为超能力

《Deep Residual Learning for Image Recognition》(2015) · 何恺明， Xiangyu Zhang, Shaoqing Ren, Jian Sun（微软亚洲研究院） · [arXiv:1512.03385](https://arxiv.org/abs/1512.03385)

## 1. 一句话

ResNet 用一个**小学生都能看懂的恒等式**（`y = F(x) + x`）解决了「网络堆深反而变差」的退化问题，第一次把网络训到 **152 层**，在 ImageNet 上把 top-5 错误率压到 **3.57%、首次超过人类**——而且它发明的「跳连」从此长在几乎所有后续架构体内，包括 Transformer 和 GPT。

## 2. 它之前的世界：一个诡异的障碍

AlexNet 之后三年，「更深 = 更好」已是行业共识：2013 年 ZFNet 11 层，2014 年 GoogLeNet 22 层。逻辑很朴素——层级特征嘛，层越多特征越抽象。但工程师们很快撞上一堵诡异的墙：

**网络堆到 30 多层，训练误差反而上升。**

请注意这里有个极易搞混的点，也是本篇第一个关键认知：**这不是过拟合**。过拟合是「训练误差很低、测试误差很高」（模型死记硬背）。而这里是**训练误差本身变差**——网络连训练集都拟合不好了。模型没有记住太多，是它**根本没学进去**。

为什么说这「诡异」？因为理论上不该如此。做一个思想实验：假设 18 层网络能达到某个不错的性能，那 34 层网络**至少**应该能做到一样好——把前 18 层原样复制，让新增的 16 层学成**恒等映射**（`f(x) = x`，什么都不做，原样传递）就行了。深网络的解空间严格包含浅网络的解空间，**深不应该输给浅**。

但现实是：SGD（随机梯度下降）**找不到**那个解。问题出在「让一堆层精确学会什么都不做」出乎意料地难：

- 深度网络的权重初始化是围绕 0 的小随机扰动，训练是从这个随机起点出发爬山
- 无跳连的普通层（论文称 **plain 层**）天生倾向于「做变换」，用 ReLU 网络去表达「恒等」这个函数非常别扭——就像让一个学生抄写原文一字不改，但他每过一页都**强制要求动笔修改**，传抄 30 遍必然走样

这就是退化问题的本质：**不是深没用，是「深而不变」这个看似免费的东西，在 plain 架构里学不出来**。

## 3. 核心思想：让每一层学「增量」，而不是「完整答案」

### 3.1 残差学习：diff，不是快照

ResNet 的改动小到令人发指。原来每个堆叠的块要学完整的目标映射 `H(x)`；现在改成让它学**残差**：

```
F(x) := H(x) − x      （相对输入，要改变多少）
输出：y = F(x) + x    （增量 + 原值）
```

架构上就是一条**跳连（shortcut / skip connection）**：输入 `x` 绕过两三个卷积层，直接加到它们的输出上。

用版本控制来类比：plain 网络每一层都要输出一份**完整快照**，30 层就是 30 次全量重写，每次都有出错风险；残差网络每层只提交 **diff**——「这里改一点，那里改一点」。如果某一层没什么可改的呢？**提交一个空 diff 就行**。

关键就在这里：**「什么都不做」在残差架构里便宜到了极点**——

- plain 层要学会恒等：需要多层非线性变换精确拟合出 `f(x)=x`，难
- 残差块要学会恒等：只需把 `F(x)` 的**权重推向 0**，梯度只消说「别动」——`y = 0 + x = x`，无损透传

于是深网络有了**下界保护**：最坏情况下新增的块全部退化成透传，深网络至少不比浅网络差。「深」从一场赌博变成免费选项。

### 3.2 梯度视角：给信息修一条高速公路

这是 ResNet 真正的命门所在，也接上了 L01 埋的主线。

反向传播的本质是**梯度逐层相乘回传**。plain 网络里，梯度传到浅层要连乘几十项导数，任何一项偏小，浅层梯度就衰减殆尽——AlexNet 时代我们说 ReLU 解决了「激活函数饱和吃掉梯度」，但**长链路连乘衰减**是另一个独立病灶，ReLU 治不了它。

跳连改变了数学结构。对 `y = F(x) + x` 求导：

```
∂y/∂x = ∂F/∂x + 1
```

那个 **`+1`** 是全部魔力：不管 `∂F/∂x` 多小、甚至为零，梯度都**至少原样传回**浅层一条无损通道。梯度再也不需要「闯关」——它有了一条默认直达的高速公路，卷积层只在旁边提供「改道选项」。

快递类比：plain 网络像包裹每经一个中转站都必须重新分拣，任何一站积压，包裹就永远到不了；ResNet 像有一条**默认直通的传送带**（跳连），中转站只在必要时改派。信息永远有一条回家的路。

把三篇连起来看，「让梯度活下去」这条主线现在是三级跳：**ReLU 治激活饱和 → Dropout 无关梯度但治过拟合 → ResNet 治长链衰减与退化**。下一级别的规模，每一次都被「梯度通不通」卡住，每一次都由一个朴素改动解锁。

### 3.3 有效深度是学出来的，不是设计死的

因为每个块都能便宜地学成透传，**网络自己决定哪里需要变换、哪里保持**。152 层的网络，可能有些层只在部分样本上才真正「干活」。后来 Veit et al. (2016) 给出一个漂亮解读：ResNet 实际上行为上像**大量浅网络的集成**——删掉训练好的 ResNet 的个别层，性能只轻微下降（plain 网络删层直接崩溃）。这解释了它的鲁棒性。

### 3.4 架构细节（快速过）

- **BasicBlock**（ResNet-18/34）：两个 3×3 卷积 + 跳连
- **Bottleneck**（ResNet-50/101/152）：`1×1 降维 → 3×3 卷积 → 1×1 升维`，先压缩通道再算，省算力
- 维度不匹配处（通道翻倍、分辨率减半），跳连上配一个 1×1 卷积做投影对齐
- 全程使用 **BatchNorm**（2015 年另一篇论文）：把每层输入分布拉回稳定区间——ResNet 能用大学习率训练，BN 功不可没。两个组件是搭档关系

## 4. 实验逻辑：两组对照钉死结论

**决定性的对照组**（这篇论文最漂亮的实验设计）：

| 对比 | plain 网络 | ResNet |
|---|---|---|
| 18 层 → 34 层 | 训练误差**上升**（退化实锤） | 训练误差**下降**（退化消失） |

同一深度、同一数据，唯一的差别是「有没有跳连」——退化问题的病因和解药同时被钉死。

**主战场结果**：ResNet-152 在 ImageNet 上 top-5 错误率 **3.57%**，ILSVRC 2015 冠军，比前一年的冠军方案近乎腰斩，**首次超过人类水平（约 5.1%）**。L01 那张错误率曲线的终点就是 ResNet 画上的。

**极端压力测试**：CIFAR-10 上堆到 **1202 层**——依然能正常训练，训练误差不随深度变差（虽然这个规模过拟合了，但「退化」被彻底证伪）。

**消融的启示**：跳连的三种实现（零填充 / 1×1 投影 / 全部投影）性能差别很小——说明关键不是「投影能学东西」，而是**「存在这条无障碍通路」本身**。这个结论为下一篇埋了伏笔。

## 5. 为什么在这份 List 里：大模型时代的地基

1. **Transformer 的骨架就是 ResNet**。GPT 的结构图里那条贯穿全层的直通线——residual stream——就是跳连的直系后代。Transformer 每个子层写的都是 `y = x + Attention(x)`、`y = x + FFN(x)`，**先加再输出**，一个字都没改。可以说：Transformer = 注意力 + ResNet 骨架。没有 ResNet，几十层的 Transformer 根本训不动
2. **它补全了 scale 信念的第三块拼图**。Ilya 的公式是「模型 × 数据 × 算力」，其中「模型」这维在 2015 年之前是带病的——深到一定程度就退化。ResNet 把深度变成免费午餐（想加就加、不会更差），规模化道路上的最后一个架构障碍被扫清
3. 这是计算机视觉史上引用最高的论文之一（20 万+ 引用），何恺明也因此成为 CV 界传奇——一篇论文解决一个「理论上不该存在的问题」

## 6. 织进网里

- **← L01 AlexNet**：ReLU 和 ResNet 是「让梯度活下去」主线的两级；AlexNet 的 8 层天花板由此打破
- **→ L03 Identity Mappings（下一篇）**：ResNet 的官方续作，何恺明回答「跳连为什么**真正**有效」——把 ReLU 和加法的位置重新排列做消融，发现关键是「信息通路干净与否」，并顺手改进出 pre-activation 结构。这篇是对 ResNet 机制的显微镜级剖析，Ilya 把它单独列进 List（而不是当作附注），说明他要你理解的是**机理**而不只是结论
- **→ L12 Transformer**：residual stream 是 Transformer 的主干道，到时候你会认出每一个 `+x`
- **→ L19 GPipe / L20 Scaling Laws**：152 层能训了，接下来是「怎么把大模型分布到多卡」（GPipe）和「深度/宽度/数据该按什么比例配」（Scaling Laws）

## 自测题

1. 退化问题的定义是什么？它和过拟合的区别在哪？为什么说它「理论上不该存在」？
   > 网络堆深后训练误差本身上升（SGD 找不到解），不是过拟合（训练低测试高）；理论上深网络解空间严格包含浅网络（新增层学恒等即可），深不应输给浅——这是优化问题而非表达能力问题。
2. 残差块让每层学什么？为什么「权重压向 0」比「学会恒等映射」容易得多？
   > 学残差（增量/diff）而非完整映射 H(x)；plain 层表达恒等需要多层非线性精确拟合，残差块只需把 F 的权重推向 0（空 diff）即无损透传——「什么都不做」变得极便宜。
3. 从反向传播看，`y = F(x) + x` 里的 `+1` 提供了什么？它和 ReLU 解决的是同一个问题吗？
   > ∂y/∂x = ∂F/∂x + 1，+1 保证梯度有一条零衰减直通浅层的无损通道；不是同一问题——ReLU 治激活函数饱和，ResNet 治长链连乘衰减与退化，两个独立病灶。
4. GPT / Transformer 结构里的哪一部分是 ResNet 的直系后代？
   > 每个子层的写法 y = x + Attention(x)、y = x + FFN(x)（先加再输出），贯穿全层的 residual stream（残差流）就是跳连的直系后代。
5. 为什么说 ResNet 让「有效深度」变成可学习的？
   > 每个块都能便宜地学成透传，网络自己决定哪里变换哪里保持；行为上像大量浅网络的集成（Veit et al.），删掉个别层性能只轻微下降。

## 内化记录（2026-09-18 · 得分 5/5）

**Q1：退化问题的定义是什么？它和过拟合的区别在哪？为什么说它「理论上不该存在」？**

> 退化问题的定义是 SGD 找不到解。退化问题是训练误差本身变差，模型没学进去，过拟合是误差训练很低，测试误差很高，模型死记硬背。不应该存在是因为深网络的解空间应该严格包含浅网络的解空间，深不应该输给浅。

✅ 满分。特别表扬「SGD 找不到解」的表述——解存在（解空间包含关系保证）但优化器到不了，这是**优化问题**而非**表达能力问题**，这个区分是理解 ResNet 的钥匙。

**Q2：残差块让每层学什么？为什么「权重压向 0」比「学会恒等映射」容易得多？**

> 残差网络学的是相对输入，要改变多少，而不是直接学完整的目标映射。权重压向0比恒等映射容易是因为恒等需要多层非线性变换精确拟合，而残差只需要把权重置零，无损透传。

✅ diff 类比用对了，「权重置零 vs 精确拟合恒等」的难易对比抓准了。

**Q3：从反向传播看，`y = F(x) + x` 里的 `+1` 提供了什么？它和 ReLU 解决的是同一个问题吗？**

> +1 保证梯度都至少原样穿回浅层一条无损通道。ReLU指的是激活饱和，ResNet治的是长链衰减与退化。

✅ 无损直通 + 两个独立病灶分得清。

**Q4：GPT / Transformer 结构里的哪一部分是 ResNet 的直系后代？**

> y = x + Attention(x)

✅ 对。补充：完整的一个 Transformer block 有**两个**残差子层——`y = x + Attention(x)` 和 `y = x + FFN(x)`。顺带记一个词：**residual stream**（残差流）——那条贯穿几十层、所有子层都往里读写的直通主干道，L12 的主角。

**Q5：为什么说 ResNet 让「有效深度」变成可学习的？**

> ResNet 每个块能够便宜学透传，自己决定那里变换哪里保持，像是大量浅网络的集成，且具备鲁棒性。

✅ 透传 + 浅网络集成 + 删层鲁棒性，三个要素齐了。
