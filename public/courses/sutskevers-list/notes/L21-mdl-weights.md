# L21 · MDL 权重 — 死记硬背的解，比特账单最贵

《Flat Minima》(1997, Neural Computation) · Sepp Hochreiter, **Jürgen Schmidhuber**（慕尼黑工业大学） · [MIT Press](https://direct.mit.edu/neco/article/9/1/1/6027/Flat-Minima)

文献注记：这份 List 流传的条目名《Keeping Neural Networks Simple by Minimizing the Description Length of the Weights》其实属于另一篇论文——Hinton & van Camp 1993 年的 COLT 工作，「给权重的信息量记账」这个主张最早由 Hinton 组提出（做法：给权重注入噪声，把「权重里装了多少信息」直接当惩罚项）。1997 年这篇是那条线的完整理论版（前身短文是 1995 年的《Simplifying Neural Nets by Discovering Flat Minima》），文献里说「flat minima 论文」指的就是它。本篇讲 1997 这篇。

术语先立：**MDL（Minimum Description Length，最小描述长度：好模型 = 数据拟合得好 + 模型本身编码短，两者求和最小——奥卡姆剃刀的数学化。原理本身的系统教材在 → L22，本篇看它在神经网络上的落地）**。

## 1. 一句话

把「这个神经网络泛化好不好」翻译成一道记账题：**总码长 = 数据残差的码 + 权重自己的码**。尖锐的极小值逼你把每个权重记到小数点后十几位，比特账单爆炸；又宽又平的极小值（**flat minima，平坦极小值**）允许把权重记得很粗——反正抖一抖损失不涨。于是「平坦」成了「可泛化」的指纹：flat 的解码得短、扛得住噪声、抓的是真结构；sharp 的解全靠小数点后的巧合死记硬背。训练时挑平不挑尖，就是在用奥卡姆剃刀剃掉巧合。

## 2. 它之前的世界：拟合误差最小，缺了半本账

1997 年。反向传播已发明十年，而「深层网络不可训练」的悲观还笼罩着学界（→ L01 讲过那个年代；诊断出病灶「梯度消失」的，正是本文一作 Hochreiter 1991 年的毕业论文）。过拟合是家家在防的病，药只有两味：早停，正则。

但「为什么正则有效」只有手挥式的解释：「别让权重太大，模型就『简单』了」。简单到底是什么？没有可计算的定义。更尴尬的是参数量这把尺子也不够细：同样的参数量、同样把训练误差压到零，有的解对新样本照样准，有的解一碰新样本就翻车——**参数量一样，泛化天差地别**。在「参数个数」的分辨率上，这两种解长得一模一样。

还有一笔旧范式根本没算过的账：模型学好了是要**交给别人**的。传一个模型，光传「它在训练集上错多少」不够——权重本身也得传。权重是实数，实数没法直接装进字节，得先量化（quantization：把实数四舍五入到固定精度的网格上再编码）再发。这一下冒出一个新成本项：**你的解需要多少位精度才能用？**

读者以为最好的解是「训练误差最小」的那个；这篇论文说，是「数据残差 + 权重编码」总账最短的那个。

## 3. 核心思想

### 3.1 给权重记账：量化要花多少比特

先算最朴素的账。传一个实数权重，量化到精度 δ（比如小数点后 3 位，δ=0.001），数值落在 [-W, W] 里，需要的比特数大约是：

```
每个权重的码长 ≈ log₂(2W / δ)
```

精度放大一倍，每个权重省 1 bit；单个权重这点账不起眼，乘上权重总数就是大头。做工程的人对这笔账有现成的参照系：FP32 存权重，每个权重付 32 bit；若盆地的容忍度允许只用 4 bit 记一个权重，模型体积立刻缩到八分之一——今天大模型 4-bit 量化省显存，付的就是这笔账。

于是问题变成：**δ 能不能放大？** 答案取决于解长在地形的哪里。

### 3.2 损失面上的两种盆地

把损失看成权重的函数，极小值附近的地形分两种：

```
损失
 │      sharp                     flat
 │        ▼                    ___________
 │        │                   /           \
 │       /│\                 /             \
 │      / │ \               /               \
 │ ────/  │  \─────────    /                 \────
 └────────────────────── 权重 w ─────────────────→
   抖 ±0.001 损失就上墙        抖 ±0.1 损失几乎不动
   δ 只能极小,每个权重付满精度   δ 可以很大,粗编码也够用
```

**尖锐极小值（sharp minimum）**：针尖立在平地上，只有精确插在这一点损失才低，权重抖 ±0.001 就出盆。传它，δ 必须极小——每个权重付满精度比特。

**平坦极小值（flat minimum）**：一片宽盆地，权重抖 ±0.1 损失几乎不动。δ 可以开得很大——粗精度编码照样落在盆内，每个权重只付几 bit。

论文的核心论证是：**量化精度 δ 由盆地宽度决定，盆地宽度由解的「结构含量」决定**。泛化好坏第一次和「编码成本」直接挂上钩——这是一条全新的推理链。

### 3.3 为什么「平」就是「泛化」

「flat = 泛化好」，论文给了两层论证，都值得记：

**噪声论证**：flat 盆地里的解，权重被扰动后功能不变——它的工作**不依赖任何精细权重**。一个抖一抖就废的解，算的东西只在「恰好这组权重值」上成立；那恰好是什么？恰好是训练集。能扛扰动的解，才真正把规律（扰动下稳定的部分）和巧合（一抖就散的部分）分了家。训练时给权重注噪会把解自然推向平坦区——这是后来 noise injection、dropout（→ L01）一族正则直觉的先声。

**数据论证**：存在一种假平坦——盆地只对「这份数据」平坦。论文强调要找的是「大」平坦极小值：删掉一部分训练样本，盆地还得保持平坦。只对全样本合起来平坦的解，平坦性本身也是死记出来的。加上这个条件，「平坦」才是可泛化解的指纹。

顺带一份红利：在容忍的扰动范围内，可以顺手把接近零的权重清零（剪枝）、其余权重量化到粗网格——**平坦性直接兑换成模型的「简单性」**。List 条目名里的「Keeping Neural Networks Simple」那半句，说的就是这层兑换。

### 3.4 怎么找平坦盆地（一段带过）

论文给了搜索算法（flat minimum search）：先正常训练收敛，再围绕这个极小值迭代估计「损失不涨」约束下每个权重能容忍的最大扰动范围，把整个容忍区域显式算出来；再配合尺度不变性的运用（网络一层「输入乘 c、输出除 c」功能不变，可借此调整平坦区域的宽度）和训练期的权重注噪，把解从针尖赶进宽盆地。算法细节此篇不展开——重点不是算法，是「平坦度可以被显式优化」这个观念本身。

## 4. 实验逻辑

这是一篇论证型论文，实验的职责是支撑推理链，不是刷榜。四步组织逻辑：

1. **存在性**：同一任务的网络，损失面上确实并存 sharp 和 flat 两类极小值——两种地形都可抵达，不是理论假设
2. **可搜索**：上述算法能从 sharp 出发找到 flat，平坦范围可被显式度量
3. **可兑换**：在容忍范围内做量化和剪枝，性能几乎不掉——「平坦 = 码短 = 模型简单」当场兑现
4. **泛化对照**：flat 的解在新数据上明显更稳——「平坦指纹 → 泛化」推理闭合

## 5. 为什么在这份 List 里

1. **「学习即压缩」的最早期神经版本**。1997 年，神经网络的学习被重写成一道码长最小化题：好解 = 拟合好 + 权重编码短。比 Ilya 亲手的 AlexNet（→ L01）早 15 年，比「Scaling Laws 的损失就是码长」（→ L20）早 23 年——整份课程的世界观在这里出示出生证明
2. **1997 年的前瞻性，今天全额兑现**：大模型的权重量化（把几百亿参数压成 8-bit/4-bit 省显存推理）就是「量化精度 → 比特账」这套计算的工程化；2017 年「大 batch 训出尖锐极小值、泛化变差」的发现，以及后来的 sharpness-aware minimization（SAM：显式惩罚损失面尖锐度的训练技巧），都是「flat minima = 好解指纹」这个 1997 年判断的当代生产
3. **Schmidhuber 系 → Ilya 系的思想影响**。Schmidhuber 一系把压缩当学习的第一原理（压缩 = 找规律 = 智能），Ilya 把这条线接过去变成 GPT 的实践语言：预训练损失就是压缩长度，语言模型是数据的压缩器。List 把这篇放在实践篇 → 理论篇的接缝上，位置本身就是一句话：你以为你在训模型，其实你在做压缩

## 自测题

1. MDL 视角下「传一个训练好的神经网络」要付哪两笔比特账？sharp 和 flat 极小值分别把账单推向哪里？
   > 两笔：数据残差的码（拟合误差）+ 权重自身量化到精度 δ 的码；sharp 逼小 δ、每权重付满精度比特，flat 允许大 δ、码单大减——总账 = 拟合 + 权重编码，不是只看拟合。
2. 「平坦极小值里的解泛化好」的两层论证分别是什么？
   > 噪声论证：权重扰动下功能不变 = 没用小数点后的巧合，扛得住扰动的解才真正分清了规律与巧合；数据论证：删掉部分训练样本后盆地仍平坦（「大」平坦），排除只对这份数据平坦的假平坦。
3. 辨析：参数量相同的两个解、训练误差都压到零，为什么一个泛化好一个死记硬背？哪把尺子才分得开它们？
   > 「参数个数」这把尺子分不开——两个解在这个分辨率上一模一样；能分开的是描述长度：sharp 解必须付满精度比特（靠巧合），flat 解粗精度就够（靠结构），码长细一个分辨率。
4. 本篇和 L22 的分工是什么？今天大模型工程里哪两样东西是它的直系后代？
   > L21 是 MDL 在神经网络上的具体化（权重付比特账），L22 是 MDL 原理本身的教材；直系后代：权重量化（LLM 8-bit/4-bit 省显存 =「量化精度→比特账」的工程化）+ SAM 等「显式优化平坦度」的训练技巧。
5. 为什么说这篇是「学习即压缩」世界观的出生证明？
   > 它最早把神经网络学习重写成码长最小化：好解 = 拟合好 + 权重编码短；Ilya 系接过去说成「预训练损失 = 压缩长度、模型 = 压缩器」——L20 的损失曲线、L26 的 ELBO=码长，都沿这本账。
