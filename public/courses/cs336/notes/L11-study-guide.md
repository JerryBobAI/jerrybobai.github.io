本讲是缩放定律系列第二讲（收尾）：前半以 Cerebras-GPT、MiniCPM、DeepSeek LLM 三个公开案例拆解工业界如何真刀真枪地用缩放定律定超参、定配比（含 WSD 调度与临界批量），并速览 Llama 3、Hunyuan-Large、MiniMax-01 的新进展；后半从两条谱条件出发推导 muP 参数化（初始化+每层学习率的宽度缩放），并用大规模消融检验其迁移能力与失效边界。

## 分节要点（带时间锚点）

### 一、本讲定位：缩放定律如何用在真实模型里
- 本讲是缩放定律系列第二讲（收尾），结构为「案例研究 + muP 深挖」：先看真实模型团队如何把缩放定律用进设计流程，再推导 muP 的数学与实证边界([0:00])
- 动机：ChatGPT 之后前沿实验室对缩放细节全面保密——讲者向实验室朋友打听缩放做法，得到的回答是「什么都不告诉你」——只能依赖公开且执行认真的大规模模型论文反推最佳实践([0:00])
- 三个核心案例：Cerebras-GPT、MiniCPM、DeepSeek LLM，三者至今仍是最详细的公开缩放研究；新近的 Llama 3、Hunyuan-Large(MoE)、MiniMax-01（线性注意力）各有缩放内容但细节稀疏([0:00])
- 带着怀疑检验上一讲：log-log 拟合是否真可靠？isoflop 真能定最优 token 权衡吗？能拿来定最优学习率吗？该为「缩放友好」专门挑架构或参数化吗？([0:00])

### 二、Cerebras-GPT:muP 的首次公开验证
- Cerebras-GPT：0.1B-13B 模型家族按 Chinchilla 配比训练，核心发现是 muP（maximal update parameterization,最大更新参数化）让放大过程显著更稳定、更省心([0:05])
- 标准参数化(standard parameterization, SP)下各规模损失围绕预测线大幅震荡（学习率要随规模重调，难以精确命中预测）；muP 训练的曲线紧贴缩放律拟合，可预测性大增，整体表现不输 Pythia/GPT-J([0:05])
- 这是 muP 最早的公开验证之一：前沿实验室普遍关注参数化、初始化随规模的变化以及逐层学习率来稳定缩放；业内还有 MetaP 等同类变体（相关论文未公开）([0:05])
- muP 一句话：非嵌入参数按 1/宽度 初始化 + 每层学习率按 1/宽度 缩放；与 SP 的真正差异在后者——Kaiming 式初始化本就接近 1/√fanin，真正新鲜的是「每层学习率各不相同」([0:05])
- 策略上极其激进：把实验下探到 40M 参数代理模型做大规模超参网格搜索，再靠 muP 把超参稳定放大回目标规模；「小代理模型 + 稳定放大」是本讲反复出现的主题([0:05])

### 三、MiniCPM：WSD 调度与近乎单次训练的 Chinchilla 分析
- 目标是「用大算力把小模型喂好」：1.2B-2.4B 模型在 2024 年中即胜过多数 2B、追平不少 7B，确属当时前沿；手法与 Cerebras 同源——muP 稳定嵌入/初始化/逐层学习率并固定纵横比(aspect ratio)，把实验从 9M/30M 放大到 0.5B/1B，约省 5 倍算力([0:10])
- 批量大小仿 Kaplan：对每档规模拟合二次型找临界批量大小（critical batch size,收益递减拐点），目标损失与最优批量对数线性，可由预期损失反推批量；同时实测各规模最优学习率稳定在 ~1e-2，跨数量级不动——muP 生效的直接证据([0:15])
- 关键陷阱：cosine 调度的形状取决于终止数据量，单次训练的早期 checkpoint 不能当作「小数据训练」来研究数据缩放；正统做法要从头训练到每个目标终点，运行数随目标数平方级增长——讲者强调「这事坑了无数人」([0:20])
- 解法是 MiniCPM 推广的 WSD(warm-up stable decay)梯形调度：warmup-平台-衰减三段，平台段学习率恒定可复用，从任意 checkpoint 回卷后再单独衰减，≈一次完整训练的成本做完 Chinchilla 扫描([0:20])
- 实践效果：衰减期损失骤降属正常现象；各 token 数的最优损失不输 cosine 且免预先定终止点，业界已广泛采用；另有华盛顿大学+Apple 的工作估计「Chinchilla 惩罚」（过量 token 相对配比的损失劣化），小规模外推即可再省配比分析([0:20])
- 拟合结果：method 1（训练曲线下包络）+ method 3（双变量缩放律联合拟合）给出高达 192 tokens/参数的配比（疑似离群，与多数文献不符），但核心结论可信——Chinchilla 非硬约束，20:1 只是起点，可大幅上探([0:25])

### 四、DeepSeek LLM：直接拟合超参缩放律
- DeepSeek LLM v1(2024,7B/67B)首次出手即在开源侧追平 Llama 2/Mistral；论文里大量细致的缩放消融体现「认真做缩放科学」的态度，与 MiniCPM 并列最透明的公开研究([0:30])
- 方法论与前两家最大差异：不用 muP；在两个小规模上对批量大小×学习率做网格，每格取最优，再分别对最优批量、最优学习率拟合缩放律直接外推到大模型——简单直接，但需要对缩放律有强信念([0:30])
- 讲者吐槽：学习率的拟合线「有点可疑」，换一条水平线似乎也能拟合；但超参缩放律的现实意义主要是把量级搞对——批量与学习率的选择本身有宽盆地，相对宽容([0:35])
- 调度用 WSD 变体：warmup+平台+两段各 10% 的衰减（冷却合计约占总算力 20%），不同衰减选择影响不大，效果与 cosine 相当([0:35])
- 广泛规律：超参缩放律在各家论文里普遍显得噪声大、牵强，isoflop/Chinchilla 复现却总是干净漂亮；DeepSeek 从 ~1e24 FLOPs 量级外推，精准命中 7B/67B 的最终表现——缩放律真能在训练前预测能力([0:35])

### 五、2024-2025 新模型简报：配比在漂移
- 总体观察：近年新发布模型的缩放细节越来越稀疏——DeepSeek v2/v3 只强调 MLA、低比特训练等新组件，不再有新缩放律研究；MiniCPM 与 DeepSeek v1 至今仍是 2025 年最详细的公开缩放研究([0:40])
- Llama 3 重做 isoflop/Chinchilla 分析，得约 39:1（文中亦称 40:1）的 token/参数比：20:1 并不稳固，配比整体在上移，可能来自架构的算法效率或数据质量提升([0:40])
- Llama 3 还把对数似然(NLL)经 sigmoid 映射为下游基准准确率，据称可从小模型+Llama 2 的拟合预测 405B 的表现并用于数据选料，但披露有限，更像辅助工具而非核心方法([0:40])
- Hunyuan-Large(MoE)重做 Chinchilla 得 96:1（按活跃参数计）；「isoflop 拟合可给出可预测的最优配比」是被复现得最好的缩放结论，具体数值则随架构与数据漂移——大家普遍想待在数据多于参数的一侧，让模型好用且推理便宜([0:40])
- MiniMax-01 用缩放律为架构背书：lightning（线性）注意力与混合版的下包络与 softmax 注意力基本持平，足以支撑长上下文路线；同类图常见于 Mamba/Mamba-2/deltaNet 等论文，由主力模型发布给出大规模版本属罕见([0:45])

### 六、muP 推导：两条谱条件
- 出发点：初始化与每层学习率本质上是「自由变量」（没有先天理由非得那样设），可以操纵它们换取尺度不变性——最优学习率跨规模恒定，小规模实验即可定超参；讲者推荐两份可读材料：所依据的预印本与博客《A Practitioner's Guide to muP》([0:45])
- 两条谱条件(spectral conditions)：A1——初始化时每坐标激活保持 Θ(1)，不爆不消失(整个激活向量的范数相应为 Θ(√n)，n 为宽度)；A2——初始化后走一步梯度，激活的变化量也保持 Θ(1)([0:50])
- A1 推导（深度线性网络+高斯初始化）：随机矩阵算子范数集中到 σ·(√n(l)+√n(l−1))，且 ‖h(l)‖≈‖W(l)‖·‖h(l−1)‖；取 σ≈1/√fanin 乘纵横比修正（fanin 更大时乘 √比值），归纳可证每层激活范数稳定在 √n——结果即熟知的 1/√fanin（Kaiming 式）初始化([0:50])
- A2 推导（学习率）：batch=1 时一步 SGD 更新 ΔW=−lr·(∇L)hᵀ 是秩一矩阵；补一条更强的隐含假设——一步之后损失的变化量也 Θ(1)——联立各量即可解出每层学习率([0:55])
- 结论：SGD 每层学习率 = fanout/fanin（MLP 中 ≈4,近似常数，故 SGD 下 muP 与 SP 相差不大）；对 Adam 重做推导得 1/fanin——这才是 muP 与 SP 的真正分野([1:00:00])
- 对照 SP：Kaiming 初始化本就 ≈1/√fanin（已达标），SGD 全局常数学习率也勉强凑合；Adam 下全局常数学习率会随宽度放大让更新越来越大——这正是大模型必须调小学习率的根源([1:00:00])

### 七、muP 的边界：Cerebras 表回顾与问答
- 回看 Cerebras-GPT 的 SP/muP 对照表：嵌入层特殊（one-hot 输入的范数不随词表放大），其余所有非嵌入层初始化与学习率都按 1/宽度 缩放——正是 Adam 版 muP 规则；讲者类比物理学的重整化（取极限时让关键量保持稳定）([1:05:00])
- 架构假设的边界：推导基于深度线性网络（只反复乘矩阵，教学用简化）；非线性、注意力层、GLU 各需单独分析才能得到对应的 muP 形式；谱条件里的维度比由该层矩阵乘的输入/输出维度(fanin/fanout)决定，MLP 的 d_ff=4·d_model 即得比值 4([1:05:00])
- Q&A：谱条件是宽度→∞ 的渐近论证；经验上「只要用缩放律把学习率钉准，就不需要 muP」——muP 只是把最优学习率的漂移压到最小；DeepSeek 用全局学习率，但让它随规模下调，以补偿大模型更新变大([1:05:00])

### 八、muP 实证检验与全课总结
- 实证检验来自预印本《A Large Scale Exploration of μP Transfer》（独立研究者出品）：只变宽度、固定深度的受控设置；细节上注意力得分用 1/D 缩放而非标准的 1/√D（为满足激活/更新尺寸稳定）([1:10:00])
- 问题一「迁移有效吗」：有效——宽度 128/512/2048 下，小规模扫出的最优学习率放大后仍然最优，迁移相当可靠([1:10:00])
- 鲁棒性消融：换激活函数（SwiGLU/squared ReLU 与 ReLU 同最优点）、批量 ±4 倍、初始化变体（query 置零、输出层按 SP/muP 缩放）都不破坏学习率迁移([1:10:00])
- 失效场景：加可学习增益/偏置会破坏（需移除）；Lion 等异构优化器破坏——muP 是为 AdamW 控制更新尺寸定制的；过强权重衰减也破坏——后者是实践中真实会碰到的显著失效([1:15:00])
- 反证 SP 的必要性：同学习率放大到宽度 2048 直接训崩（损失退化）；而 10B 参数 hero run 验证小规模选定的 2^-6 学习率仍最优；Meta 已把 muP 用于 Llama 4，但尚未成行业共识([1:15:00])
- 全课收束——「野外」缩放三件套：用缩放律定超参（学习率与批量最关键）、用 muP 或稳定性假设免掉超参搜索、用 WSD 等调度降低拟合缩放律本身的算力成本([1:15:00])

## 核心概念速查
| 术语 | 一句话解释 |
| --- | --- |
| 缩放定律(scaling laws) | 损失随参数量、数据量、算力呈幂律，可外推预测大模型表现 |
| muP(maximal update parameterization) | 非嵌入层按 1/宽度 初始化 + 每层学习率缩放，让最优超参跨规模不变 |
| SP(standard parameterization) | 标准参数化：Kaiming 式初始化 + 全局常数学习率；Adam 下学习率需随宽度下调 |
| 谱条件(spectral conditions) | 初始化激活与一步梯度更新的激活变化均保持 Θ(1) 的两条 muP 设计条件 |
| WSD(warm-up stable decay) | 升温-平台-衰减的梯形学习率调度；平台段可复用，≈一次训练做完 Chinchilla 扫描 |
| 临界批量大小(critical batch size) | 批量增大收益递减的拐点，与目标损失对数线性，可据此反推训练批量 |
| isoflop 分析 | 固定总算力扫「参数×数据」配比，取损失下包络或二次型最低点定最优配比 |
| fanin / fanout | 层权重矩阵的输入/输出维度；muP 学习率：SGD 取 fanout/fanin,Adam 取 1/fanin |
| Chinchilla 配比 | 每参数 20 token 只是起点；实测 Llama 3 约 39:1、Hunyuan 96:1、MiniCPM 拟合 192:1 |
| 冷却(cooldown) | WSD 尾段把学习率降到极低以「兑现」损失；损失骤降属正常，约占总算力 10-20% |

## 自测题
1. 为什么不能用单次 cosine 学习率训练的早期 checkpoint 近似「训练更少数据」的实验？
   > 不同数据目标对应不同的 cosine 形状（衰减节奏不同），早期 checkpoint 的学习率状态与从头训练到该数据量的模型不一致。
2. WSD 学习率调度的三个阶段是什么？它如何让 Chinchilla 分析只需约一次训练的成本？
   > warmup 升温、stable 平台、decay 衰减；平台段学习率恒定，从任意 checkpoint 回卷后单独衰减，即可得到任意数据目标的完整轨迹。
3. muP 相对标准参数化的两处核心改动是什么？
   > 非嵌入层权重按 1/宽度 缩放初始化，且每层学习率按 1/宽度 缩放（对应 Adam 的 1/fanin 规则）。
4. muP 的两条谱条件(spectral conditions)分别是什么？
   > 初始化时每坐标激活保持 Θ(1)；初始化后走一步梯度，激活的变化量也保持 Θ(1)。
5. 按谱条件推导，SGD 与 Adam 的每层学习率分别如何随 fanin/fanout 缩放？
   > SGD 为 fanout/fanin（MLP 中约为常数 4）,Adam 为 1/fanin。
6. DeepSeek LLM v1 在超参选择上与 Cerebras-GPT/MiniCPM 的最大方法论差异是什么？
   > 不用 muP，直接在两个小规模上网格搜索最优批量与学习率，再对最优值拟合缩放律外推到大模型。
7. 大规模迁移探索发现哪些改动会破坏 muP 的学习率迁移，哪些不会？
   > 可学习增益/偏置、Lion 等异构优化器、过强权重衰减会破坏；换激活函数、批量缩放、初始化变体不会。
8. Llama 3 与 Hunyuan-Large 的 isoflop 复现分别给出多大的 token/参数配比？共同说明什么？
   > 约 39:1 与 96:1（按活跃参数）；说明 Chinchilla 的 20:1 只是起点，好数据好架构可大幅提高配比。
