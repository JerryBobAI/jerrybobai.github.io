## 一句话概览

本讲回答「不抄别人的超参，如何自主创新训出最好的模型」：先用统计学习理论与 Bell Labs 的历史论证数据缩放幂律是自然的，再过一遍 Kaplan 式单变量缩放（数据、架构、深度宽比、参数口径），进入批大小与学习率（临界批大小、muP）两个最棘手的缩放对象，随后给出 log loss 与下游任务分裂的警告，最后落到 Kaplan–Rosenfeld 联合缩放与 Chinchilla 的 ~20 token/参数，并指出产品时代已从训练最优转向推理最优。这是缩放定律专题的上篇，下讲(Scaling Laws 2)继续。

## 分节要点（带时间锚点）

### 一、开场与历史脉络：从理论界到 Bell Labs

- 设定场景：富朋友借你 10 万张 H100 跑一个月，要训出最强的开源 LM；infra、数据集、架构等零件前面各讲都已备齐，但早期讲座给的建议只是「照抄 Llama」——缩放定律才是让你自主创新、推动前沿的工具([0:00])
- 方法论转变：过去不愉快的做法是直接训一批大模型再调超参，烧掉天价算力；新乐观主义是训一批小模型、从中学到规律，再外推回大模型，在真正的大训练上「一次命中」([0:00])
- 理论源头：统计机器学习早就关心样本量与误差的关系——有限假设集的泛化界约 1/√m、非参数密度估计的 n^(β/(2β+1)) 速率，都是「缩放定律的理论版」([0:00])
- 关键跃迁：理论给的是上界(upper bound)而非实测损失；缩放定律的飞跃在于承认界太松，转而在经验上直接拟合误差与数据量之间的函数形式([0:05])
- 最早的缩放定律论文：1993 NeurIPS Bell Labs（Vapnik、Cortes 等）提出「不训完就预测模型好坏」——test error = 不可约误差 + 多项式衰减项，并且真的训小模型拟合曲线再外推，与现代缩放定律几乎同构([0:05])
- 思想史碎片：Banko & Brill 用 log 图展示「数据换算法」；2012 年已有人在争论幂律是不是正确的函数形式；Hestness et al 2017（百度）完成最早的大规模神经缩放实验（机器翻译/语音/视觉），给出三区域图，并预言了涌现能力、按算力缩放、量化换精度等今天才流行的观念([0:05])

### 二、数据缩放：幂律为何是自然的

- 先回答「有没有不缩放的情况」：inverse scaling prize 专门搜集模型越强表现越差的例子（如模仿能力变强导致更难压制抄袭行为）；远离数据分布(OOD)时可以不缩放甚至反向缩放——本质是经典深度学习鲁棒性问题的延伸([0:10])
- Kaplan 论文的全景：compute、数据量、参数量在 log-log 图上对 test loss 皆近线性，而且对下游任务与分布外设定也成立——幂律出现的频率远超预期([0:10])
- 定义：数据缩放 = 数据集大小 n 到超额误差（excess error,超出不可约误差的部分）的映射；关注区间是幂律区到渐近区，小数据端离开随机猜测区的行为则难得多([0:10])
- 前提：只动数据时，模型要选得足够大、不被数据量饱和（避开渐近区）；动 compute 时数据与模型按预定比例联合缩放([0:10])
- 例一(Stats 101)：高斯总体估计均值，估计量的平方误差为 σ²/n，log-log 斜率恰为 -1——参数估计给出漂亮的整数码率([0:15])
- 例二（非参数回归）：在 D 维单位方块里分箱估计任意光滑回归函数，误差约 n^(-1/D)；灵活函数类带来维度依赖，实证指数（机器翻译 -0.13、语音 -0.3、语言建模 -0.095）远慢于 1/n 或 1/√n——斜率近似反映任务的内在维度(intrinsic dimensionality)([0:15])

### 三、数据缩放的工程应用

- 数据组成只影响截距、不影响斜率（Kaplan 的图）——意味着数据选择/消融实验可以放在小模型上做，不必烧大预算([0:20])
- 用缩放律回归求最优数据混合：已有若干论文，但与一切数据选择研究一样，可靠执行并不容易([0:20])
- 多 epoch 训练：引入有效样本量的概念，重复数据收益递减——约 4 个 epoch 后新增收益急剧缩小；对标准缩放律做改造，即可建模「独特 token 数随重复衰减」([0:20])
- 数据配方的双轴优化：重复高质量来源（维基百科、盗版书）10 遍，还是加入更多新数据？CMU 的工作专门研究「重复 vs 换低质量新数据」的权衡——前提是假设幂律在每个配比上都成立，再分别拟合外推([0:20])
- 问答澄清：数据缩放曲线用的是「一个足够大的固定模型」跑所有数据点；compute 缩放曲线才是数据与模型按预定比例联合走([0:25])

### 四、模型缩放：架构、参数与切片分析

- 工程问题清单：新架构（状态空间模型）、新优化器、各种新技巧哪些值得放大？给定 FLOP 该花在更大模型、更久训练还是更多数据上？缩放定律给出一套简单的回答流程([0:25])
- Transformer vs LSTM：无论 LSTM 堆多少层，都存在约 15 倍量级的常数因子算力差距（log 轴上的平行位移）——用 LSTM 有固定的计算效率惩罚([0:25])
- 广度架构对比（Yi Tay 等/Google）：把一批备选架构逐个放大与 transformer 基线对撞，只有 GLU（门控线性单元）与 MoE 可靠地胜出——这正是今天主流配置(SwiGLU、Switch Transformer)的由来([0:25])
- 优化器同理：SGD vs Adam(Hestness)呈常数因子差距；重要的是分析方法——小模型上测出常数 offset，即可外推到大规模做取舍([0:25])
- 深度 vs 宽度：1 层显著更差，但其余深度选择的损失曲线几乎重合；长宽比(aspect ratio)存在很宽的最优盆地（10–100 皆可），印证了架构讲座「宽盆地」的结论([0:30])
- 「不是所有参数都等价」：把 embedding 参数计入会得到弯折的缩放曲线，只统计非嵌入(non-embedding)参数才干净；MoE 还需要换算「等效稠密参数」——延伸结论：曲线不交叉、只差常数 offset，故可在小尺度切超参切片并安全外推，养成 scale-aware 调参心态([0:30])

### 五、批大小与学习率的缩放

- 批大小的两段行为：批小于噪声尺度(noise scale)时，加倍 batch ≈ 多走一步梯度，并行收益与优化效率兼得；超过后额外样本不再消噪，收益被优化景观的曲率主导([0:35])
- 临界批大小(critical batch size)= 完美缩放与强收益递减的分界点；OpenAI 论文从理论上分析过，也可以经验拟合估计出「进展放缓」的位置([0:35])
- 损失目标越低，临界批越小、可用的最优批越大——梯度需要更干净来「降噪」，与降低学习率联动；Llama 3 训练报告正是随训练推进逐步加大 batch([0:35])
- Kaplan 的 compute 缩放结论：算力增长时最优批变大而总步数可保持不变（固定批数则步数暴涨）——对数据并行是好消息([0:35])
- 学习率的标准做法：模型越宽最优学习率越小，经验法则约 1/width；更进阶的做法是把各尺度的最优 LR 找出来再拟合一条缩放律([0:35])
- muP（宽度重参数化）：按宽度缩放初始化方差、各层学习率与前向输出幅值，使最优学习率跨规模稳定——最小模型上调一次即可直接迁移到最大规模；Meta 在 Llama 4 提出的 MetaP 是同类思路([0:40])

### 六、警示与缩放驱动的超参设计流程

- 大警告：缩放律对 log loss（next-token 交叉熵）行为良好；一旦直接以 benchmark 为缩放目标，行为就难预测得多([0:40])
- 反例（Yi Tay 论文）：参数量对负 log perplexity 干净线性——仿佛只剩总算力重要；换成下游 SuperGLUE 准确率则完全非线性，架构之间明显分化([0:40])
- 状态空间模型同样：perplexity 缩放漂亮，但上下文学习、QA 类能力落后——别把 perplexity 缩放当成下游缩放([0:45])
- 缩放驱动的调参流程：训几个跨两个数量级的小模型 → 确认 log-log 线性关系 → 按拟合律设定最优超参；斜率通常不变，小模型结果迁移得出奇地好——学习率是重要例外([0:45])

### 七、联合缩放与 Chinchilla：多少 token 配多少参数

- 问题背景：数据远比算力充裕的年代（约 2021–2023），限制资源是训练 FLOPs 总预算；小模型灌海量数据与巨模型吃少量数据都明显浪费——需要「每 FLOP 最优」的配比([0:45])
- 联合缩放函数形式（Rosenfeld/Kaplan 各自提出、一阶等价）：误差 = 数据量的多项式衰减项 + 模型规模的多项式衰减项（外加不可约误差）；形式是「从帽子里抽出来的」，但 Rosenfeld 的 3D 曲面（数据×参数×损失）拟合惊人准确([0:45])
- 外推验证：只用「小模型×小数据」那一半做拟合，预测大模型大数据的误差，在 ImageNet 与 Wikitext 上几乎完全命中([0:50])
- Chinchilla(Google)为钉死配比实证训练了一批模型：三种方法给出一致的缩放系数（方法一/二 0.5/0.5,方法三差 0.03），经典结论 ~20 token/参数；Kaplan 的估计明显偏离，主因之一是 cosine 学习率必须完整走到冷却末尾才是有效模型、不能中途截断，而 Kaplan 用了截断的运行([0:50])
- 方法一（最小包络）与方法二(IsoFLOP)：前者叠全部训练曲线取「任何算力预算下最优」的下包络，包络点自身呈幂律；后者固定多档 compute 扫模型大小、取每档最小点（或拟合二次取谷底）再拟合缩放律——两者对最终预算分别给出 63B 与 67B，互相印证，IsoFLOP 是最标准的做法([0:55])
- 方法三（直接对 Rosenfeld 形式做 3D 曲线拟合）拟合明显更差、系数偏离；Epoch AI 甚至从论文图上取证提取数据点做复现，发现数据是好的、错在曲线拟合（残差非零均值），修正后与方法一/二几乎一致——罕见的「复现反而证明原结果正确」([0:55])

### 八、从训练最优到部署最优

- 时代转折：Chinchilla 与 Kaplan 写作时 LLM 还不是产品，大家只想要最大最聪明的模型、不管推理成本；如今模型产生收入，推理开销正式进入权衡([1:00:00])
- token/参数比一路上移：GPT-3 约 2 → Chinchilla 20 → 如今以数十万亿 token 训练（讲者提到最新的 Qwen 用了 30T）——宁可付一次性的训练成本，也不付大模型持续的推理运营成本([1:00:00])
- 健壮性案例（文本扩散模型）：学生 Ishan 推进文本扩散时，套用同一套 IsoFLOP 流程，得到与自回归几乎相同的曲线、只差常数 offset——缩放律在新模型上自然涌现，不是精选出来的特例([1:00:00])
- 收束：log-log 线性不止于数据，延伸到模型参数与总算力，支撑超参决策与「更大模型 vs 更多数据」的资源权衡；今天 recapped Kaplan 与 Chinchilla，下讲继续缩放定律([1:05:00])

## 核心概念速查

| 术语 | 一句话解释 |
|---|---|
| 缩放定律(scaling laws)| 训小模型拟合损失与数据/参数/算力间的可预测关系，外推指导大规模工程决策 |
| 幂律(power law)| 误差 ∝ n^(-α)：log-log 图上的直线，斜率 α 同时刻画任务「学习难度」 |
| 三区域图 | Hestness 2017：随机猜测区 → 幂律缩放区 → 不可约误差渐近区 |
| 超额误差(excess error)| 总误差减去不可约误差；缩放律刻画的是这一段 |
| 不可约误差(irreducible error)| 数据与模型都无限大也消不掉的误差地板 |
| 内在维度(intrinsic dimensionality)| 非参数视角下缩放斜率约 -1/D；估计它本身与建模数据一样难 |
| 逆缩放(inverse scaling)| 模型越强某些任务表现越差的反常缩放，常见于远离数据分布的行为 |
| 噪声尺度(noise scale)| 批内随机采样带来的梯度噪声量级；批小于它时加批 ≈ 多走梯度步 |
| 临界批大小(critical batch size)| 完美缩放与收益递减的转折批大小；损失目标越低，它越小、可用批越大 |
| muP | 按宽度重参数化初始化与各层学习率，使最优学习率跨规模一次调好、直接迁移 |
| MetaP | Meta 在 Llama 4 提出的同类按规模重参数化方案（讲者表示尚未看懂细节） |
| IsoFLOP 分析 | 固定多档算力、每档扫模型大小取损失最小点，再拟合最优参数/FLOP 缩放律；Chinchilla 三法中最标准 |
| 最小包络法(minimum envelope)| 叠全部训练曲线取下包络，包络上的点即各算力预算下的最优配置 |
| Chinchilla 比例 | 训练最优配比约 20 token/参数（以训练 FLOPs 最小为目标） |
| token/参数比 | GPT-3≈2 → Chinchilla 20 → 现代数十万亿 token：推理成本驱动持续上移 |

## 自测题
1. 缩放定律的核心方法论是什么？相比「直接训大模型再调参」的旧方式好在哪？
   > 训一批跨数量级的小模型、拟合可预测规律再外推到大规模，在大训练上一次命中；省下在大模型上反复试错的天价算力
2. Hestness et al (2017) 把模型行为随数据量分成哪三个区域？
   > 随机猜测区（小数据）→ 幂律缩放区（可预测）→ 不可约误差渐近区
3. 语言建模的数据缩放指数约 -0.095，远慢于均值估计的 -1，为什么？
   > 神经网络是灵活的非参数函数类，D 维输入下误差约 n^(-1/D)；斜率反映任务的内在维度
4. 什么是临界批大小(critical batch size)?损失目标降低时它如何变化？
   > 完美缩放与强收益递减的转折点；目标越低梯度要越干净，临界批越小、可用的最优批越大（Llama 3 随训练加大 batch）
5. muP 解决什么问题？代价/局限是什么？
   > 按宽度重参数化初始化与各层学习率，使最优学习率跨规模稳定、小模型调一次直接迁移；实践中不像论文说的那么理想
6. 「不是所有参数都等价」指什么？计数口径错了会怎样？
   > embedding 参数不服从与主体参数相同的缩放；计入后缩放曲线弯折，只有非嵌入参数才呈干净 log-log 线性
7. Kaplan 对最优 token/参数比的估计为何与后来的 Chinchilla 相差很远？
   > 关键之一是 cosine 学习率不能中途截断——必须完整冷却到末尾才是有效模型，而 Kaplan 用了截断的运行
8. Chinchilla 之后，实际模型的 token/参数比为什么一路上涨？
   > LLM 成为产品后推理成本进入权衡：宁可付一次性训练成本，也不付大模型的持续推理开销（GPT-3 2 → 20 → 数十万亿 token）
